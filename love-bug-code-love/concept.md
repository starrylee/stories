# 故事概念卡（Story Concept）

- **故事名称（暂定）**：《零日重逢》（备选：《核心崩溃》《守护进程》）

- **故事类型**：职场 + 虐恋 + 悬疑（查真相），TVB 职场剧质感；长篇双段式结构（成长线 → 双强线）

- **故事背景**：当代一线城市软件/互联网行业，一线大厂与创业公司交织的技术职场；专业细节真实，群像鲜活

- **核心人物**：
  - **男主**：达西内核的技术灵魂人物（如首席架构师）——表象高冷傲慢、直言不讳易得罪人；内里判断精准、行动派、一旦认定便守护一生。从导师式守护到并肩守护，爱的表达是"兜底"而非"甜言"
  - **女主**：双段式成长——前半段是普通人里的硬骨头、低起点职场小白（被栽赃背锅、被低估，但死不低头）；经过分离与真相淬炼，后半段以独当一面的大女主（伊丽莎白式能力担当）归来
  - **反派配角**：蠢而坏的同事/中层——能力不行业绩焦虑，靠写 bug 使坏、栽赃嫁祸酿成大祸；其技术作恶是全篇危机引擎，也是男女主分离与重逢的因果枢纽

- **核心设定**：技术作恶（蓄意埋 bug）是可被查证的——真相散落在代码、日志与时间里，构成贯穿全篇的悬疑骨架

- **核心冲突**：
  1. 明线：女主从背锅小白到大女主的成长 vs 反派的持续构陷与二次作恶
  2. 情感线：达西式傲慢开场 → 共克难关相爱 → 反派大祸酿成"不可抗力"被迫分离（男主牺牲自己收拾烂摊子/女主为保护男主主动消失）→ 五年后重逢，身份与权力结构重置，二次"傲慢与偏见"→ 达西式二次告白，守护落地
  3. 价值线：小人物"被看见" vs 强者"学会低头"，两种骄傲的和解

- **故事主题**：被看见的成长，不因时间改变的爱；真相或迟但到，守护一生

- **故事卖点**：
  - 虐点与悬疑强绑定：分离不是误会梗，而是反派 bug 大祸的直接后果——重逢日即真相大白日，情绪与 plot 同时结算
  - 双段式女主弧光（小白→大女主）+ 达西内核男主全程不变，"变与不变"的对照即最大情感张力
  - 职场单元案例天然适配长篇/多集体量，反派的"技术作恶"线是撑起 60-100 集改编容量的贯穿骨架

- **商业模式**：通用

- **一句话故事概述（Logline）**：一个被栽赃背锅的职场小白，在为公司救火中与高冷架构师相爱，却被一场蓄意代码大祸逼至分离；五年后她以大女主身份归来，而那个用一生守护她的人，终于等到真相大白与她并肩的那天。

## 结构备忘（改编容量规划）

- A 段（成长期）：约 35-45 集，单元职场案例铺节奏，反派埋 bug 暗线 + 感情升温线并行
- 分离段（虐点峰值）：约 5-10 集，大祸爆发 → 背锅 → 牺牲 → 分离
- B 段（重逢期）：约 30-40 集，身份反转张力 + 反派线收网 + 达西式二次告白
- 反派线须贯穿全篇（分离与重逢均由其技术作恶驱动），是撑起总量的关键骨架
