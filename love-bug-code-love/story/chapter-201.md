# 第二百零一章 一张回单

卡片钉上墙的第九天，回单来了。

不是人来的。是一个信封，寄到铺子，牛皮纸的，寄件人一栏空白，邮戳是邻省一个她查过就没有再查的城市。池默拆开，里面一张卡片——不是空白卡片，是照着他的格式写好的。

三段，一段不缺：

"故障：一台修不了的机器。诱因：一九九三年交付，投运两年后开始停机，此后三十年，每年停机时间变长。**停机期间无人报警。**过程：不赘述，赘述需两小时。建议：**该机器无修复方案。仅请求：在你们墙上，给它留一个格子。**"

池默在电话里念给她听。念完，电话那头是铺子里熟悉的安静——零件盒、镊子、隔壁的收音机。

"一九九三年。"她说。

"对。"池默说，"比聂海生那页纪要还早六年。"

她在书房的白板前站起来，走过去，把年份写上：1993，1999，2004——池默的案子和周衡的案子各自入列——再往后，2007，2015，2023。写完她退后一步看。

一整条时间线。三十年，六代人。每一代人里，都有一个话被摁回去的人。**这不是一条弧——是一个矿脉。**

"卡片怎么回？"池默问。

"这单你已经接完了。"她说，"他的请求是留一个格子。你钉卡片那天，格子就留了。现在只差一件事——"

"钉他的这张？"

"钉他的这张。"她说，"钉在你那张的旁边。他写的是回单，**单子来来回回，才算通。**"

电话那头沉默了几秒。

"我钉的位置，"池默说，"想好了。钉在墙的正中间。"

"为什么？"

"我这面墙挂了十几年，从来没有正中间。"他说，"头些年是没东西配挂中间。后来东西多了，也没哪张配。这张配——**一张写'修不了'的卡片，就该在正中间。**修得了的东西，挂在哪儿都是修得了。修不了的，位置就是它的分量。"

第二天下午，池默发了张照片过来：卡片钉好了，正中，两张卡片一左一右——他那张国在左，回单在右，中间隔着两厘米。照片里看不出别的，就是一面旧软木板，几十张卡片，中间两张新的。

她把照片存了两个地方：工作档案一份，另一份发给温遥，配了一句话：

"明年的提案墙，第四件候选。"

温遥回得很快："两张卡片一起挂？"

"一起。"她说，"一张是问，一张是答。**单问没答的墙是控诉，有问有答的墙才是收留。**"

---

周五晚上，自由陈述的排期定稿了。

温遥拉了个表发到筹备组：三个报名人，同一个下午，顺序抽签。周衡抽到第一个，"停机两小时"第二个，聂海生压轴。场次说明只有两行，是温遥写的，写完被沈见微改了一个词——

原稿："每人五分钟，讲述被打断的经历。"

她把"经历"划掉，改成：

"每人五分钟，**讲那一段没讲完的话。**"

改完她跟温遥说："不是讲经历。经历是过去时——这些人要讲的不是过去发生了什么，是**当年那几句没出口的话，原样补出来。**时态不一样，台上的话就不一样。"

温遥盯着屏幕看了一会儿，回了三个字："改得好。"隔了几秒又补一句："你发现没有，这三个人的讲题，排在一起像一句话——周衡替收音机讲，'停机两小时'讲十五分钟，聂海生讲一页纪要。**一台收音机，十五分钟，一页纸。全是没送出去的东西。**"

她看着这句话，很久没回。

书房里，江叙白在改他自己那份讲义——明年他也排了一场，讲"制度补丁"的进阶课。两个人的键盘声一前一后，偶尔停一下，又响起来。

"温遥说，"她忽然开口，"三个讲题排在一起像一句话。"

"哪一句？"

"没送出去的东西，凑成一屋子。"她说，"我从前办展，是想让人看见'留下来'的东西。现在这一届，满台都是'没送出去'的东西。**留下来的和没送出去的——原来是一个东西的两面。**留下来，是有人收了；没送出去，是没人收。"

江叙白的手停在键盘上。

"那台一九九三年的机器，"他说，"你现在怎么看？"

"我看它不只是一个案子。"她说，"三十年，每年停机时间变长，没人报警——**这是一台一直在说话的机器，只是说的话没人登记。**他现在把它写成卡片寄过来，是第一次有人替它登记。"

"那你们登记得了吗？"

"登记得了。"她说，"登记和修复是两回事。**登记是承认它坏过——这一步，三十年没人做过。**"

台灯底下，笔架上的钢笔、桌沿的搪瓷缸、两杯茶。窗外没有雨，冬夜很静。

她合上电脑之前，最后看了一眼排期表。三个名字排在一起。她在聂海生的名字旁边，把去年在笔记本页脚画的那个空括号，添在了后面。

括号还是空的。但她知道快了——**这个人上台那天，括号里会有字。**
