# 第五十九章 第三方鉴定

鉴定机构是方工选的。

不是本地那几家跟各大厂法务都熟到能一起吃饭的，而是一家总部在北京、以"不接回头客"著称的电子数据司法鉴定所——方工的原话是："这案子要么别鉴定，要鉴定就找一个连我们的话都不听的。"

鉴定范围三方签字确认：举报信所附"原始项目"的真伪、两个仓库的创建时间先后、代码流向。女主提交了她的证据包三份，核查组提交了内部调阅记录，第三方材料里还包括乔曼自己签过的那批调阅单——她在技术委员会上亲手投票通过把自己的签字送进去的那一刻，谁也没有提醒她这一条。

鉴定进行了十一天。

这十一天里，她照常上班。染色课题进入二期排期，值班表轮转，茶水间的咖啡机修好了又坏。圈内那场舆论战的热度按江叙白预言的半衰期衰减——三天，七天，第十天的时候，热榜上的位置已经让给了一桩明星离婚。两万条评论不会消失，但它们不再增长。时间戳停在原地，涨潮的是别的。

只有一个人的热度没有衰减。乔曼那两周安静得反常：评审照做，例会照开，附加说明的起草稿写得比谁都周全。第 55 章那场顶撞之后，她把"收敛"两个字执行得像执行一份变更方案——每一步都对，每一步都没有表情。

温遥在茶水间跟她说："她安静下来的时候，比她闹的时候可怕。"

"我知道。"女主说，"安静是她的发布窗口。"

---

鉴定报告是周三上午十点送达的。

方工没有先开会，而是先做了两件事：把报告的纸质版当场拆封，编号，扫描归档；然后才通知三方到场。会议室里，HR 总监、核查组、技术委员会三方坐成一圈，乔曼以技术秘书的身份坐在记录位——这是章程给她的位置，也是她此刻唯一能坐的位置。

方工念结论。他的声音平得像在念一份天气记录：

"第一，举报信所附'原始项目'trace-mender/heal，经 GitHub API 元数据、commit 对象哈希、作者邮箱行为链三条独立证据链交叉验证，判定为伪造仓库。创建时间为本年度十一月二十六日二十三时零六分，晚于被举报人开源项目首次提交两年零两个月。"

"第二，伪造仓库两百一十七次提交中，至少六十四次存在时间戳倒填特征，其中一次引用了晚于其声称日期十一个月才存在的 issue 编号。"

"第三，伪造仓库初始化提交的作者邮箱为 u237114@163.com，该邮箱前缀格式与灵犀科技内部工号格式一致。该线索已超出本次鉴定范围，移交公司核查组。"

念完，他把报告合上，看了一圈会议室："我提醒一句。鉴定意见只对送检材料负责。但邮箱这条，是它自己长出来的。"

会议室安静了三秒。

HR 总监先开口，口径是准备好的："感谢第三方机构。鉴定结论澄清了候选人资格问题，公示即刻恢复，本周五重新进入流程。至于 u237114——"他顿了顿，"属于内部核查事项，我们会另行跟进。"

"另行跟进"四个字出口的时候，女主在心里给这四个字记了一笔时间戳。她见过"另行"的下场：GH-2201-004 另行跟进的结果是"查无实据"，乔曼约谈周昊的会议记录另行待查的结果是没人查。但她这次没说话。她只是看着记录位上那个妆容完整的人。

乔曼在记。钢笔——不，记录笔，在纸上走得又稳又快，脸上是恰当程度的严肃，像一个尽职的秘书在履行程序。只有女主知道往哪个方向看她：她的耳垂。乔曼戴着一对小珍珠耳钉，人在强撑镇定的时候，耳廓会先于脸红。

耳廓是白的。白得用力。

散会的时候，乔曼收拾记录本的动作用了平时的两倍时间，纸页对齐，笔帽扣好，椅子推回原位——每一个动作都无可挑剔。她走到门口，跟女主擦肩，还点了一下头。

"恭喜沈工。"她说，"清者自清。"

"谢谢。"女主说。

两个人都没有停步。

---

当天下午四点，事情变了。

女主布的哨响了。她自建服务器上的监控脚本从第一天起就盯着那个伪造仓库——不为别的，就为"它还在"这三个字。四点十七分，脚本推送了一条告警：

**trace-mender/heal 仓库已删除（404）。**

她盯着那条告警看了十秒钟，然后做了一件后来被证明价值连城的事：她把告警截图，标上时间戳，存进 monthly-archive-01。

删除来得比她预想的快，但完全合乎逻辑。鉴定报告上午十点拆封，下午四点仓库消失——六个小时的时差，够一个人从"知道结论"走到"决定销毁"，再走到"动手"。这不是慌乱，这是止损。举报已经死了，仓库从"证据"变成了"罪证"——它现在唯一的功能就是等着被查，留着它的人每天都要多担一天心。

删掉，是最理性的选择。

问题是，删掉这个动作本身，也是一次提交。向全世界提交。

---

她五点半把消息告诉温遥，是在楼下的便利店，一人一杯关东煮，隔着热气说话。

"删了。"她说，"下午四点十七。"

温遥的第一反应不是惊讶，是懊恼："我存的是页面快照——鉴定启动那天存的。删除之后，archive.org 那种全站存档服务可能还没爬到它，页面快照只能证明'它存在过'，证明不了它里面的内容——"

"不。"温遥忽然停住，放下杯子，"等等。你等我十分钟。"

她当场掏出手机。女主看着她在屏幕上翻一个相册——不是她平时用的那个相册，是另一个，界面很旧，像是专门用来放某种东西的。翻了大概两分钟，温遥把手机递过来。

屏幕上是一整套截图。按日期分文件夹，每个文件夹命名规范得像工程文档：**11.26 仓库创建当晚 / 11.27 全量 commit 列表 / 11.28 举报信发布后 / 12.05 鉴定启动日**——最后一组是五天前，截图里连 issue #437 那条"穿越"的注释都拍得清清楚楚，一共四十七张，张张带系统状态栏的时间水印。

"鉴定启动那天我就想，"温遥说得很慢，像在解释一件她自己都有点不好意思的事，"第三方只能看到'现在'的仓库。万一哪天它变了、没了，'它原来的样子'就只有截图能作证了。所以那天晚上我把它整个翻了一遍，从第一个 commit 拍到最后一个。"

"你什么时候存的？"女主问。

"十一月二十七号就存了第一批。"温遥说，"就是它刚冒出来那晚。那时候我还不知道它是什么，我只知道——一个不存在的东西突然存在了，而且它冲着你来。冲着你的东西，我都不删。"

便利店的关东煮冒着白气。女主捧着那杯汤，很久没说话。

她自己给"不存在"存过证——11 月 26 日晚上的 404 截图。她存证的角度是"它还不存在"，温遥存证的角度是"它存在过"。一个人的直觉是查案，另一个人的直觉是护人。两套快照拼在一起，这个只活了十九天的假仓库，从出生证明到死亡证明，一份不缺。

"温遥。"她最后说，"你知不知道你手里这四十七张图，是现在全网唯一的完整底片？"

温遥愣了一下，然后笑了，笑意很浅："我不知道。我只知道万一哪天用得上呢——我这个人，别的不会，就是舍不得删东西。"

---

十分钟后她们回到楼上，女主把两套快照合并、打包、加密，存进网盘。做完这一切是六点二十。她给自己定了二十分钟的闹钟，决定到点就下班——这半年她学会的事情不多，"到点下班"是其中一件。

闹钟没响，手机先震了。

是江叙白。一条消息，没有称呼没有铺垫：

**"伪造仓库 404 了你看到了？"**

**"看到了。四点十七删的。"**

对面沉默了两分钟，然后来了一段她没料到的内容：

**"我刚托人查了删除操作的来源。GitHub 的操作日志外部拿不到，但仓库删除会触发一次 webhook 回调，那个仓库创建时挂过一个 CI 钩子——钩子的接收端日志里留了记录。删除请求的发起 IP，归属地是杭州。"**

她盯着"杭州"两个字。

杭州。她的记忆立刻开始检索——不是情绪检索，是时间线检索，这是她查案一年半养成的本能。她打开自己的工作笔记，往后翻。十二月的排班表、会议纪要、周报。翻到第三页，她的手停住了。

**十二月十日—十二日，平台研发部乔曼，杭州客户现场，灰度平台联合评审。**

今天是十二月十二日。

鉴定报告是今天上午十点拆的封。仓库是今天下午四点十七分删的。而删除操作的 IP 归属地，是乔曼此刻出差所在的城市。

她把这三行时间并排抄在笔记本上，一行一行，抄得很慢。抄完，她没有给江叙白回"是谁"，也没有回"怎么办"——她只回了四个字：

**"记下了。"**

对面这次回得很快，只有两个字：

**"嗯。存好。"**

她合上笔记本，关掉工位的灯。窗外，张江的十二月夜色已经落严实了。走向电梯的时候她路过四楼平台研发部，那层楼黑着，负责人出差，办公室提前进入了夜里。

电梯下行，她看着楼层数字一层层地跳，忽然想起下午会议室里那个白得用力的耳廓，想起那句"清者自清"。

清者自清。她当时回的是"谢谢"。

现在她想补一句没说出口的：**乔曼，你删掉的那个仓库，从今晚起，活在四个地方——我的哨、温遥的相册、你的钩子日志，和这座城市到杭州之间一条三点五个小时的高铁线上。**

你销毁证据的动作，成了我们最新的证据。

电梯到一楼，门开了。她把围巾拢上，走进冬夜里。

那一刻她还不知道，"等她再走一步"这句话，六天之后会由一个活人说出来。
