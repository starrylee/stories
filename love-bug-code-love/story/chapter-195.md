# 第一百九十五章 老严的信

二届闭幕后的第九天，一封信寄到了出版社，转给沈见微。

是纸信。牛皮纸信封，钢笔写的地址，贴的邮票。落款是南方的地址——她认得那个地址，去过两次。

老严的信从来手写，从来不超过一页。这封也是一页，字比上次大了一些，笔画之间的间距宽了——他在南方教书这些年，字越写越松。

"见微、叙白：

二届的事，夜枭把纪要发我了。我在办公室看完，又带回家看了一遍。

两件事想说。

第一件。周衡那条'记到第几分钟'，我看了三遍。这条规矩定下来那天，你们这个行业往前挪的，不止是几分钟。我在学校教了这些年书，最深的体会是：**学生不是被讲会的，是被听完的。**一个行业能想明白这一点，比多养十个专家值钱。

第二件。听说你们有一页纸，挂一年，谁想写谁写。这件事办得好。好就好在你们忍得住——**大部分人办一张空纸，忍不了三天就要往上面写东西。**忍不住的人，是把自己看得比纸重。你们把自己放得比纸轻，所以纸上才长得出别人的字。

信不多写。去年说好的，名单在长。今年我数了数，又长了几个。有一个，下个月我带他来上海——到时你们见见。

附：池默那孩子的卡片，我听说了。替我带句话给他：卡片写得比我当年的报告好。让他接着写。写满一墙的时候，来学校讲一堂课——题目我给他留好了。

严"

她把信读了三遍。第三遍读到"有一个，下个月我带他来上海"的时候，停了一下。

老严的"名单在长"她听了四年。名单上的人她大多见过——池默、周衡、陈序，还有一个她没见过的，是老严念叨过几次的"第四个学生"：档案钩子挂了几年，老严只说过一句话——"他还没出师，不急。"

信里这个"又长了几个"里的一个，是新的，还是那个？

她不知道。她发现自己居然没有想查——搁在三年前，这个钩子能让她翻一晚上通讯录。现在她只是把信折好，放进"慢线"的牛皮纸袋，压在 CH 的邮件、一九九九的申请、那张空线纸条上面。

袋子越来越厚了。她掂了掂。

---

带话这件事，她当真去办了。

池默那边不好联系——他没有微信，铺子的座机只在营业时间有人接。她打过去，铃响了很久，接电话的就是他本人。

"是我。"她说，"老严让我带句话。"

那头安静着，像是在等。

"他说，你卡片写得比他当年的报告好。让你接着写。写满一墙的时候，去学校讲一堂课——题目他给你留好了。"

电话那头安静了很久。久到她以为信号断了。然后池默开口，声音跟平时一样平：

"墙满不了。"他说，"软木板就那么大。"

"换个大的。"她说，"老严的意思，是接着写，不是写满。"

那头又安静了一会儿。

"带句话回去。"他说，"课我到时候去讲。**但题目别让他留——我自己出。**"他顿了顿，"我那间铺子开了九年，名字是我自己起的。这次也一样。"

她说好。

挂电话之前，池默忽然多说了一句，不在任何话头里：

"这两天有个事儿，说给你听。"他说，"上礼拜有个客人来修手机，四十来岁，外地口音。修完了不走，在我那面卡片墙前面站着，看了得有十分钟。看完问我：'这些卡片，最早的写了几年了？'我说九年。他说——"

池默在电话里停了一下，像在回忆原话。

"他说：'**那我这本账，比你的还老。**'说完就走了。手机修好了，钱付的现金。"

"你记住他了吗？"

"记不住。"池默说，"外地口音，长的样子我没细看。我就是觉得这话奇怪——**什么账，能比九年还老，还拿到我这么个小铺子门口来说。**"

她握着电话，站在自家书房的窗前，看着楼下的街。

窗外没什么人。一辆收废品的三轮车慢慢骑过去，车斗里的旧纸箱颠了一下。

"池默，"她说，"下次他再来，别问他是谁。"

"那问什么？"

"什么都不问。"她说，"他要再说这种话，你就说：**账再老，也是今天来对。**"
