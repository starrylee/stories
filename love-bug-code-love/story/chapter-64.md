# 第六十四章 想收购的人

年后的第一个工作周，事情正式摆上了台面。

顾时帆把经过讲得很清楚：灵犀战略投资部的一个人，年前通过 shiguang 项目的企业合作邮箱找过来，年后第二周约了线上会。"规格不低，对面来的是投资部一个执行董事，姓岑。开场十分钟全在聊技术——问到补标仲裁模块的设计取舍，问得很内行。我还以为遇上了懂行的。"

"然后呢？"

"然后话锋一转，谈收购。"顾时帆在视频那头摊手，"方案有两版。第一版，收购项目的商标和治理权，给一笔钱，承诺投入资源共建；第二版——"他顿了顿，脸上浮出那种"我念给你听你自己品"的表情，"第二版的标题叫'人才收购'。收购的不是项目，是**人**。"

"人？"

"他们点名要我。"顾时帆说，"条件开得很漂亮：职级、薪资翻倍、项目并入灵犀云产品线、我带自己的方向。原话是——'项目只有跟着创造它的人，才有生命力'。"

女主坐在会议室里，视频窗在笔记本右上角，她的表情没有变化，但握着鼠标的手收紧了。

"你怎么回的？"

"我说我考虑考虑。"顾时帆说，"我没敢直接拒——他们打听得太细了。小微，你知道他们连我现在的职级和绩效档都摸清楚了吗？谈判桌上的人不会做功课做到这个份上，除非——"他停住，看着她，"除非这不是生意。"

不是生意。

女主沉默地关掉了共享屏幕上的报价文档，脑子里各条线路在一瞬间并了起来。开源罗生门那场仗里她学过一件事：**当一个动作在商业上说不通的时候，它的真实动机一定在商业之外。**

灵犀战略投资部。霍振声的条线。一个开源项目——哪怕按他们自己尽调报告的估值口径，也只是一家上市公司体量下可以忽略不计的小标的。可他们派执行董事、做足功课、开出翻倍的价——为什么？

答案在她心里跳出来的时候，几乎是烫的：

**因为 shiguang 的作者名单上，有一个"沈见微"。**

不，不对。她纠正自己——顾时帆是主维护人，她是早期贡献者之一，贡献记录公开可查。而她的 ID 和她的真名之间的映射关系，经过"学历罗生门"那场舆论战，如今在行业内已经是半公开的秘密。灵犀的战略投资部只要做过最基础的功课，就会知道：想收 shiguang，绕不开一个名字。

想收的不是项目，不是顾时帆。

是**围着她转的那张网**。她开源底座的技术声誉、她行业里的名字、她大学时代就织起的人脉——收进灵犀的编制里，就是收进霍振声的棋盘上。一颗棋子最安全的处理方式，不是吃掉它，是**请它入局，然后让它变成自己人**。

她忽然想起江叙白转给过她的一句话——那是乔曼向秦立群递投名状之后，霍振声在电话里说过的："让所有技术权力住进同一个笼子。"

技术权力。开源项目的作者、社区的核心贡献者、行业里被引用的名字——这些在霍振声的世界观里，全都是"技术权力"，全都是要么为己所用、要么成为变数的东西。

"顾时帆，"她开口，声音很稳，"两个问题。第一，他们提没提过我的名字？"

视频那头安静了一秒。"……提了。"他说，"岑董事最后问了一句：'听说项目的早期核心贡献者目前在灵犀任职？我们希望这次合作能把双方的缘分续上。'原话。"

"第二个问题。这份收购意向，公司内部现在有多少人知道？"

"按流程，战略投资部的项目要走内部会签。"顾时帆皱眉，"你问这个干嘛？"

"因为我想知道，"她一字一字地说，"这件事，多久会变成**打我的棍子**。"

---

答案是一周。

一周后的周二上午，她的直线组长、攻坚组的张组长，把她叫进了小会议室。组长的表情很不自然，那种"我被人授意来办一件事、但我自己都觉得这事不体面"的不自然。

"小沈，有个事，按流程跟你通个气。"组长斟酌着用词，"技术合规委员会那边转过来一个'利益冲突提示'——说你在职期间，是外部开源项目 shiguang 的核心贡献者，而这个项目正在与我司战略投资部进行收购洽谈。委员会提示：存在'员工外部技术资产与公司交易潜在关联'的情形，要求你——"

组长念到这儿，停了一下，像是在斟酌要不要念完。最后还是念了：

"——要求你签署一份《外部技术利益申报与回避承诺书》，申报你在该项目中的全部权益，并承诺在收购洽谈期间，不参与、不干预、不向外部泄露任何相关信息。"

女主坐在那里，很仔细地听完了每一个字。

每一个字单拎出来都合规。申报，合规；回避，合规；保密，合规。可是把这些字连起来，再放到时间线上——她瞬间看穿了这套组合拳的真正用途：

收购 shiguang 的谈判桌上，灵犀是买方。而她，作为项目核心贡献者，本应是谈判中被征询意见的一方——她的态度、她的授权、她对项目治理权转让的立场，直接影响交易的成色。可是这份《承诺书》一旦签下去，她就在制度上被**拔掉了嘴**：不参与、不干预、不泄露。

剩下谁在谈判桌上代表"项目方利益"？只剩顾时帆一个人，独自面对一家上市公司的投资部。

而这还不是最狠的。最狠的是——

"组长，"她问，"这份提示函，发起方是谁？"

组长的眼神飘了一下。签发流程他都清楚，但这个问题他显然不想答。女主替他把答案说了出来："技术合规委员会的日常事务，经手人是谁？"

会议室安静了几秒钟。

"……秘书处。"组长最后说，声音低了下去，"但是小沈，程序上没有毛病，我挑不出来。你自己也挑不出来。函我看过了，每一个字都在章程里。"

"我知道。"她说，"我签。"

组长愣了："你——"

"我签。"她重复了一遍，语气平静，"申报的部分，我会申报得比他们想要的更完整——我的贡献记录、时间线、全部公开可查，我一行都不会少写。至于回避和保密，"她顿了顿，"我本来也没打算通过公司的渠道去干预什么。"

她说的是实话，而且是双层的实话。签这份承诺书，确实是合规；但更重要的原因是——她瞬间明白了乔曼把这份函推过来的用意：**用公司的制度捆住她的手，让她在谈判里发不出声音。**

那她就顺着这个捆法，把手收到桌子底下。

桌子底下的手，可以做的动作，比桌子上面多得多。

---

当天晚上，她把整件事讲给了江叙白——在五楼他办公室，门关着。

江叙白听完，很久没说话。钢笔在指间转着，转得比平时慢。

"岑敬儒。"他终于开口，说出了一个名字，"投资部执行董事，岑敬儒。这个人不归秦立群管，他的汇报线直接通到董事会投资委员会——那一条线，只有一个人说话算数。"

"霍振声。"

"霍振声。"他确认，"我查过岑敬儒近两年经手的案子。一个规律：**他只做'人'的生意。**他投的每一个标的，交割条款里都有创始团队绑定条款——三年锁定期、竞业限制、期权换控制权。别的人收项目是买资产，他收项目是**收编活人**。霍振声把他放在这个位置上，就是让他替自己把行业里有名字的年轻技术人，一个一个变成'自己人'。"

他停下笔，看着她。

"沈见微，你现在明白这件事的量级了吗？这不是乔曼能策划的局。乔曼推那份提示函，是顺水推舟——她顶多看见了'用制度堵你嘴'的机会。但整个收购的盘子，从岑敬儒找上顾时帆、到点名要人、到'把缘分续上'——这是一张从更上面撒下来的网。"

"网要收的是什么？"

"你。"他说得毫不迟疑，"确切地说，是所有'在行业里开始有名字、又不肯进任何一张棋盘'的年轻人。你是这类人里现在最显眼的一个——罗生门那一场，你的名字在全行业面前过了一遍水。对霍振声那样的人来说，过完水还站着的鱼，是最好的鱼。"

办公室的灯很亮。女主坐在椅子上，忽然笑了一下，笑意很冷。

"他要收编我。"她说，"所以先收我大学时最好的战友，再捆住我在谈判桌上的嘴，然后等我自己走进'人才收购'的笼子——理由都想好了：为了项目的生命力。"

她站起来，走到窗边。楼下，夜里的园区安安静静，一家正在冲刺上市的公司灯火通明。

"那他大概不知道两件事。"她说，"第一，shiguang 那个项目，47 个 star 起家，从收光的那晚开始，就没打算卖给任何一个'懂监控的人'。"

"第二呢？"

她回过头。

"第二，"她说，"他挑错了要收编的时点。我在他公司里——离他的棋盘越近的地方，看得越清楚。他不知道他现在撒网捞的这条鱼，已经在他自家的池塘里，摸了两年的底了。"

江叙白看着她，看了两三秒，忽然把笔放下了。

"说得好。"他说，语气里有种罕见的、不加掩饰的东西，"那就让他捞。等他收网那天——"

他没说完。但两个人都知道后半句。

等他收网那天，会发现自己捞上来的不是一条鱼。是一个已经在网上剪了很多个月的人，带着剪刀，等着他呢。
