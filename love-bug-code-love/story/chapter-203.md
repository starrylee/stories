# 第二百零三章 新纸第一行

三届开幕那天，天气晴。

新签到纸挂了七个月，第一行一直空着。青梧每天拍档，档存了两百多张——同一个角度，同一页白纸，空了两百多天。夜枭偶尔开玩笑，说这是全行业被拍得最多的一张空纸。

开幕日上午九点四十，第一行落了笔。

写的人是个快递员。

不是参会代表。他来送一批会议资料，出版社的收发让他送到展厅，送到之后等签收，等的时候站在签到处边上。他看了看那页纸——挂了七个月、被两百多张档拍过的白纸——又看了看笔。然后他问青梧："这纸……我能写吗？"

"能。"青梧说，"写什么都行。"

他写了。写得很慢，字不算好看，一笔一画都用了力。写完他没多停留，签收单交了，走了。资料搬上车的时候，他跟同伴说了句什么，同伴笑了，他也笑了，车开走了。

第一行写的是：

"**送了五年快递，头一回有人让我在纸上留句话。**"

青梧拍完档，把照片发到筹备组群里，配了一句话："第一行不是我们的人。**第一行是路过的人。**"

温遥回了三个字："对了。"

---

上午的议程是开幕式和条款年度报告。报告念到"打断署名条款落地统计"那一节，全场安静了几秒——这一年内，自愿备案试行该条款的机构，从年初的五家变成了四十一家；试行机构里被记录在案的打断，一共一千九百多次；**一千九百多个名字里，职位最高的一个，是一家银行的副行长。**

温遥念完统计，合上稿子，加了一句不在稿上的话：

"有人问我，这条规矩推行一年，行业变好了没有。我说我不知道——行业是个太大的东西，一年量不出来。但有一件小事量得出来：**一千九百多次打断，每一次都有了名字。**变好这件事，是从有名字开始的。"

下午两点，自由陈述。

会场坐了三百多人。周衡第一个上台。他还是那件退休协会的深蓝夹克，没拿稿子——他今年讲的是那台收音机。三分钟讲完收音机的前主人：一个去世了两年的独居老人，收音机是他老伴的遗物，老伴走后他把它搬进地窖，不是怕坏，是"开着它，屋里就显得还有人"。讲到最后，周衡说：

"池师傅把收音机修好了。修得好喇叭，修不好地窖。**我带它来，不是讲它坏过——是讲它现在天天响着。**"他从讲台底下把那台木壳收音机搬上来，摆在台中央，打开，调了台。

戏曲频道咿咿呀呀地响了起来。

台下一片安静。三百多人，听着一段不知名的戏。周衡站在收音机旁边，五分钟用完了，他没再说话，就站着，陪着它。

温遥没催。全场没人催。戏文唱完一整段，周衡才把收音机关上，鞠躬，下台。

第二个是"停机两小时"。

他上台的时候，沈见微在第一排坐直了。

四十多岁，中等个子，灰色夹克，走上台不快不慢。他不紧张——或者说，他把紧张用掉了，用在别处：他的手在裤缝上按了一下，按完就不动了。他开口第一句：

"我的故障，讲之前先报参数。"他说，"发生时间：三十一年前。持续：十五分钟。后果：一条生命。**归档定性：技术性中断。**"

台下的呼吸声轻了一层。

"那年我是热力公司的值班调度。冬天，凌晨，锅炉房的一个压力报警响了。规程要求：报警确认之前，锅炉降负荷运行。我打了电话下去，锅炉房值班的老师傅说，是表的问题，他见过这毛病，**不用降。**"

"我讲了三分钟，讲为什么要降。他听了三分钟。然后我讲到第四分钟，车间主任的电话插了进来——他在另一条线上等着，他说：'小张你听着，今晚供暖是政治任务，降了负荷全城要骂街。表的问题老李看过了，就这样，执行。'"

他停了一下。

"我执行了。没降。"他说，"第七分钟，我把没讲完的那几句话，写进了值班记录。**记录里的原话是：'建议降负荷运行，待查表计。'——就九个字。**我本来还要写'若非表计故障，十五分钟内需泄压处置'。这句话写到一半，主任的电话又来了，问记录写完没有。我说写完了。"

"第十一分钟，压力表回零。第十四分钟，爆管。"他说，"老李，锅炉房的老师傅——他当时就站在管子旁边。"

会场上静得能听见空调的风。

"事后调查四个月。我的九个字救了我——'建议降负荷'，白纸黑字，责任定不到我头上。老李走了，定性里没有他的名字，他连'被问责'的资格都没有——**他是'设备故障的受害者'。**那十五分钟的调查结论，你们已经听见了：技术性中断。**中断的不是技术。是我那半句话。**"

他看了一眼台下，从第一排看到最后一排。

"我今年五十八。三十一年，我每个冬天都把那半句话背一遍。"他说，"今天五分钟，我把背的讲完了。后半句是——"

他一个字一个字地补出来：

"**'若非表计故障，十五分钟内需泄压处置。泄压口在东墙，人员须撤离至西向掩体。'**"

"老李当时站的位置，"他说，"在西向掩体的门边上。**差半句话，他退一步，就在门里。**"

他停住。五分钟早到了。温遥看了一眼计时牌，又看了一眼沈见微。

沈见微站了起来。

"时间到。"她说。她说得很稳。"按规矩，打断要署名——打断人：沈见微。**记入纪要。**"

"停机两小时"看着她，看了两秒，点了点头。他没再说一个字，鞠躬，下台。

台上空了。计时牌的红字还亮着。三百多人坐在下面，很久没有人动。
