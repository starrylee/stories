# 第一百一十一章 召回

隧道出来之后，她做的第一件事是回拨温遥。

没接。第二遍，没接。第三遍，通了三秒，被挂断——紧接着一条消息进来：

"在开会。别打电话。看邮件——公司邮箱，你名下，周日晚上的。看完就懂了。高铁上别睡，看好自己的东西。到了直接来公司，别回家。"

三条消息，间隔一共不到十秒。打字的手是抖的，还是赶的，分不出来。

沈见微坐在车窗边，深吸了一口气，打开了手机上的邮箱客户端。

邮箱是她休假期间的状态：收件箱里躺着十一封未读。她按时间倒序扫标题——最后到的那封是两小时前的，全员通报，标题让她指尖一紧：**《关于今日部分域名解析异常的情况通报（一）》**。再往前，是几封常规的例会通知。再往前，周日晚上十一点零四分，一封：

**【变更确认】W-041 批次执行前确认单（含代理执行项清单）**

她点开。

邮件正文是一张确认单。批次信息，窗口时间，执行项清单。她的目光从第一行开始走，走得很快——工程师读这种表格的速度，是多年练出来的"扫异常"模式：跳过所有正常的，只在不对的地方停。

第一行到第二十六行，正常。

第二十七行。

**"共享域遗留项·参数段同步补执行——执行人：沈见微（休假代执行）；实际操作人：老涂；依据：值班制度第七章第 3 条。"**

列车正在过一段弯道，车身轻轻地晃。她盯着那一行字，一动不动。

她知道自己此刻的表情在变——从"读邮件"变成"读案卷"。邻座的大叔从手机上抬起头看了她一眼，又默默把头低回去了。人有一种本能：能识别出旁边的人"最好别打扰"的那种气场。

执行人：沈见微（休假代执行）。

她的第一反应不是恐慌，是一种冰冷的、熟悉的职业性错愕——像她在代码评审里看见一段自己从没写过、却署着她名字的提交。**这行字在逻辑上不成立**：她休假了，她没有"需要被代执行"的常规操作——她的岗位在攻坚组，不在平台侧；配置治理二期的变更，从业务归属上跟她没有执行关系；所谓"同步补执行"，她此前从未被告知、未被征询、没有签过任何代理预设。

代执行机制她懂——制度第七章，保护休假工程师的善意设计。但机制有一个前提：**被挂载的操作，必须是"本来就该你执行的"。**一个跟她毫无执行关系的变更，挂到她名下——这不是机制的误用。

这是机制的**盗用**。

她把那封邮件又读了一遍。第二遍读的是邮件的生成逻辑：系统什么时候发出的？周日 17:22——在她休假开始的代理切换生效之后。发给谁的？她——但代理接收人是温遥，所以温遥那边同时收到并归了档。抄送栏里还有谁？变更平台的存档系统，和——

她看清了抄送栏的最后一个地址，胃里沉了一下。

**技术治理·双牵头工作台账。**

一个自动化的抄送组地址。乔曼和江叙白，作为双牵头，这个台账他们都能看到。乔曼能看到——这不奇怪，她的排期她当然知道。**江叙白也能看到。**

那么昨晚，窗口执行的时候，他看到了这封确认单吗？他盯了六个屏幕，二十七行全绿——他有没有看见第二十七行挂着的名字？

她给江叙白发消息。手指打字的速度太快，第一遍打错了两个字，删掉重打：

"第二十七行。我的名字。你看到执行人是谁了吗。"

发送。

消息下面，一个小小的"送达"。

然后她等。列车报站，停两分钟，再开。窗外的天色从下午转向傍晚——五个小时的车程，她已经在车上三个小时。她盯着那个对话框，盯着"送达"两个字旁边，等待"已读"跳出来。

没跳。

一分钟。五分钟。十分钟。

**未读。**

这个人，在她发出"第二十七行，我的名字"这种级别的消息十分钟之后，未读。

沈见微靠回椅背，脑子里飞快地过了一遍他此刻可能的行踪：监控室？他如果在监控告警一线，手机会响——他为了盯告警，手机永远不静音。会议？什么样的会能让他两个小时不看手机——她想起来：今天下午，**董事会。**上市前最后一次全体董事会议，T-4 的最后事项汇报，程亦朗上周就跟她提过，技术条线要出人列席讲解静默期方案——出的人，是他。

董事会上手机静音。汇报的人，两个小时，看不见外面的世界。

而外面的世界，正在塌。

她切回全员通报那封邮件，仔细读了正文。通报的措辞是那种让她太阳穴突突跳的熟悉配方：

"今日上午九时起，部分用户反馈域名访问异常……经排查，初步判断为网络波动……各条线正在排查……请勿对外传播不实信息……"

部分。波动。不实信息。

她太知道这四个词的分量了。这是"还没查到"的官方同义词。而她比写通报的人多知道一样东西——她知道周日晚上有一份变更确认单，知道那单子上有两个参数段的名字。她从收藏里调出周日晚上——不对，是她出发前和他聊过的记忆：他提过，第二十七行同步了二十三段，超出预期，加了人工巡检。**他自己都觉得不对，加了巡检。**

现在，巡检的期限还没到，异常已经开始了。

时间线在她脑子里自己咬合上了——不是推理，是她做了四年的那种本能：**变更在周日 23:00 出口，异常在周二上午开始，中间隔的不是巧合，是 TTL。缓存到期，逐批失效——这解释了"部分"：先到期的先倒，像多米诺，骨牌正在一张一张翻。**

而牌的起点，在配置中心那两个被"归位"的参数段里。

一个叫 dns-authoritative-resolver——她不用猜都知道那是什么。另一个，kms-reference-routing——加密服务的路由。

DNS。密钥。

她的手指冰凉。

DNS 意味着什么，全公司每个人都懂。KMS 意味着什么——懂的人不多，她是懂的少数：**密钥路由失效，所有依赖加密的服务会在缓存耗尽后开始窒息。而在一家公司里，深夜里还在默默运行、并且依赖密钥的例行任务，数量最多的那一类，叫备份。**

她不敢往下想了。

列车广播响起：前方到站，终点站。

---

上海，傍晚六点半。

出租车直接开往公司。晚高峰的路上，她把周日晚上的全部流程在脑子里又过了一遍——每一遍，第二十七行那几个字都变得更重一点：

休假代执行。

她想起来，轮休名单是周日下午才发的。名单发出之前，她没有任何休假的安排——她是被排进"第一批"的。排她进去的理由冠冕堂皇：一号位优先休整。

名单发出来两个小时之后，那份确认单就挂上了她的名字。

**名单和确认单，间隔两小时。**

不是巧合。这是排期。她的休假不是被安排的——**是被需要**的。有人需要她"不在场"，需要她"名下挂载"，需要她在异常爆发的时候，人在三百公里外的一趟高铁上，手机里躺着一封她"已经收到过"的确认邮件。

她在出租车后排，握着手机的手指关节发白。

倒不是怕。怕这个东西，四年前就消耗完了。此刻在她胸腔里烧着的是另一种东西——一种混合了愤怒和后怕的、极冷的东西：**她四年攒下的每一个"问号"，此刻正在从纸上站起来，变成活的东西。**

她想起那张拓扑图。想起"缺的是同一块"。想起他们最坏的判断——绩效造假级别的丑闻。

**他们想小了。**

车窗外，公司的楼群出现在视野尽头。研发楼的灯亮着，看起来和每一个加班的傍晚没有区别——但她知道，此刻那栋楼里的某几层，正在为一个他们还没找到源头的故障，把所有的人往回召集。

手机震了。她低头看——是她给他发的那条消息下面，状态终于跳了。

不是"已读"。

是一条新消息，发件人不是他。是温遥：

"看到你上车了。直接来战情室。**别去工位，别开电脑，别碰评审系统。**到了给我发消息，我在门口等你。"

三条禁令。

沈见微盯着那三条禁令，在出租车里坐了整整五秒钟，才明白它们合在一起的意思——

温遥在告诉她：从现在开始，你做的每一个动作，都可能变成别人手里的东西。

战要打了。

而且这一次，敌人先画好了她的位置。
