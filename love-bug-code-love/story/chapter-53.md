# 第五十三章 举报信

正式的核查约谈，安排在周五上午十点，四楼那间双人小会议室——还是那间。纸巾盒换了新的一盒，还是放在老位置。

这次屋里坐了三个人：HRBP，法务部的一个年轻律师，还有技术合规委员会秘书处的一位干事——干事是来"记录流程"的，笔记本摊开，态度职业，全程只抬头看她。这个配置本身就是一份说明书：举报信既然引用了内部数据，核查就得有"流程合规"的见证，而"流程合规"的见证人来自秘书处。

秘书处。沈见微进门的时候看了一眼那位干事的工牌，名字不认识，工牌下缘的部门条印着"技术合规委员会·秘书处"。她不知道这位干事头顶的汇报线通向哪里，她只知道一件事：从今天早上开始，这场核查的每一份流程文档，都会经过一个文件夹——秘书处的归口。

约谈持续了五十分钟。问题沿着一个精心设计的坡度往下走，走了三层。

第一层是事实层："你的开源项目，核心模块的参考来源是什么？开发过程中是否借鉴过其他项目？"——这一层她答得很顺：借鉴过，都标了。开源社区的规矩本来就是站在彼此的肩膀上，依赖声明、来源注释、致谢清单，她的仓库里一样不缺。

第二层是时间层："境外项目 X 的对应模块发布于前年三月，你的提交在前年九月。这个时间关系，你如何解释？"——她答：时间先后不构成抄袭因果，"两个项目依赖同一个更早的底层库，相似的部分来自那个底层库，双方都标注了"。这一层开始硌人了：提问的人不在乎她的解释，提问的人在乎把"前年三月"和"前年九月"这两个时间点，钉进记录里。

第三层，是原罪层。

"见微，你的录用属于破格通道。"法务律师翻着材料，语气公允得像在念天气预报，"破格的依据是你这个项目的原创性和影响力。所以这封举报信的核心关切其实是——**如果项目的原创性存疑，那么录用依据、此后的绩效评价、技术评优的提名，整条资格链都需要重估。**你理解这一点，对吗？"

会议室里安静了两秒。

"我理解。"沈见微说，"所以我会配合核查——而且我会比核查组更积极。因为这条资格链是我的，链上每一环怎么打的扣，我最清楚。"

"另外，"她顿了顿，看着桌上那封举报信的复印件，补了一句，"贵方的核查如果只查我，是查不完这封信的。这封信指控的不是我抄袭了谁——它指控我被错了地方。**查信本身，和查我，是两条线。**我建议两条都走。"

律师抬头看了她一眼。HRBP 在记录本上飞快地写了一行字。

约谈结束，她在流程确认单上签了名。签名的时候她注意到，确认单的最下面有一行小字：**"本约谈记录归档路径：技术合规委员会秘书处-年度评优核查-001。"**

秘书处。归口。归档。

她把笔帽合上，笑了笑——在流程的世界里，连"被举报"这件事，也有它安静的、编号齐全的保存位置。这个系统的每一层设计都在告诉她同一件事：**你经过的每一步，都有人在看。**

至于看的人是谁——这就是另一个问题了。

---

当天下午，她请了半天假，回家。

不是躲。是干活。核查组的节奏她左右不了，但自己的证据链，她可以先把地基打穿。

书桌清理干净，电脑接上电源，三个屏幕：左边开着她自己的开源仓库，中间开着那封举报信的扫描件，右边是浏览器。

她从举报信里把"证据"一样一样摘出来。信里附了一个"证据附录"，列了三样东西：

**第一样：境外项目的仓库地址。**名字她此前闻所未闻——这不奇怪，开源世界几千万个仓库，没人全知道。名字起得很像样：`trace-mender/heal`，看描述是做"链路追踪的自愈修复"的，方向跟她的模块撞得严丝合缝。

**第二样：两组 commit 编号。**信里说，境外项目的核心算法提交于"前年三月十四日"，编号 3f9a2c1；她仓库里对应功能的提交编号 8e4d17b，时间前年九月。两个 hash 并排列着，配上精确到日的时间，看上去证据感十足。

**第三样：两段代码的对照。**左边一段引自"境外项目"，右边一段引自她的仓库，相似度确实很高——高到任何不懂技术的人一眼看去，就是"抄了"。

她开始逐项验证。

浏览器里输入那个仓库地址。页面转了一圈，跳出来一行字：

**404 — This is not the web page you are looking for.**

她愣了一下。刷新。还是 404。

换搜索引擎，搜仓库名。搜"trace-mender heal"。搜"trace-mender github"。翻了五页结果——没有这个仓库。搜它声称的技术方向加上各种关键词组合，出来一堆别的项目，没有一个叫这个名字。

再验证 commit。GitHub 的 commit 是全站唯一的——任何一个真实存在过的 commit，哪怕仓库删了，只要被任何人的 fork、任何人的引用、任何一条 archived 记录碰到过，都可能留下痕迹。她把那个 hash `3f9a2c1` 扔进搜索，扔进两个第三方的 commit 检索服务——

**无结果。**

这个编号，在任何索引、任何缓存、任何归档里，都不存在。

她靠在椅背上，盯着中间屏幕上那封举报信，看了很久。

然后她做了第三项验证——也是最狠的一项。信里"引用"的境外项目那两段代码，她把第一行扔进了自己仓库的全文搜索。

**命中了。**

那段被标注为"引自境外项目、提交于前年三月"的代码，一个字符不差，来自她自己的仓库——出自她前年九月的一个 commit。那行代码里有一个她至今记得的小习惯：行尾注释写的是"// prevent duplicated healing"——healing 这个词，全世界的开源项目里没人这么用，是她当年从自己一次失败的重试逻辑里攒出来的私人语感。

**信里引用的"原始项目"，是用她的代码伪造的。**

时间标在前年三月，内容来自她的九月。**证据的时间戳，比证据的内容年轻。**这就好比有人拿着一张翻拍的照片指认原作抄袭了翻拍——照片可以伪造底片，但底片伪造不出原作的笔触。

查无此库。

她把这个结论在心里放了十分钟，放稳了，才开始想它的引申义。

引申义有三层。

第一层：这封举报信的"证据"是彻头彻尾的伪造——这一点对她有利，但有利得危险，因为——

第二层：伪造者不会想不到她会去查。一个能把内部提交数据、外部时间线、空主语话术组织成九段的人，不可能漏算"被指控者第一时间检索原始仓库"这个动作。**伪造者算到了 404。**那么 404 就是设计的一部分：信先发，仓库后到。等指控的种子在人群里发芽，等"听说她抄袭"成为既定印象，那个仓库会"出现"的——带着逼真的提交历史，带着"前年三月"的时间戳，带着全部两段对照代码。到那时候，再有人去查，就查得到了。**指控先行，证据后置——这是和时间打的一个时间差。**

第三层，是最冷的一层：这个战场不在公司内网了。工单、评审、变更、门禁——她这一年的所有仗都打在一堵内网防火墙里面，墙内的一切至少归同一个系统管。而伪造一个 GitHub 仓库这件事，发生在墙外。墙外的世界没有她的工牌，没有她的权限，没有技术委员会，没有归档令——**技术作恶第一次跳出了公司内网，跳进了一个她的所有工具都够不着的开放平台。**

墙外的规则她不是没有——墙外有它自己的规则：git 的对象模型、提交历史的数学、互联网存档的时间线。只是这些规则，得用另一种方式调用。

她坐直了，开始干活。

第一步，给"不存在"存证。这四个字在一般人听来像悖论——不存在的东西怎么存证？但她做起来行云流水：她对 404 页面截图，带时间；她用第三方存档服务，把"检索 trace-mender 无结果"的搜索结果页抓了快照，带时间戳；她把 commit 检索服务的"无结果"页面也存了。三份"不存在的证据"，每一份都带着公证级的时间。**今天的不存在，就是明天的铁证**——等那个仓库出现，这些快照就是"仓库创建于指控之后"的间接证明。 absence，也会说话。

第二步，布哨。她写了一个监控脚本：每隔十分钟检索一次那个仓库名和那段代码的第一行；关键词命中即通知。脚本部署在她自己的服务器上——不经过任何公司的系统。这是她入职以来第一次，把武器库从公司的地基上，搬了一块到自己的地上。

第三步，回溯。她把自己仓库里与"信中引用"相关的全部提交历史导出来，连同依赖声明、来源标注、和那个底层库的公开仓库一起，打成了一份完整的时间证据包。证据包的封面上她写了一行说明：

**"本包证明两件事：一，我的代码从哪里来；二，'原始项目'从哪里来——它从我的代码来。"**

---

晚上八点，监控脚本安安静静，一次都没响。

她泡了杯面，吃到一半，门铃响了。

是温遥，拎着一袋橘子，进门先环视了一圈她的"作战室"——三个屏幕、贴在墙上的时间线草稿、和一碗吃了一半的泡面。温遥把橘子放下，叹了口气：

"我就知道。核查组按流程走要两周，你打算这两天自己把案破了。"

"没打算破案。"沈见微吸了一口面，"打算抢时间。对方在等一个东西出现，我要在它出现之前，把'它还没出现'钉死。"

温遥没太听懂这句话的技术含义，但她听懂了另一件事——她朋友的状态。她剥了个橘子，掰了一半递过去，忽然说："微微，我问你个问题，你别多心。"

"嗯。"

"这次的事，你怕吗？"

沈见微接过橘子，想了想，认真地答了：

"上一仗打完的时候我跟自己说过，下次它再伸手，我能预判。"她说，"但这次伸手的方式我没预判到——它没伸向我的现在，它伸向了我的过去。我的过去是我最没设防的地方，因为过去没法加固——十九岁写的代码，没法回到十九岁去多加一层防御。"

她顿了顿，掰了一瓣橘子放进嘴里。

"但是温遥，"她说，"我不怕。因为过去有一件事是现在的任何手段都伪造不了的——**时间本身。**那个伪造的人可以伪造时间戳，可以伪造提交历史，可以伪造一整个仓库。但他伪造不了三年里真实的几十万个对象、几百个贡献者的交叉记忆、和整个开源社区在这个项目上留下的所有真实的痕迹。伪造是一条线，真实是一张网。一条线做得再像，也盖不住一张网。"

温遥看着她，看了很久，把手里那半个橘子放下了。

"行。"她说，"你都不怕，我怕什么。我就是来送橘子的——顺便告诉你两件事。第一件，公司里现在的风向：骂帖子的、看热闹的、替你说话的都有，班底那几个人都快炸了，周昊今天在群里发了三百字长文，被人截图传出去了，标题起的是《我知道的见微》。林霜把自己朋友圈那条'官宣'置顶了，配文改成了'我认识的沈见微，配得上她得到的一切'。"

"第二件事呢？"

温遥的声音低了下去："第二件——有人看见五楼的灯，昨晚亮到两点。今晚，现在这个时刻，还亮着。"

沈见微握着那半个橘子，半天没说话。

"我不问你们聊什么。"温遥站起来拎包，走到门口，回头，"我就带一句话回去——不是你让我带的，是我自己想说的：**墙外的事，谁也帮不上太多忙，这一仗你得自己打。但墙内的灯亮着，你随时回头，都能看见。**"

门关上了。作战室重新安静下来。三个屏幕的光照着桌面，照着那袋橘子，照着墙上手写的时间线。

十一点四十分，她洗漱完毕，准备睡前最后看一眼监控——

屏幕右下角，脚本的通知栏，跳出了一个红色的提示。

**关键词命中：trace-mender。**

她的睡意瞬间散了。她坐回桌前，点开通知——检索结果的页面上，一个崭新的仓库出现在了列表里：

**trace-mender/heal — "Self-healing for distributed trace pipelines"**

创建时间：今天，晚上十一点零六分。

**它来了。**

在举报信发出后的第三天深夜，在指控已经传遍公司、在核查组已经立案、在她所有的"不存在"快照都拍完之后——

它踩着她算过的那个时间差，来了。
