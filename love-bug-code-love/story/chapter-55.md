# 第五十五章 内部代号

周五上午十点的技术委员会，开在五楼的大会议室。

到场的阵容比平时齐：委员会的七位委员来了六位，法务来了一个人，HRBP 坐在角落里做记录，秘书处的干事占了长桌末端的位置——技术秘书乔曼本人坐在干事旁边，面前的笔记本开着，姿态是标准的"流程记录员"。

沈见微作为当事人列席前半场。她进门的时候，目光从长桌两侧扫过去，在乔曼脸上停了不到半秒——三个月来第一次，两个人在同一间会议室里，隔着一张桌子，一个坐在被审查的位置上，一个坐在记录流程的位置上。

乔曼朝她点了点头，微笑，职业，得体。微笑的弧度和十一月那次走廊相遇时分毫不差。

会议的前四十分钟是她的。她把证据包过了一遍：举报信的九段结构、查无此库的三重验证、伪造仓库的三刀验尸——API 时间戳、issue #437 的穿越、不可能的合并。最后是那七个字符。

"伪造仓库的初始化提交里，作者邮箱是 u237114@163.com。"她把投屏停在最后一页，"u 加六位数字，是灵犀内部系统的账号格式——工单、门禁、评审、终端登录，全部是这个格式。我不知道 u237114 是谁，HR 系统里工号和姓名的对应关系我查不到。但格式本身就是结论：**伪造者的 git 默认配置里，填的是这家公司的内部账号。**"

她关掉投屏："我的部分完了。接下来的问题是委员会的问题——举报信的'证据'被证明是伪造的，那么这封匿名信的性质，就从'举报'变成了'构陷'。构陷发生在这栋楼里。"

会议室安静了几秒。方工先开口，问了三个技术细节，问完点点头："取证逻辑闭环。我个人的意见——这事不能止步于'还候选人清白'。"

然后，僵局出现了。

僵局的两头，一头是 HR。

HRBP 的上级今天亲自来了——人力资源部的总监，一个说话滴水不漏的中年男人。他的立场表达得极其圆熟：候选人资格问题，"既然举报所依据的证据被证明系伪造，提名公示即可恢复，这件事对候选人本人也就结了"；至于伪造线索——

"关于那个邮箱前缀，"他的措辞斟酌得像走钢丝，"我要提醒各位几点：一，格式相似不等于同一来源，外部巧合的可能性无法排除；二，即便确系内部人员，追溯需要动用 HR 系统的账号对应关系，涉及全员隐私授权；三——"他停了一下，看了一眼会议室的门，把第三点说得很轻，"现在是上市筹备的关键期。**在没有实锤的情况下启动'内部构陷'调查，等于向全公司宣布'我们有内鬼'。**这个消息如果传导到资本市场那边……"

他没说完。不需要说完。会议室里每个人都知道那半句话的分量：上市前夕，公司最不需要的就是一则"内部有人伪造证据构陷员工"的丑闻。

"所以 HR 的建议是：恢复公示，线索归档，观察后续。"

"观察后续。"方工重复了一遍这四个字，语气里听不出温度，"上次'观察后续'的是雪崩案的操作者认定。观察了一年，后续是——他又伸了一次手。这回伸到 GitHub 上去了。"

另一头，是乔曼。

"我不同意'恢复公示'。"

秘书处的位置上，乔曼合上了记录用的笔记本。这个动作让会议室里的几个人都看了她一眼——记录员合上笔记本，意味着接下来的话不是记录，是发言。

"我理解 HR 的顾虑。"她开口，声音平稳，逻辑严整，"正因为理解，我才更要说：现在恢复公示，是错的。"

"举报信的证据是伪造的——这只说明'这份证据无效'，不说明'抄袭不存在'。"她说，"两个项目的代码相似度是客观事实，issue 编号的穿帮只能证明伪造者搬运了她的**当前代码**，但两项目之间'高度相似'这个基础事实，一天不给出权威结论，公司就一天悬在'我们的技术新锐是不是抄的'这个问号上。恢复公示？公示挂出去，外部一句话就能问倒我们：'抄袭疑云未澄清就颁奖，这是什么导向？'"

她环视一圈会议室，语调落到了最正当的位置上：

"所以我建议：**暂缓公示，立项彻查。**由技术合规委员会牵头，对相似性问题做一个内部的、彻底的、不受外部干扰的结论。在结论出来之前——"她顿了顿，目光没有看向任何人，"涉及此事的评审记录、提交流程、以及，相关人员的操作权限，都应该纳入合规审查的范围。"

相关人员。四个字说得毫无指向，落进不同人的耳朵里，砸出不同的坑。

沈见微坐在当事人的位置上，安静地听完了。她注意到一个细节：乔曼说"暂缓公示，立项彻查"的时候，语速、手势、停顿，全是标准的"从严治理"的公共姿态——八年职场打磨出来的那种无懈可击。如果她不知道那本压在抽屉底层的《人月神话》，不知道那个深夜亮着的订阅通知，不知道六十一枚时间戳，她大概真的会信：这是一位负责任的技术秘书，在维护公司声誉。

知道的人只看见四个字：**拖延战术。**立项彻查，彻查多久？三个月？半年？查到最后"证据不足，无法定论"？提名黄了，声誉挂着，质疑长草——去年雪崩案的操作者认定，走的就是这条路。

"我谈一点不同意见。"

长桌另一端，江叙白开口了。这是他今天的第一句话。

"乔秘书的方案里，有一个前提没有检验：**内部彻查的结论，有没有公信力？**"他说，语速照旧不快，"这场指控的战场在墙外——伪造的仓库、外部的平台、匿名的账号。用墙内的调查去回应墙外的指控，等于用内部备忘录去回应公开质疑。谁信？"

"信不信是市场的事，查清楚是我们的事。"乔曼接得很快。

"市场不信，查了等于没查。"江叙白说，"这个案子的正确解法只有一个：**第三方鉴定。**委托一家和外双方都无利害关系的技术鉴定机构——开源知识产权鉴定，业内有现成的资质和先例——对两个项目做独立比对，出具可公开的鉴定意见。"

他环视会议室，把理由说完整：

"第一，第三方结论有公信力，不管结论是什么，公司都下得来台。第二，鉴定过程和结论可公开，这本身就是对'资本审视'的最好回应——HR 总监担心的那个'问号'，恰恰需要一份敢拿出去的文件来消除。第三，"他停了一拍，"第三方鉴定的启动记录、过程记录、结论记录，全部是外部存证。**这件事从今天起，不能再只有内部的版本。**"

最后半句话说完，会议室安静了两秒。懂的人都听懂了：他在给这件事上双保险——万一内部有人想"观察后续"，外部已经有了自己的时间线。

"程序上我补充一点。"方工跟着开口，"第三方鉴定属于技术委员会职权范围内的重大事项，今天表决就行，不需要再走别的流程。"

到这一步，会议的走向已经很清楚了。HR 总监的脸色缓和了——第三方鉴定恰恰也是他可以接受的出口：不是"内部有内鬼"的丑闻，而是"公司主动委托外部鉴定、以正视听"的公关动作。表决的气氛开始成形。

就在这时候，乔曼再次开口了。

"我反对。"

会议室安静下来。这一次没有人再看笔记本——所有人都在看她。反对一项即将表决通过的动议，需要理由，而她接下来给出的理由，让整个会议室的温度降了一格。

"第三方鉴定，把公司的技术资产、评审内部、代码细节，整套交给外部机构。"她说，"保密成本、时间成本、合规风险，主席有没有评估过？上市筹备期，任何外部尽调都要过法务的合规审查——这个流程走完，三个月都打不住。为一个评优提名，值吗？"

她顿了顿。接下来的那句话，出口之前，她自己大概有过半秒钟的犹豫——半秒钟之后，八年的修炼输给了别的东西。

"还是说——"她看着江叙白，微笑，那个微笑还维持着职业的弧度，但弧度下面的东西第一次露出了棱角，"**主席对这个案子的投入程度，已经超出了一般的技术判断。**从取证到定性到今天的外部鉴定动议，每一步都推进得这么快、这么坚决——主席要不要顺便说明一下，你和候选人之间，有没有需要回避的关系？"

会议室死一般的安静。

方工手里的笔停在半空。HRBP 的记录停了。法务的年轻人抬起头，张着嘴，忘了合上。沈见微坐在当事人的位置上，看见长桌末端那个被影射的人——他没有动，脸上没有任何表情，只有指间那支钢笔，不知什么时候已经不在转了。**停着的。笔尖朝下，像一枚钉子。**

"回避申请，"江叙白开口了，声音比平时低了半度，每个字都砸得很稳，"是委员会成员的权利，也是义务。乔秘书提醒得对——那我们现在就走这个程序。"

他环视全场：

"我，江叙白，与候选人沈见微，存在同一项目条线的长期工作协作关系。协作记录包括：攻坚组借调、归因专项、评审流转——全部有据可查。**如果任何一位委员认为这构成需要回避的利害关系，请现在举手，我立刻退出本案的全部表决与讨论。**"

没有人举手。会议室里安静得能听见空调的风。

"没有人举手，回避程序完结，记录在案。"他说，"那么我也提醒乔秘书一件事——"

他翻开面前的一份文件，是秘书处的章程复印件，指尖点在某一页：

"章程第十条：秘书处的职责是归口、调阅、协调、支持。**乔秘书对委员会表决事项公开发表反对意见，对委员个人进行动机质询——这两项，都不在四项职责之内。**"

"下次发言之前，请先确认发言的身份是'秘书处'，还是'个人'。如果是个人——"他合上文件，语气平得像在念一行代码注释，"委员会的讨论不限制个人发言。但个人发言要署个人的名。"

会议室里，有人的呼吸声清晰可闻。

乔曼坐在秘书处的位置上，脸上的微笑还挂着——挂得很吃力，像一件从内部裂了缝的瓷器。她大概用了全部的修养才让那个微笑没有碎在当场。三秒钟之后，她开口，声音恢复了大半的平稳：

"我收回刚才的表述方式。程序问题我服从表决结果。"

表决五分钟之后结束：第三方鉴定动议通过，委托方工牵头本周内拟定机构名单；候选人公示恢复，附加鉴定结论待出的说明；伪造线索——方工坚持加了一条："秘书处对 u237114 相关的内部调阅记录，一并纳入第三方材料范围。"

这一条通过的时候，沈见微看见乔曼的手指在笔记本的边缘，极轻地收紧了一下。

散会。人流散去，各怀心事。

---

沈见微是最后一个走的。

收拾东西的时候，方工留下来跟她说了一句体己话："今天的会，你看明白了吧。 HR 要的是'了结'，乔秘书要的是'悬置'，江总要的是'外证'——三种方案背后是三种立场。往后你再看会议上的任何争论，别听词，看立场。词是给人听的，立场是给自己用的。"

她点点头，走到电梯口的时候，遇到了落在最后的乔曼。

两个人在电梯里独处了三十秒。楼层数字往下跳，谁也没有说话。到了一楼，门开了，乔曼先走出去，高跟鞋的声音在大厅里响起来，一步，一步——

今天的节奏乱了。快了半拍，重了三分。八年来第一次，沈见微听出了这双高跟鞋声里的东西。不是从容，是**惊惶的余烬**——一个人刚刚在四十个人面前，亲手打碎了自己端了八年的碗，正努力把碎片拢回怀里的那种声音。

"沈工。"乔曼走到大厅门口，忽然回了一下头，隔着几步远，说了一句收场白，声音已经完全恢复了平稳，"恭喜你的取证文章。写得好。"

"谢谢。"沈见微说，"乔秘书今天也发言很好。"

两个人的目光在冬天的玻璃门两侧碰了一下，各自收回去，各自走进了各自的战场。

---

当晚，四楼，乔曼的办公室。

灯只开了台灯那一盏。她坐在光圈里，面前摊着她那个从不示人的便笺本——今晚翻开的是新的一页，但笔悬了很久，一个字都没写。

写不出来。写下来会变成证据——这是她的纪律。可是今晚的另一种冲动更强：**她需要复盘。她刚才在会上，失控了。**

四十个人。八年来她在这家公司做的每一个动作、说的每一句话，都经过同一道工序：先算立场，再算后果，最后才让字出口。这道工序从来没失手过——直到今天那句"需要回避的关系"脱口而出。那句话出口的瞬间，她听见自己心里有个声音在尖叫着阻止，但嗓子比理智快了半秒。

半秒。八年的修炼，输给了半秒。

为什么是那半秒？她比谁都清楚。是因为他站起来说"第三方鉴定"的时候，是为了那个女人——为了把那个女人的清白，交给一个他信得过的外部世界去背书。他站在长桌那头，用他全部的分量，给另一个人铺路。铺得那么理所当然，铺得像他给那个人铺了两年路之后的又一次顺理成章。

她坐在那儿看着那一幕，八年的工序忽然全部死机。死机的系统输出了那半秒钟。

"蠢。"她对着空气，轻轻说出这个字。骂的是自己。

骂完，她做了一件今晚唯一理性的事：复盘损失。损失清单不长，但每一项都重——

第一，她在四十个人面前暴露了"针对"的立场。八年来她的立身之本是"永远不直接出现在证据链上"，今天她把自己的一条影子，钉进了委员会的会议纪要。

第二，他说的"个人发言要署个人的名"——这句话是当众划线。从今天起，委员会里所有人都知道了：秘书处的立场，和某个个人的立场，可能不是一回事。她的通道，第一次被人当众标注了"可能被私人动机污染"。

第三——这一项最隐蔽也最致命——方工最后加的那条："秘书处对 u237114 相关的内部调阅记录，一并纳入第三方材料范围。"

调阅记录。留存五年，不可删除。那是十一月章程里被他亲手钉进去的钉子。当时所有人都以为那是一颗无关紧要的钉子——今天它露出了用途：**从今往后，秘书处查过谁的记录，谁查的，什么时候查的，全部会成为第三方手里的材料。**

包括——她心里那本账翻到某一页——她自己签过的那几份调阅单。

台灯的光圈里，她盯着便笺本的空白页，盯了很久很久。最后，她什么都没写，合上了本子，压回键盘底下。

窗外，城市的灯火一如既往。她起身关灯，走到窗前站了一会儿。冬夜的玻璃映出她自己的脸——妆容完整，眼线一丝不乱。只有她自己知道，这张脸的内部今天塌了一角，塌掉的那一角，八年来第一次，没能当场补上。

"不急。"她对着玻璃里的自己，说了今晚的最后一句话，"塌了就塌了。**裂缝这种东西，是给对手看的。让他看。**"

"看到裂缝的人，会忍不住往里伸手。"

她关掉了台灯。

黑暗里，那句话悬在原地，像一枚反扣着的、看不见底色的筹码。
