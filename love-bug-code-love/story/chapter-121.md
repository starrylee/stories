# 第一百二十一章 格局

那杯推过来的茶，江叙白最后还是端起来了。

不是接受——是拖延。端起茶杯这个动作，在谈判桌上有一个精确的含义：**我在听，但我没答应。**他需要这几十秒，因为接下来霍振声要说的话，他必须一字不漏地听完，才能知道自己面对的到底是什么。

霍振声看着他把茶端起来，很满意。满意于这个年轻人的分寸——不赌气，不冲动，懂得用程序性的动作给自己争取思考的时间。**这样的年轻人，是所有棋手最喜欢的那类棋子：有骨头，骨头长在棋理之内。**

"我先把话说透。"霍振声重新开口，语气从闲聊切换到了一种他极少使用的、近乎坦诚的频道，"江总，你昨天夜里查到的东西——两秒钟、二十六封邮件——**都是真的。**"

江叙白握着茶杯的手，稳住了。

"我不跟你绕。"霍振声说，"我在这个行当里五十年，绕话是说给外人听的。你今天坐在这儿，就不是外人——你是这家公司最后一件值钱的东西，我没有对你绕话的必要。"

"乔曼做了什么，我知道。"他说得很平，平得像在核对一份例行报表，"从她三年前开始动手脚，到这次的窗口，**每一个关键节点，我的账上都有记录。**"

"你不意外？"他看着江叙白的表情，笑了笑，"还是说，你昨天夜里，已经猜到了这一层？……嗯，你猜到了。二十六封抄送，你既然查到了，就一定推到了我这里。"

"那我替你把推理的最后一步补完。"霍振声放下茶杯，身体后靠，目光落在窗外的江面上，"**是的。我不是旁观者。我是这张图纸的收图人。**"

"三年前，灵犀要上市的消息第一次放出来。我做了一轮尽调——我对每一家投过的公司都做，尤其是准备上市的公司。尽调的结论是：**这家公司上不了市。**"

"不是业绩问题。业绩是好的。问题在人。"他伸出两根手指，"两个人。一个程亦朗，一个你。"

"程亦朗这个人，"霍振声的语气里有一种老人谈论故人般的复杂，"是那种创业者里最好、也最麻烦的品种——**他要做成事，但他不肯脏手。**公司做到这个规模，每一轮增长都背着原罪：早期的数据获取、灰色地带的竞争、用顺手的权宜之计。别的创始人把这些消化掉了，他消化不掉，他攒着，攒成了一种东西——你看得见的，他这三年签'已阅'越签越多。**那不是懒，是他在替自己攒一张'我没有参与'的清单。**"

"而上市是什么？上市是把公司交给市场、交给监管、交给公众。**交给公众的公司，需要一个对公众负责的管理层。**程亦朗攒了三年的那张清单，过不了审计——不是法律上过不了，是**气质上过不了**。他会为了保清白，在最后一刻掀桌子。这种人，董事会里不能有。"

"还有你。"霍振声的目光转回来，落在江叙白脸上，"技术合规委员会。证据保全规程。五留存条款。**你花三年，给这家公司装了一整套'程序正义'。**你知道那套东西在上面的眼睛里是什么吗？"

他停了停，给出答案：

"**是刹车。**"

"一家要冲上市的公司，装了一整套刹车。谁踩谁知道。查历史——踩的是我放进来的人；查披露——踩的是要修饰的报表；查流程——踩的是每一次'先上车后补票'。江总，**你的规程没有一条是错的。但一家从泥里长出来的公司，靠的不是'没有一条是错的'，靠的是很多条'当时顾不上对'。**你的正义，是上市路上最贵的一块绊脚石。"

"所以三年前，我的结论是：**灵犀要上市，先换管理层。**"他说，"程亦朗要体面地退下去，你——你的刹车要拆掉。这不是针对，江总。这是手术。**给一家要上市的公司，摘除不能共存的器官。**"

"乔曼，就是那把手术刀。"

窗外一艘货轮拉了一声很长的汽笛。声音穿过玻璃，闷闷的。

"手术的方案本来不是这样的。"霍振声说，"原方案干净得多：借治理项目，做出一串'管理失序'的事实，董事会在上市前自然换帅。你那套规程，会因为'效率问题'被改组掉。**没有泄露，没有八千万，没有人受伤。**"

"是这次出了事故。"他承认，语气里第一次有了一点近似于遗憾的东西——但那遗憾的成分，江叙白听得出来，不是为人，是为局，"乔曼的窗口做得太深了。她要的不只是一个换帅的理由，她要的是把你和你护着的那个人，一起钉进去——**这一层，超出了我给她的图纸。**她在自作主张。"

"但事故已经出了。"霍振声说，"成熟的人不追究炸飞的弹片，只决定废墟怎么用。而废墟的用法，就是我今天要跟你谈的。"

他终于说到了正题。

"现在的局面，三条路。"他竖起三根手指，"第一条，你把材料递上去。我刚才说过了——炸不掉我，炸掉的是公司残值、程亦朗的体面、八百个人的赔偿清偿顺位。**而且，你护不住你要护的人。**"

"这条我可以展开说。"他看着江叙白的眼睛，一字一字，"刑事移送的建议稿，法务已经拟好了——不是我们授意的，是他们作为法律顾问的'专业判断'，你明白这个区别。稿子里，**'直接责任人员'那一栏，写的是沈见微。**只要公司按'责任事故'的口径走完流程，监管采纳移送建议的概率，我的律师评估是七成以上。泄露八千万条金融和医疗数据——这个量级一旦进刑事程序，三年起步。加上民事赔偿和行业禁入——江总，你替她算过没有？**她今年二十八。**"

"第二条路，乔曼顶罪。"他摆了摆手，像拂开一个不值一提的选项，"她会顶的，你信不信？她那个性子，护起你来不要命。让她顶了，公司有了交代，你保住了人。**但你和我在内的所有人都知道那是假案。你查了三年真相，最后用一个假案结案——江总，你那些规程，那些五留存，那面你供了三年的荣誉墙——你就这么用它们？**"

他说到这儿停住，让第二条路的荒谬感在空气里泡了一会儿。

然后他说了第三条。

"第三条路。"霍振声身体前倾，双手交叠放在桌上——那是一个把底牌翻上桌的姿势，"**你退场，换她平安。**"

"具体是这样的。"他说，"公司层面的定性，改为'治理架构审核失职'——你是技术委员会主席、治理双牵头，这个责任你担，名正言顺，没有人能说什么。你引咎辞职，公告写得体面些：'对技术治理体系重大疏失负总责'。你退了，'直接责任人'的链条就断了头——**一个引咎辞职的管理者已经付出了他这一层能付的最高代价，再往下追一个执行层面的年轻工程师，监管没有这个动力，舆论没有这个胃口。**法务那份移送建议稿，我让它停在最合适的抽屉里。"

"她呢？"他说，"她免于刑事。停职解除，档案里留一个'调查终结，未予处分'——干干净净。赔偿是公司的，禁业是免了的，**她还可以去任何地方，做任何事，当她的沈工。**行业那么大，云启不是要她吗？顾时帆不是等她吗？**她失去的只是灵犀——而灵犀，本来就不值得任何人拿一辈子来陪葬。**"

"你失去的，"他看着江叙白，语气放得很缓，像在替对方盘点，"是这座楼，这个位置，这面墙。还有——你们那点刚刚开始的东西。辞职的人，和被调查的人，往后各自天涯，这个我想不用我教你。"

"但你换来的是：**她完整地走出去。**没有案底，没有禁业，没有二十八岁就背上的八千万条人命。"

"而我换来的，"他终于说到自己，语气平静得近乎坦荡，"是一家我可以重新收拾的资产，一个听话的管理层，和一段**被你亲手封存的过去**——你的材料，你的哈希，交给我保管。或者你留着也行，**一个退了场、签了封存协议的人手里的东西，和一个在位的执棋者手里的东西，分量是不一样的。江总，你比谁都懂这个道理。**"

"这就是全部。"霍振声说，"三条路，摆完了。我五十年没跟人把话摆得这么全过——因为你是值得摆的人。"

他重新拿起茶壶，给江叙白续了水。水声很轻。

"你可以现在答，也可以回去想。"他说，"我建议你想。**这种决定，冲动做出的，都会后悔；权衡做出的，都是对的。**"

---

江叙白在桌边坐着，很久没有说话。

他看着窗外。江面在下午的光里泛着浑黄的光，货轮一艘一艘，慢慢地走，每艘都拖着长长的水痕。五十年前，这条江上跑的是更小的船；五十年后，还会跑更大的。江水不记得任何一艘船。

他心里过了很多东西。快得像走马灯，又慢得像抽丝。

他过了那两秒的审计——那是真相，真金白银的真相，他熬了四年零一个通宵换来的。

他过了那份移送建议稿——"直接责任人员：沈见微"。七成概率。三年起步。二十八岁。

他过了她。过了便利店，过了白板笔，过了"你是我的底气"，过了充电盒，过了天台上她哭着说"通过"，过了站前广场她笑着说"天大的喜事"。

**——过了天台上她说的另一句话。**那句他当时没有听懂分量、此刻像针一样扎进来的话：

"第二，'看着'这个词你用错了一处。你不是看着。**那是把我往前推。**"

往前推。

他忽然发现自己此刻坐在这里，听一个七十岁的棋手给她的命运报价——**这件事本身，就是他此生对她做过的、最彻底的往回拉。**

他抬起头。

"霍总。"他开口了。他的声音不大，也不冷——是一种他极少使用的、彻底平静的声音。那种平静不是修养，是**决定之后的平静**。

"我有一个问题。想清楚了再走流程，对大家都好。"

"你问。"

"你的第三条路里，"江叙白说，"她免于刑事，免于禁业，免于赔偿——你把她的出路安排得很完整。我退场，你收资产，各得其所。"

"但你漏算了一样东西。"

他看着霍振声，问出了那个问题——问的时候，他自己都不知道，这个问题问对了，问到了整盘棋唯一没有复盘过的一个格子：

"**她呢？她会怎么想？**"

霍振声端着茶的手，停了半拍。

然后他笑了。笑得很轻，很慈祥，带着一种长辈对晚辈天真实在的怜悯：

"江总。"

"**她怎么想，重要吗？**"
