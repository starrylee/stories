# 第五十二章 风向

年度评优的季度总结会，开在十二月十六号，周一。

这是每年最后一次全员大会，也最像一场"年终汇报演出"：各条线轮流上去讲这一年的仗，讲完评优提名的名单过一遍流程，最后是年终奖的口径说明。今年的会开得比往年热闹——确实是打了胜仗的一年：灰度事故的处置拿了行业关注度，归因工具平台成了内网的技术名片，雪山银行的感谢函在开场就被程亦朗投在了大屏上。

大屏上那封感谢函，落款处有三个字的署名。沈见微坐在攻坚区的位子上，看着自己的名字被投在几百人的礼堂正中央，第一次没有低头。她看了一会儿，然后该看哪儿看哪儿——名字挂在那儿就行了，人不一定要站在名字底下。这是她这一年学会的。

会开到评优环节，主持人念提名名单。

"年度技术新锐——"主持人顿了顿，翻页，"提名：沈见微。提名方：技术委员会、数据平台条线、推送中心条线，三方联名。"

三方联名。这个规格在"技术新锐"这个奖项的历史上没出现过——新锐奖素来是单个条线推自己的新人，三方联名意味着：她这一年打的仗，救过的人，替别人扛过的锅，在年底长成了这个形状。念到提名方的时候，礼堂里有几个方向响起了掌声，掌声不齐，是那种此起彼伏、各自为政的掌声——数据组的掌声，推送中心的掌声，还有攻坚区这一片闹得最凶的。

老康拍巴掌拍得像打快板，一边拍一边跟旁边的人说："看见没，三方联名，我们见微。"

主持人继续往下念："年度技术贡献——提名：江叙白。提名方：技术委员会。"

名单念完，公示走流程：三个工作日后挂内网，无异议则生效。

散会的人流里，温遥挤过来跟她并排走，压低声音："看见名单没？同一份文件。一个新锐，一个贡献。你们俩的名字，头一回印在同一页纸上。"

"评优名单都印在同一页纸上。"

"好好好，是我想多了。"温遥摆摆手，眼里全是笑，"我就是想提醒你——按今年的惯例，颁奖那天，新锐和贡献，是要站同一级台阶上拍照的。你提前想想穿什么。"

"工牌绳配羽绒服。"沈见微说，"我赶时间。"

---

举报信是周三上午到 HR 的。

公示挂在哪儿了呢——哪儿都没挂。三个工作日的公示期，第一天就停了。周三上午十点，HRBP 打电话请沈见微去一趟，电话里的措辞很客气："不着急，下午任何时间都行，来聊聊。"

沈见微去的时候是下午三点。还是那间放着纸巾盒的双人小会议室，年初乔曼坐过的那间。纸巾盒还在原来的位置——这个细节她记得，年初在这里听乔曼的绩效面谈时记下的：那个位置放着纸巾，说明这间屋子经常有人在哭。

她今天没哭。她进门先看了一眼纸巾盒，然后坐下，问："什么事？"

HRBP 把一页打印件推过来。打印件是一封邮件的截图，发件人是一串乱码般的匿名邮箱，收件人是公司 HR 的公开举报通道。邮件的标题很短：

**《关于年度"技术新锐"候选人沈见微的几点情况反映》**。

"公示暂停了。"HRBP 说，声音放得很软，"按流程，涉及候选人的实名或匿名反映，公示期顺延，先核查，再公示。你先看内容——看完我们再谈。"

沈见微把那页纸拉到面前，从头往下读。

信一共九段，写得比论坛那个帖子长，也比那个帖子冷。九段的逻辑链她读第一遍的时候就理清了：

第一段到第三段，讲事实——她的开源项目，那个让她被破格捞进灵犀的、星数过千的项目。信里说，该项目的核心模块"链路染色与自愈补标"，与某个境外开源项目"高度相似"，并附了"证据"：境外项目某模块发布于前年三月，她的对应模块提交于前年九月，"时间上存在明确的先后关系"。

第四段到第六段，讲性质——"若参考与借鉴确凿，则其全部建立在'原创'叙事上的职业资格存疑：破格录取的依据、入职以来获得的技术评价、乃至本次'技术新锐'的提名，地基都需要重估。"

第七段到第九段，讲升级——建议公司"审慎核查"，并附了一段措辞极其讲究的收尾："**尤其值得核查的是其入职后的工作时间分配。据可查的记录，该员工工作日内的提交活动与其开源项目的维护存在大量时间重叠——用公司的时间，做个人声誉的资产。**这样的成长曲线，或许可以部分解释'新锐'的成色。"

最后一行是落款：**"一个关心公司声誉的普通员工"。**

沈见微把九段读完了。读完，她没有立刻说话，而是把那页纸翻过来，看了看背面——背面是空白的。她又翻回正面，目光停在第七段到第九段，停了很久。

HRBP 观察着她，小心地开口："我知道这个时机很难看。公示第一天就出这个，怎么想都不是巧合。你先别急，公司有核查流程，开源项目的原创性是可以——"

"我问一个问题。"沈见微打断了她，声音很平，"'据可查的记录'，这六个字。"

"什么？"

"第七段说，'据可查的记录，该员工工作日内的提交活动与其开源项目的维护存在大量时间重叠'。"她抬起头，"我开源项目的提交，是公开的，任何人都能查——这部分'可查'。但'工作日内的提交活动'，指的是我**在公司内网系统的提交记录**。这部分是内部数据。"

会议室里安静了一秒。

"把两边的时间线做重叠分析，"她一个字一个字地说，"需要同时拿到两边的数据，还需要专门花时间去对齐、去统计。外人做不了——外人只能看到我开源那一半。**写这封信的人，调阅过我的内部提交记录。**"

HRBP 的脸色变了。

"这还不是最重要的。"沈见微把那页纸推回去，指尖点在最后一段，"最重要的问题是：谁有权限调阅一个普通工程师的内部提交记录？"

她替 HRBP 答了这个问题，答得很轻，像陈述一个天气：

"今年十一月之前，需要走安全审批。十一月之后——技术合规委员会成立了。章程第十条，秘书处经双签授权，可以调阅'合规事项范围内'的全量评审与变更记录。年底正在进行的'年度合规审查'，是一份覆盖全员的批量授权。"

HRBP 张了张嘴，没出声。窗外冬天的太阳白晃晃的，照得会议室里很亮，亮得有点冷。

"我要说的就这些。"沈见微站起来，"信你们按流程核查。抄袭的指控我不担心——我那个项目从第一个 commit 到现在，每一行代码的来历都清清楚楚，境外那个项目我看过，相似的部分是共同依赖的底层库，双方都标了来源。这一部分，事实会替我说话。"

她走到门口，停了一下，回头补了最后一句：

"但是 HRBP，请你们核查的时候，多查一件事。**这封信不是举报我的人写的，是举报我的人借的刀。**刀是'流程'，握刀的手藏在一份批量的调阅授权后面。你们查抄袭，查十天就能还我清白；你们要是不查那只手——"

她顿了顿。

"下一次，它不会只举报我的代码了。"

门轻轻合上了。HRBP 一个人坐在会议室里，面前那页纸安安静静躺着。她做这份工作七年，见过各种举报信——怨气的、报复的、竞争的。这一封不一样。这一封通篇没有一个错字，没有一句情绪，引用的数据精确到可以出报告。

她把纸拿起来又看了一遍，看到第七段的时候，忽然打了个寒噤。

她现在才反应过来刚才那个姑娘坐在对面时，她的感觉是什么——**那不像一个被举报的人在看举报信。那像一个事故分析工程师在看现场。**她在读这封信的时候，眼睛里没有委屈，没有愤怒，只有一种职业性的、逐层下钻的专注，像在把一具故障的机器拆成零件，一个一个编号。

被举报的人在拆举报信。

HRBP 把纸锁进了抽屉，给她的上级拨了电话。电话接通之前她想起一件事：年初在这间会议室，另一个人坐在今天那个位置上，听完自己的绩效，笑着说"我明白"。两个人，同一间屋子，同一种冷静。但今天这一种，让她后背发凉。

---

当天晚上，沈见微在出租屋里坐了很久。

笔讲本摊开在桌上，她把这九段信的结构重新画了一遍。画到第七段的时候，她停笔了——不是因为分析不下去，是因为分析得太顺了：真话的排列（时间先后是真的）、空主语的毒芯（"高度相似"不给定义）、藏在数据后面的手（内部调阅）。三种手法，她在三个不同的现场见过：茶水间的话术，动员会的"时间上的巧合"，论坛帖的七百字。

**同一双手。第四次。**

她翻到笔记本的前面，翻到三月那一页，那页上写着观察项：第一次使用，四月七日，GR-22104。她往下看：第二环，十一月，技术秘书。她在这一页的末尾，添了第三行：

**"第三次：十二月，匿名举报信。武器：我的出身。"**

写完这三行，她盯着"出身"两个字，看了很久。

前三仗，打的都是她的"现在"——工单、事故、代码。这一仗不一样，这一仗直接挖她的"来处"：那个让她被捞进灵犀的开源项目，那块她全部职业资格的基石。对方学得很快：现在她是动不了的了——班底、声誉、CEO 的归档令；那就打过去，打那个十九岁的、在没有暖气的实验室里熬夜写代码的自己。

她想起老家小城，想起母亲，想起大学四年不敢看的成绩单，想起被辅导员约谈时走廊里的那种灯。想起毕业那年投出去的两百多份简历，和唯一回来的那个电话——"我们看了你的项目，绩点不重要"。

那个人举报的，就是那个电话。

她在"出身"两个字下面，又写了一行。这一行不是分析，是她自己的话，写给那个十九岁的自己的：

**"别怕。**这一次，站在你身边的东西比那时多了——时间戳、留痕、三方联名的人、一个秒删帖子的 CEO、还有一整个把你的名字投在大屏上的年份。**她挖的是你的地基。她不知道你的地基是怎么打的——是一行一行代码，自己打的。**"

写完，她合上笔记本。

窗外是十二月中旬的夜。城市的灯火照常亮着，地铁的震动从楼下远远传来，像这座城市沉稳的心跳。

她起身给自己烧了壶水。等水开的时候，她看着窗玻璃上映出的自己——马尾，眼下淡淡的青，站得笔直。她对着玻璃里的自己，把今晚的最后一点情绪处理掉了：不是愤怒，也不是委屈，是一种更冷的东西——她在心里，向那个看不见的对手，回了一句话。

**你打对了地方。**

**你打错了人。**

水开了。她泡了杯茶，坐回桌前，打开电脑，开始整理她的开源项目从第一个 commit 到今天的全部证据链：提交时间、依赖声明、相似度争议模块的来源标注、境外项目同期代码的逐行对照。

一场关于"来处"的战争，明天开始打。

这一次，她不是一个人在战情室里打——虽然她还没完全知道这一点。她不知道的是：同一个夜里，这座城市的好几盏灯为她亮着——一盏在五楼，那个从不熬夜的人今晚把她的开源仓库 clone 到了本地；一盏在四楼某间办公室，一份"核查建议"正在被起草；还有一盏，在产品部某个姑娘的工位上，温遥看着"风要变了"那条旧消息，新建了一个备忘录，备忘录的标题是三个字：

**护住她。**
