# 第一章 破格录取

出租屋的清晨，是被闹钟叫醒的。

六点整，手机在床头柜上震起来，铃声穿透一层薄薄的遮光帘。沈见微伸手按掉，盯着天花板看了三秒钟，坐起来。她其实五点五十就醒了——闹钟只是把这件事变成正式的。

今天是她入职的日子。

这是她来上海租房的第二个年头。三十平米的老公寓，朝北的卧室，月租两千八，家具是房东留下的：一张床，一张书桌，一个双门衣柜。屋子不大，但只住她一个人。毕业那年拖着行李箱走出上海站，她在心里默默算过一笔账：房租可以占到工资的三分之一，但必须一个人住——合租省下的钱，买不回深夜一个安静的房间。

她洗了澡，把头发吹到八成干，对着洗手台上方那面有点水雾的镜子刷牙、护肤。然后是衣服。

昨晚她睡不着的时候把要穿的衣服在脑子里盘算了一遍，最后选了白衬衫，深色直筒裤，下摆扎进裤腰——干练得体，但不隆重，分寸刚好。她把领口抚平，对着镜子给了自己一个不算自信但很郑重的点头。

早饭是一片吐司配热牛奶，一个煎蛋。吃到一半，母亲的微信语音进来了，六十秒一整条：第一天上班，早饭要吃的，不许空肚子；挤地铁不要跑，迟到一次天塌不下来；还有那个灵什么公司，大是大，到底靠谱吗。

她回了一条语音："靠谱，要上市的。妈，我到了给你发消息。"

对面沉默了两秒，又进来一条六十秒的语音，核心就一句：就你那个成绩……人家大公司抢着要你？

她没回这条。有些账，用嘴算不清。

考是考进去了——那是四年前的事。高考她拼尽全力考上了A大，上海那所985，录取通知书来的那天，她还是懵懵的，像做梦一样。专业是软件工程，她其实并不知道软件工程要学些什么。第一个学期结束，高等数学、离散数学、计算机组成原理、数据库……一大堆专业课，都是厚厚的书在啃，绩点排名出来，全专业倒数十名以内。

之后的每一年，她都像溺水一样，被这些课业淹没，苦苦挣扎。在阶梯教室角落的位置、在宿舍熄灯后的走廊、在春节亲戚追问"保研了吧"的饭桌上，一遍一遍地体会同一件事：她是这所学校里最名不副实的那种存在。

好学校里的差学生。

差学生三个字，她听了四年。听得耳朵起茧，听得心口结痂，听得她在毕业前最后一个学期把所有精力砸进了一个谁也没让她做的开源项目——一个分布式任务调度框架，起因只是她实习时被一个难用的调度系统折磨到凌晨三点，回来顺手重写了一个。

顺手。后来技术社区的编辑在推荐语里用的词是"以惊人的工程直觉"。

再后来，那个项目在 GitHub 上拿了八千多个 star。再再后来，一个猎头找到了她，然后是灵犀科技的面试，四轮。一面到三面她都过得磕磕绊绊——算法白板上她能写出来，但写得不像科班标准答案；系统设计她答得慷慨激昂，却屡屡用错术语。到第四轮，面试官翻着她的项目仓库看了足足二十分钟，什么问题都没问，最后只说了一句：

"下周一来报到吧。破格录用，流程我签字。"

破格两个字，人事系统的录用通知里没写，但整个流程走下来的感觉，像极了当年那封录取通知书——被格外开恩地放进一扇门。

她收拾好碗杯，把录用通知、充电宝和一把折叠伞装进双肩包——天气预报说今明两天都是晴，但伞是伞，晴是晴。

七点十分，她锁门下楼。地铁站在两条街外，去张江要一个小时零一刻钟。

---

灵犀科技的总部在张江，一栋十九层的玻璃幕墙大楼，楼顶架着公司 logo：一只抽象化的犀牛角，据说设计费花了七位数。

九点整，沈见微站在一楼大堂，和另外七个人排成一排。七个人都是今天入职的，工牌还压在胶膜下面，照片都是证件照标准僵硬脸。

带他们办手续的 HR 是个语速很快的姑娘，一路走一路讲："咱们这批校招加社招一共二十三人，今天是你们最后一批报到。行业情况大家都清楚，今年整个部门 headcount 收了百分之三十，你们能进来，都是过五关斩六将——"

沈见微注意到，队伍里有人交换了一个眼神。她自己也在心里把那句话过了一遍：收了百分之三十。冬天不光在新闻里。

"哪个学校的？"排队等电梯的时候，一个高个子男生跟她搭话，胸牌上印着"周昊"。

她报了校名。

"哟，"周昊眉毛扬起来，语气里的佩服货真价实，"顶级名校啊，学霸。"

"不是。"她说，"我是我们专业倒数的。"

周昊愣了一下，随即笑了，笑得有点尴尬："谦虚了谦虚了。"

她没解释。解释起来太长，而且她发现自己其实懒得解释——四年了，她第一次发现自己可以懒得解释。在校内，绩点是悬在每个人头顶的明码标价，倒数就是倒数，没什么好辩解的；而此刻站在这栋大楼里，工牌上印着"研发工程师·沈见微"，没有人问她绩点，只问她会什么。

她会的东西，花了四年，终于比绩点值钱了。

这个认知让她脚下有点轻。

上午是入职培训和系统开通。中午在食堂吃饭，她端着餐盘找位子，听见斜对面一桌同期在聊天，聊得热闹，话题是各自上一份实习或者上一家公司。

"我上一段在字节，"一个圆脸男生说，"就是太卷了才跑的。"

"我阿里出来的。"旁边短头发女生接话，"灵犀这个 offer 我对比了三家，薪资中上，但听说要上市了，期权这块……"

沈见微埋头吃饭。她没有上一家公司，实习只有一段，还是家二十来人的小公司，名字说出来没人听过。她插不进这个话题，也没打算硬插。

倒是有人的视线落在她身上。短头发女生——工牌上写着"林霜"——压低声音问旁边人："那个名校的是谁带进来的？"

"不知道，好像不是校招通道，"圆脸男生——大刘——也压低声音，"我听 HR 提了一嘴，说是……破格？"

"破格？"林霜重复了一遍这个词，笑了一下，"现在这个行情，还破格进人？"

那个笑没什么恶意，沈见微听得出来。那只是一个混过了几轮正规军厮杀的人，看到有人走了侧门时，本能的一点酸。可正因为没什么恶意，才格外真实——侧门就是侧门，不管门后面的人是凭八千个 star 进来的还是凭别的什么，在从正门进来的人眼里，都一样。

她扒完最后一口饭，收了餐盘。心里把那句"还破格进人"原样记下了，没添评价。她这四年养成的习惯：先把话收着，账后面再算——算得清就算账，算不清就长本事。

下午两点，各团队来领人。开放区里站了一排来接新人的 mentor，各自举着手机对名单。

来领沈见微的是"客户门户组"的组长，一个三十五六岁、说话慢吞吞的微胖男人，姓宋，胸牌上写着"宋启明"。

"沈见微？"

"宋组长好。"

"别叫组长，叫老宋就行。"老宋笑呵呵的，带着她往工位走，"咱们组做的是企业客户门户那一摊——说白了，给大客户看数据报表、下服务单的那个网页。不性感，钱也不多，客户骂起来倒是挺凶。"他顿了顿，补了一句，"但你别小看它，全公司一半的客户续约，都要从我们这个页面点进来。"

这是一番没什么画面的介绍。没有AI，没有大模型，没有中台。但沈见微注意到了另一件事：从大堂到工位一路，老宋跟碰见的每个人都能聊两句，保洁阿姨、前台、隔壁组探出头的测试——他在这栋楼里活得很松弛，像一条在河底待了很多年的鱼。

"你那八千个 star 的项目，"走到工位时老宋忽然说，"我 clone 下来跑过。调度器那一层写得真漂亮。"

沈见微愣了一下。

"漂亮归漂亮，"老宋把工牌递给她，笑得慢吞吞的，"门户这摊活儿没什么调度好做，你就当先歇歇脚。行业冬天，能有个地方写代码，就先写着。"

她坐到自己的工位上，闻到一股新工位的味道——塑料膜、纤维板，和上一个主人留下的、擦不干净的咖啡渍。她把双肩包放进抽屉，开机，登录内网，开始搭环境。

一切都普通得不能再普通。这个组不在十九楼的高管视线里，不碰核心交易链路，邮件列表里连全员大会的抄送行都排不进前二十——与传说中的首席架构师江叙白，与哪个组的哪个组长，都八竿子打不着。

后来她会知道，这份"八竿子打不着"，是她职场头三个月里收到的最好的运气。

只是当时她还不知道。

---

真正不普通的事，出现在下午五点半。

内网弹窗跳了一条全员通告，措辞罕见地正式：

【全员通告：公司正式启动代号"磐石"的下一代客户服务平台工程，目标 eighteen 个月内完成架构升级并支撑公司战略客户体系。即日起成立磐石工程组，相关业务与研发团队整体划入磐石工程编制。名单见附件。】

沈见微顺手点开附件。名单很长，按团队分列。她一路往下找，在第三页找到了"客户门户组"。

整组划入。包括她自己，"沈见微（初级后端工程师）"。

开放区里响起一片嗡嗡的议论。有人兴奋——磐石是公司级别的工程，进去了就是聚光灯下；有人皱眉——整体划入意味着打乱重排，现有的汇报线、排期、地盘全部重洗。

"赶上了。"老宋从工位那头探过头来，表情说不上是喜是忧，"门户归进磐石，倒是顺理成章——磐石做的就是客户侧的事。就是不知道，"他压低了点声音，"谁来分管。"

"分管？"

"这种体量的工程，公司会派一个技术委员会级别的人下来亲自分管。"老宋竖起一根手指，往楼上指了指，"十九楼那种。"

六点整，第二封通告来了。这一次只有一行字：

【磐石工程分管人：首席架构师 江叙白。下周一到任。】

开放区安静了一瞬，随即嗡的一声炸开。

"江叙白？"周昊的名字从茶水间方向飘过来，"就是那个……评审会上说'这种水平的提交也配进主干'的？"

"那是轻的。"有人接话，语气里带着一种讲述都市传说般的兴奋，"上个月他审一个外部团队的交接代码，当场把 diff 投到大屏上，问了一句——'这段代码谁写的，站出来。'"

"然后呢？"

"没有然后。写那段代码的人去年就离职了。满屋子人陪着一段没人认领的代码站了半分钟。"那人咂了一下嘴，"就那半分钟，够你记一辈子。"

笑声零零星星地响起来，笑得都不太实在。没有人觉得那是笑话——那是江叙白的履历上最不值一提的一段花边，却已经是普通人够不着的天花板。

沈见微没有笑。

她坐在自己的工位上，屏幕上还开着那行通告——【磐石工程分管人：首席架构师 江叙白】。

这个名字她在面试时听第四轮的面试官提起过一次，语焉不详，只说"进了公司你就知道了"。她在技术社区也刷到过他署名的架构文章，每一篇的行文都短促、锋利，不留情面，像一把没装护手的刀。

现在，这把刀要来分管她所在的工程了。

她关掉弹窗，继续搭环境。依赖包下载得很慢，进度条一格一格地爬。等包的间隙，她干了那件自己习惯了四年的事——新建了一个本地文档，把今天值得记的东西敲进去：

磐石工程。整组划入。下周一，江叙白到任。

敲完，她想了想，在最后补了一行：

——他审代码，看的是代码。我的代码，经得起看。

窗外，张江的夜空被写字楼群照成暗红色。玻璃幕墙上映出她自己——马尾辫，工牌绳挂脖，普通得不能再普通的一张脸。

二十四小时之前，她还是老家小城里那个让母亲担心、千里之外租房打拼的、好学校里的差学生。

现在，她是灵犀科技研发工程师沈见微，一个刚刚被卷进公司最大工程的、谁也不认识的初级工程师。

学校是她的平台，不是她的证明。

证明，从下周一那个人走进开放区的那一刻，开始计时。
