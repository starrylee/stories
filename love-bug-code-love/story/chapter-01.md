# 第一章 破格录取

出租屋的清晨，是被闹钟叫醒的。

六点整，手机在床头柜上震起来，铃声穿透一层薄薄的遮光帘。沈见微伸手按掉，盯着天花板看了三秒钟，坐起来。她其实五点五十就醒了——闹钟只是把这件事变成正式的。

今天是她入职的日子。

这是她来上海租房的第二个年头。三十平米的公寓，朝南的大卧室，月租两千八，家具是房东留下的：一张床，一张书桌，一个双门衣柜。屋子不大，但只住她一个人。毕业那年拖着行李箱走在上海的霓虹灯下，她在心里默默的想：房租可以占到工资的三分之一，但必须一个人住——合租省下的钱，买不回深夜一个安静的房间。

她洗了澡，把头发吹到八成干，对着洗手台上方那面宽大光亮的镜子刷牙、护肤。镜子里的女孩，正是青春的样子。她把头发拢了拢，半扎了马尾，瞬间清爽了起来，她给了镜子里的自己一个笑脸。

然后是衣服。

昨晚她睡不着的时候把要穿的衣服在脑五里盘算了一遍，最后选了白衬衫，深色直筒裤，下摆扎进裤子里——干练得体，但不隆重，分寸刚好。

早饭是一片吐司配热牛奶，一个煎蛋。吃到一半，母亲的微信语音进来了，六十秒一整条：第一天上班，早饭要吃的，不许空肚子；挤地铁不要跑，迟到一次天塌不下来；还有那个灵什么公司，大是大，到底靠谱吗。

她回了一条语音："靠谱，要上市的。妈，我到了给你发消息。"

对面沉默了两秒，又进来一条六十秒的语音，核心就一句：就你那个成绩……人家大公司抢着要你？

考是考进去了——那是四年前的事。高考她拼尽全力考上了上海的一所985——A大，录取通知书来的那天，她还是懵懵的，像做梦一样。专业是软件工程，她其实并不知道软件工程要学些什么。第一个学期结束，高等数学、离散数学、计算机组成原理、数据库......一大堆的专业课，都是厚厚的原版书在啃，绩点排名出来，全专业倒数十名以内。

之后的每一年，她都像溺水一样，被这些专业课淹没，苦苦挣扎求生。里而她在阶梯教室角落的位置、在宿舍熄灯后的走廊、在春节亲戚追问"保研了吧"的饭桌上，一遍一遍地体会同一件事：她是这所学校里最名不副实的那种存在。

好学校里的差学生。

差学生三个字，她听了四年。听得耳朵起茧，听得心口结痂，听得她在毕业前最后一个学期把所有精力砸进了一个谁也没让她做的开源项目——一个分布式任务调度框架，起因只是她实习时被一个难用的调度系统折磨到凌晨三点，回来顺手重写了一个。

顺手。后来技术社区的编辑在推荐语里用的词是"以惊人的工程直觉"。

再后来，那个项目在 GitHub 上拿了八千多个 star。再再后来，一个猎头找到了她，然后是灵犀科技的面试，四轮，一面到三面她都过得磕磕绊绊——算法白板上她能写出来，但写得不像科班标准答案；系统设计她答得慷慨激昂，却屡屡用错术语。到第四轮，面试官翻着她的项目仓库看了足足二十分钟，什么问题都没问，最后只说了一句：

"下周一来报到吧。破格录用，流程我签字。"

破格两个字，人事系统的录用通知里没写，但整个流程走下来的感觉，像极了当年那封录取通知书——受到老天的眷顾，被格外开恩地放进一扇门。

她收拾好碗杯，把录用通知、充电宝和一把折叠伞装进双肩包——天气预报说今明两天都是晴，但伞是伞，晴是晴。出门前，她在玄关的穿衣镜前最后看了一眼：白衬衫领口平整，头发半扎成马尾，利落又不失温柔。

七点十分，她锁门下楼。地铁站在两条街外，去张江要一个小时零一刻钟。

---

灵犀科技的总部在张江，一栋十九层的玻璃幕墙大楼，楼顶架着公司 logo：一只抽象化的犀牛角，据说设计费花了七位数。

九点整，沈见微站在一楼大堂，和另外七个人排成一排。七个人都是今天入职的，工牌还压在胶膜下面，照片都是证件照标准僵硬脸。

带他们办手续的 HR 是个语速很快的姑娘，一路走一路讲："咱们这批校招加社招一共二十三人，今天是你们最后一批报到。行业情况大家都清楚，今年整个部门 headcount 收了百分之三十，你们能进来，都是过五关斩六将——"

沈见微注意到，队伍里有人交换了一个眼神。

"哪个学校的？"排队等电梯的时候，一个高个子男生跟她搭话，胸牌上印着"周昊"。

她报了校名。

"哟，"周昊眉毛扬起来，语气里的佩服货真价实，"顶级名校啊，学霸。"

"不是。"她说，"我是我们专业倒数的。"

周昊愣了一下，随即笑了，笑得有点尴尬："谦虚了谦虚了。"

她没解释。解释起来太长，而且她发现自己其实懒得解释——四年了，她第一次发现自己可以懒得解释。在校内，绩点是悬在每个人头顶的明码标价，倒数就是倒数，没什么好辩解的；而此刻站在这栋大楼里，工牌上印着"研发工程师·沈见微"，没有人问她绩点，只问她会什么。

她会的东西，花了四年，终于比绩点值钱了。

这个认知让她脚下有点轻。

上午是入职培训和系统开通。中午在食堂吃饭，她端着餐盘找位子，听见斜对面一桌同期在聊天，聊得热闹，话题是各自上一份实习或者上一家公司。

"我上一段在字节，"一个圆脸男生说，"就是太卷了才跑的。"

"我阿里出来的。"旁边短头发女生接话，"灵犀这个 offer 我对比了三家，薪资中上，但听说要上市了，期权这块……"

沈见微埋头吃饭。她没有上一家公司，实习只有一段，还是家二十来人的小公司，名字说出来没人听过。她插不进这个话题，也没打算硬插。

倒是有人的视线落在她身上。短头发女生——工牌上写着"林霜"——压低声音问旁边人："那个名校的是谁带进来的？"

"不知道，好像不是校招通道，"圆脸男生——大刘——也压低声音，"我听 HR 提了一嘴，说是……破格？"

"破格？"林霜重复了一遍这个词，笑了一下，"现在这个行情，还破格进人？"

那个笑没什么恶意，沈见微听得出来。那只是一个混过了几轮正规军厮杀的人，看到有人走了侧门时，本能的一点酸。可正因为没什么恶意，才格外真实——侧门就是侧门，不管门后面的人是凭八千个 star 进来的还是凭别的什么，在从正门进来的人眼里，都一样。

她扒完最后一口饭，收了餐盘。

下午两点，各团队来领人。开放区里站了一排来接新人的mentor，各自举着手机对名单。沈见微的团队最后才到——来的是平台研发组的组长，乔曼。

三十岁出头的女人，妆容完整，米色西装外套，高跟鞋踩在工区地板上，声音清脆得像琴键："沈见微？"

"乔组长好。"

"叫我乔曼就好。"乔曼笑起来，热情得体，"欢迎欢迎！我们组等你好久了——哦对了，"她翻开手里的平板，"你们这批新人，本来每个组都要分摊一些日常维护的活儿，工单值班、周报汇总、测试环境巡检这些。我看你刚来，正好熟悉熟悉流程，这部分就先多担待一点？我这也是为你好，多接活儿，转正答辩的时候才有东西写嘛。"

话是商量的句式，语调里没有留商量的余地。

沈见微看了一眼周围。周昊的mentor正带着他往工位走，路上指指点点，说的是"第一个月不安排活儿，你先看看代码"；林霜那边传来的只言片语是"环境搭建好就行，别急"。

她收回视线，说："工单值班可以。周报汇总和测试环境巡检，能分我一半吗？转正答辩我打算写别的。"

开放区里有一秒钟的安静。

乔曼脸上的笑容纹丝不动，甚至更热情了："行啊，有想法是好事。"她在平板上划了两下，"那就这么定，一半。年轻人嘛，肯干总是好的。"

高跟鞋声远去。沈见微坐到自己的工位上，闻到一股新工位的味道——塑料膜、纤维板和上一个主人留下的、擦不干净的咖啡渍。她把双肩包放进抽屉，开机，登录内网，开始搭环境。

她没看见乔曼在十几米外回头看她的那一眼。

那一眼里没有热情。

---

真正的问题，出现在晚上十点。

开放区早就空了，只剩她头顶一盏灯。不是她勤奋——测试环境的依赖包下载得极慢，她只能等着。等待的时候她干了自己习惯了四年的事：翻文档，翻系统，翻一切她够得着的东西看。

灵犀的工单系统叫"犀牛工单"，入职第一天她就开通了权限。她本来只是想看看自己名下排了哪些值班任务，结果在"我的工单"列表里，看到了一条不该在的东西。

【工单编号：WT-20734】
【标题：用户反馈-订单状态同步延迟】
【优先级：P2】【状态：处理中】
【当前处理人：沈见微】
【创建时间：上周四 14:22】

她盯着屏幕看了很久。

上周四，她还没入职。这条工单创建的时候，"当前处理人"这一栏在系统里的合法选项，根本不该包含"沈见微"三个字。

她点开工单详情。订单状态同步延迟，归属模块是消息推送中心——不是她的组，甚至不是她听说会被分到的方向。她往下翻处理记录，翻到流转历史：

【上周四 14:22】工单创建，自动分配至待认领池
【上周四 16:05】处理人变更：待认领 → 张伟
【【上周五 09:31】处理人变更：张伟 → 待认领】
【【本周一 09:47】处理人变更：待认领 → 沈见微】

今天上午九点四十七分。她入职报到的第一天，领工牌、听培训、吃食堂、被划走一半杂活的那一天，上午九点四十七分——她本人当时正坐在培训室里，连工单系统的账号都还没登录过第一次。

系统日志不会撒谎。这世界上她最信任的东西就是系统日志，因为它冷冰冰，不寒暄，不微笑，改了什么就记什么。

她把流转历史又看了一遍，然后点开最下面那行小字——所有操作记录都会显示操作账号。

【处理人变更操作账号：QM-qiaoman】

工位区安静得能听见头顶空调的风声。沈见微靠在椅背上，看着那个账号名，看了足有一分钟。

乔曼。乔组长。下午两点笑容无懈可击、说"我这也是为你好"的那位。

一条别人处理了一半、被退回待认领池的 P2 工单，在她入职第一天的上午，被她的组长亲手挂到了她的名下。工单状态还是"处理中"——意味着张伟处理过的问题、可能的超时、可能的客诉，全都随着这行变更记录，无声无息地淌进了她的账户。

为什么？

她想不出答案。今天一整天，她和乔曼的全部交集就是下午那两分钟。她拒绝了全部的杂活摊派，说出口的每一句话她都记得，没有一句越界。

要么，是那句"能分我一半吗"得罪了人。

要么——她盯着屏幕，一个更冷的念头浮上来——根本不需要为什么。一条挂着"处理中"的工单，一个刚入职、连系统都没摸熟的新人，一个季度末就会自动结算的处理时效统计。她不需要得罪谁，她只需要是一个"没背景、没资历、没人在乎"的人，就够了。

灯管在头顶轻微地嗡了一声。

沈见微坐直身体，没有关掉页面。她做了一件自己都不觉得意外的事——截图，连同工单详情、流转历史、操作账号，全部存进了一个新建的文件夹。文件夹的名字她想了想，敲下三个字：

工作留痕。

大学四年，约谈、评奖、低保绩点申诉，她吃过太多"没有证据"的亏。辅导员说"你的综合表现我们了解的"，评奖委员会说"评委的考量不必解释"——每一次她都是被了解、被考量、被决定的那一方，从来拿不出一样东西替自己说话。

现在不了。

她存好截图，看了一眼时间，23:47。拿出手机，先给母亲回了条消息："妈，到了，一切顺利。我在这里有想做成的事。睡了。"然后把手机扣在桌上，重新面向屏幕。

工单系统里，那条 WT-20734 安安静静地躺在她的名下，像一颗埋进土里的、还没有发芽的种子。

她点开它，在处理日志里敲下了自己职业生涯的第一行字：

【沈见微】接手工单。先梳理前处理人已完成的排查步骤，明早同步处理计划。

不退，不吵，不装看不见。

这工单她接了。但接了，不等于这锅她背。

窗外，张江的夜空被写字楼群照成暗红色。玻璃幕墙上映出她自己——马尾辫，工牌绳挂脖，普通得不能再普通的一张脸。

二十四小时之前，她还是老家小城里那个让母亲担心、千里之外租房打拼的、好学校里的差学生。

现在，她是灵犀科技研发工程师沈见微。

她关掉屏幕，背起双肩包走进电梯。电梯下行的失重感里，她想起大学四年攒下的那句话，此刻在胸口微微发烫——

学校是她的平台，不是她的证明。

证明，从今天晚上这条工单开始。
