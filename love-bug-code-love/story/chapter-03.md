# 第三章 风险期

登录链路加固的两周排期，沈见微压着刀刃走完了。

第一周，她把四处"临时活了四年"的旧逻辑逐一清理。第三处最难——那个 2019 年的"临时规避"深埋在会话校验的底层，牵一发动全身，她不敢直接动，先在测试环境里埋了三天的影子流量做对照，确认新逻辑和旧行为在每个分支上的差异都符合预期，才敢提交。

提交是周四晚上十一点合入的。第二天早上她到工位，评审系统里躺着一条评论。她原来那个命名——`SessionFixV2`——被一条红色批注划掉了，批注下面是江叙白的一行字：

**"命名要说人话。`GracefulSessionMigration`。用词就是接口。"**

再往下翻，她在方案里的一个设计被原样圈了出来，旁边只批了两个字：**可以。**

可以。她盯着那两个字看了几秒。这个人的词典里，"可以"大概就是别人词典里的"优秀"了。

真正让全组记住她的，是第二周的周三。

那天下午两点十七分，门户的客服通道突然炸了——三家战略客户的安全负责人同时来电，说他们的账号管理后台在批量操作时出现"会话幽灵"：批量冻结一批账号，其中十分之一的管理员会话还活着，能继续操作十分钟才被踢出。

P2 事故。瑶光开工后第一枪，打在门户组头上，也打在江叙白分管的第一周。

战时响应是江叙白亲自拉起来的。二十分钟内，会议室 B 里坐了十几个人：门户组全员、QA、两个架构师、客服侧的接口人。大屏上投着操作日志，密密麻麻。

"会话服务先讲。"江叙白站在大屏侧面，钢笔夹在指间，"冻结指令下发到会话失效，中间发生了什么。"

会话服务的负责人是个老工程师，额头冒汗："批量冻结走的异步消息，消息有积压，消费延迟十分钟……"

"积压多久了？"

"……三个月。每天有，量不大。"

"三个月。"江叙白重复了一遍。会议室安静了一秒，所有人都听懂了这三个月意味着什么——不是这次事故的根因，是三次事故的根因，只是前两次没人报。

"这段消费逻辑，谁写的。"

那个声音不高，落在这间挤满人的会议室里，像刀落砧板。所有人的目光开始游移。三个月前批量冻结功能上线时，消费模块是外包交接的代码，写的人早就撤场了。

满屋子的沉默里，后排响起一个声音：

"我查过这段。"

沈见微站了起来。她刚从工位上被叫过来支援排查，手里还捏着一份上周清理旧逻辑时做的链路笔记——那三天的影子流量对照，让她把这条链路上每个坑都亲手摸过一遍。

"消息消费的代码是外包交接的，交接文档我上周核对过。"她走到大屏前，把笔记摊开，"消费失败的处理里有一个静默吞掉的异常——批量指令解析失败时，异常被 catch 后只打了 debug 级日志，然后 ack 了消息。所以解析失败的指令，消息队列以为消费成功了，删除了消息，指令本身却丢失了。丢的那一批，就是现在还活着的幽灵会话。"

她在白板上写下链条：批量指令 → 部分解析失败 → 异常吞掉 → 消息被 ack → 指令丢失 → 会话未失效。

"三个月的积压里，每天都在丢一点。"她说，"今天三家客户同时批量操作，丢的比例乘上操作量，终于大到藏不住了。"

会议室里静得能听见中央空调的风。

江叙白看着白板，看了大概五秒钟。然后他说了一句让沈见微愣在原地的话：

"坐。继续说修复方案。"

不是"不错"，不是"讲得很清楚"，甚至不是点头——是"坐"。在这间由他主导的会议室里，这是她第一次见到他把"站起来说话"的资格直接发给一个 T1。

她说完修复方案，他说了两个字："照此执行。"

散会的时候，那三家客户的事故还在收尾，但会议室里的气氛已经变了。老康——不对，她还不认识老康，是门户组的测试——路过她工位时压低声音说了一句："你刚才站起来的那半分钟，全组的聊天记录都在传你的名字。"

---

事故当晚十点，沈见微还在写复盘的根因分析。

写到一半，她收到评审系统的消息提醒。是她的登录链路加固任务下面，多了一条新评论。江叙白把修复方案里的一个细节标了出来——静默吞异常的那段代码，他不放心外包代码里还有没有同类写法，让她把全链路的 catch 块扫一遍。

批注末尾，多了一行和任务无关的话：

**"上周的影子流量对照做得对。以后你的模块，每季度留一天做这种对照。这是你的方法论，记住它。"**

你的方法论。

沈见微把光标在那四个字上停了很久。她想起周昊入职第一天说的话——江叙白上一个亲自排链路的人，现在是组长。她当时以为那是级别的许诺。

现在她隐约觉得，那不是许诺，是这个人给东西的方式：他从不给级别，他只给方法论——级别会过期，方法论不会。

她回了一个"收到"，然后把那行批注截图，存进了"工作留痕"。

文件夹里的东西在悄悄变厚。但这一晚存进去的这一张，和前面的不一样——前面存的每一张，都是别人做错的证据；这一张，是有人把她做对的东西，还给了她。

风险期的项目还在往前滚。瑶光的排期表上，登录链路加固的进度条推进到了最后一格。

她合上电脑的时候想，这个江叙白，毒舌是真的毒舌，但到现在为止，他骂过的每一句话，都骂在代码上——一句都没有骂错过人。

她不知道的是，在瑶光工程风险期的某个夜晚，乔曼这个名字，正在她看不见的一张牌桌上，悄悄地和另一个人产生了关联——

那是后话。此刻的她，只是把第二周的最后一天排完，背起包，走进张江的夜风里。

风险期还长。而她还不知道，风险期里最危险的东西，从来不是技术。
