# 第一百零八章 天台确认

把时针往回拨二十六个小时。

回到那个傍晚——她拖着行李箱走出小区，又折回公司取忘在桌上的充电器的傍晚。回到 W-041 窗口开启前的两小时四十分钟。回到一切还来得及的时候。

那天傍晚六点十分，她回公司取充电器。

取完，正要走，电梯门开了，江叙白站在里面。他刚搭完晚上要用的监控仪表盘，看见她拎着行李箱，愣了一下。

"落东西了？"

"充电器。"她晃了晃手里的线，"差点带着没电的手机回老家。"

"嗯。"他点头，正要让电梯下行——手已经按在了按钮上——然后停住了。

停了大概三秒。

三秒里，电梯门开着，门灯一闪一闪地催。她拎着箱子站在电梯外，他站在电梯里，一层楼的高度把两个人分成了上下两截。

"上来一趟。"他说。

"啊？"

"天台。"他说，"十分钟。"

电梯上行。她在电梯里看着他——他看着楼层的数字，侧脸平静，但她看见他放在按钮边的手，指尖极轻地敲了两下电梯壁。**他紧张。**这个认知让她自己的心跳也乱了半拍：一个把"照此执行"当标点符号用的人，此刻在敲电梯壁。

天台的门推开，傍晚的风涌进来。

六月初夏的傍晚，天边还剩最后一点橙红色。研发楼的天台不大，摆着几个通风设备和几盆没人管的绿植，水泥地面上有常年雨水冲出的浅色纹路。整个园区在脚下铺开，远处的写字楼群亮起了第一批灯。

没有人。这个高度，只有风。

"监控六点五十我要最后过一遍。"他说，看了眼表，"所以，十分钟。"

"嗯。"

然后他没说话。

风把他的衬衫吹得贴在身上。他站在天台的边缘，看着远处，看了大概十秒钟——那十秒里她数得清自己心跳的次数——然后他转过身来，面对她。

"沈见微。"

"在。"

"我说几句话。"他说，"说完你就去赶车。不用现在回答什么——反正你也要回来。"

她看着他。夕阳的最后一点光落在他脸上，把那张国字脸的轮廓描了一遍。她忽然发现自己在抖——不是冷，六月的风是暖的。是一种等了很久的东西终于要来的时候，人才会有的抖。

"我这个人，"他开口了。

三个字。和便利店那晚一模一样的三个字。她的眼睛一下子就热了——那半句话在她心里挂了一年半，挂成了一个小小的执念，此刻它重新开始，像一封退回去的信重新寄出。

"我这个人，"他继续说，声音不高，风一吹就散，所以她听得格外用力，"不会说好听的话。这些年说过的话，你自己都听过——短，硬，不讲情面。我不觉得这些是缺点，但我也知道，它们加起来，凑不成一句你值得听的话。"

"所以我只能把我有的，摆出来。"

他顿了顿。他的手在裤缝边动了一下——那是他习惯性去摸钢笔的动作。但今天他的口袋是空的。她后来才知道，那天他把钢笔锁在了办公室——**他不想让那支笔，替他说这句话。**这句话他要自己说，一个字一个字，用他自己的声音。

"我这个人，认定了，就不改。"

"认定一份方案，我会把它盯到上线；认定一个判断，我会为它签字担责；认定——"他停了一下。这个停顿很短，但她听出来了：那是他此生第一次，把那个词，从"方案"和"判断"的队列里，挪到了另一个位置。

"认定一个人。"

"三年零四个月。"他说，"从你把工单挂在我名下那天算——不对，"他自己纠正自己，"从更早。从你在评审会上梗着脖子对时间线那天算。那天我就认定了：这个人，我要看着她往前走。"

"后来我发现，'看着'这个词不对。"他说，"看着是旁观。我做的所有事——调你进组、调你的班、封你的证据链、替你转办疑点——都超出了旁观。我给自己找过很多理由：惜才、责任、对制度的信仰。都对，都不全。"

"全的那个理由，我在酒会那晚的回程车上想明白了。"他说，"你想明白的比我早——你连八个月的时间线都替我查好了。我只是……迟钝。查案我快，这个我慢。"

风大了一点。天边最后一点橙色沉下去了，园区路灯次第亮起。

"今天说这些，不是要你现在给我什么答复。"他说，"我挑今天，是因为——窗口今晚执行，上市在六天后，往后的日子会越来越快。我怕再不说，又要等一个'合适的时机'。我查过了，**'合适的时机'这个分支，永远不会被自动触发。得有人手动提交。**"

"所以我提交了。"

他说完，安静地看着她。

天台上很静。远处有车流的声音，很淡，像背景噪音。

沈见微站在他面前，拖着行李箱，眼睛红着。她这一年半想过的所有回应——分析过的、排练过的、在心里改过八百遍的——此刻全部不可用。工程师的大脑第一次在一台她最熟悉的机器前，彻底宕机。

最后她开口，声音是哑的：

"你知不知道，你这个人，讲个告白都像在讲技术方案。"

"知道。"他说，"改不了了。"

"我还没说完。"她深吸了一口气，"方案有三个问题。"

他愣住了。三年来第一次，她看见他脸上出现了一个接近"错愕"的表情。

"第一，时间戳不对。"她说，眼眶红着，语气却是她的，"你说'三年零四个月'——不对。你调我进攻坚组，是第六周。但你在评审会上第一次看我，是第三周。**第三周那次你在后排听完了全场。你以为我不知道。**时间戳，要改。"

"第二，'看着'这个词你用错了一处。"她说，"你说'看着她往前走'——不对。你不是看着。雪山那晚，我写第一条假设链被否定的时候，你到了，看完白板说的是'继续写'。那不是看着。**那是把我往前推。**用词要精确。"

"第三，"她的声音到这里，终于抖了，"你漏了一个必填项。"

"你说了'我这个人，认定了就不改'。你没问我——**我这个人，是什么样的人。**"

她看着他，把最后一句话说完了。这一句她没有用任何技术语言，一个字一个字，全是人话：

"我这个人，记性很好。谁在我最难的时候，往我兜里塞过一张白板笔——我都记着。我这个人，慢，但不瞎。你护了我三年，护得不留名——我用了三年，把你的名字，从所有的'不留名'里，一个一个挑出来了。"

"所以，你的方案——"

她笑了，眼泪同时掉下来，掉得毫无工程美感。

"**通过。**"

天台上安静了一秒。

然后他笑了。她从没见过他那样笑——不是嘴角的一毫米，是整个人松开的那种笑，眉眼全部参与，连肩膀都矮了半寸。三十多岁的人，笑得像把背了十年的东西放下来了。

他伸出手。不是拥抱——是握手。一个笨拙到家的、工程师式的手势，像两个签完了合作协议的人。

她把手放进他手里。握住的时候，他收了一点力，把她往自己这边带了一步——只一步，让两个人的距离从"握手"变成了"很近的握手"。

"车几点？"他问。

"七点四十。"

"六点五十了。"他说，"我送你到楼下。监控来不及最后过一遍了——叫老康盯前半小时。"

"你自己说的十分钟。"

"超时了。"他说，握着她的手没放，"**我这个人，认定了就不改。包括超时。**"

---

他们下楼的时候，没有注意到天台下方的那片阴影。

研发楼和配楼之间有一条窄窄的过道，晚上七点以后没有灯——那是物业的疏漏，多年没人修。过道里此刻站着一个人。

乔曼是六点二十分来公司的。W-041 的窗口在今晚，她有无数正当的理由出现在办公室：批次材料的最后核对、执行前的双签确认、值班表的复核。她做完了这些事，七点差十分，她从四楼下来，想去一楼打印室取最后一页材料——她选了走楼梯，电梯慢。

楼梯的转角窗，正对着配楼的天台方向。

她看见两个人上了天台。看见他们站在夕阳里说话。看见那个女人哭了。看见那个男人笑了——隔着一层玻璃和三十米的距离，她看不清表情的细节，但她看得清**形状**：那两个人的形状，是站在一起面对同一个方向的形状。是她研究了四年、记录了四年、在会议室和监控录像里见过的所有"并肩"里，最完整的一次。

她在过道的阴影里站了很久。

站到那两个人下楼，站到走廊尽头传来电梯到站的轻响，站到整栋楼重新安静下来。

她脸上没有表情。四年来她的表情管理早已臻于化境——愤怒的时候是微笑，崩溃的时候是从容。此刻她脸上是那种深度的平静，平静得像一口结了冰的井。

只是她的右手，在阴影里，慢慢地、慢慢地握紧，又松开。握紧，又松开。像在练习握住一样她永远不会拥有的东西。

**她所有的作战守则、所有的听课笔记、所有的三层转介绍和零字节输出，此刻在这条无人的过道里，露出了它们的本来面目：**那不是野心。那是一个人看着别人拥有她这辈子最想要的东西时，能够用来维持体面的、最后的姿势。

路灯在过道口亮着。她的影子被灯拉得很长，长长的影子伸进黑暗里——影子的尖端，遥遥地，指向那两个人离开的方向。

她站了最后一分钟。

然后她走出来，理了理并不乱的衣领，走向打印室。高跟鞋的声音在夜里不重，不乱。

九点，窗口开启。

她手上的材料，打印得很清晰。
