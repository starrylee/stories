# 第五十章 沙拉与沙拉酱

十一月的最后一个周五，攻坚组搞了年末团建。

地方是老康选的，公司往东两站地铁，一家"极客清吧"——包间的一面整墙都是白板，桌子底下藏着插线板，菜单的品类名全是技术梗（"内存泄漏"是无限续杯的柠檬水，"空指针"是不加珍珠的奶茶）。老板是个退役的程序员，开店的目的据说是"让写代码的人有个能随手写代码的地方喝酒"。

这一场名义上是攻坚组的团建，实际是"攻坚组加友军联欢"——归因工具二期把攻坚组、推送中心、平台条线的数据组绑在一条船上大半年，老康发通知的时候大手一挥："友军都叫上，费用组里出，谁不来谁明年优先值班。"

于是来了两桌半。攻坚组一桌，友军一桌：周昊、林霜、大刘、数据组的两个人，还有温遥——她名义上是来"考察用户对工具的满意度"，实际是来蹭饭，这个事实她本人毫无掩饰。

程亦朗的"偶遇"发生在晚上八点一刻。

他推门进来的时候，包间里正闹到一半。他穿着那身不打领带的休闲西装，手里拎着一瓶看起来很贵的酒，进门第一句话是："路过。老板说这家的白板墙值得看一眼。"

全包间起立问好。他摆摆手让所有人坐下，把那瓶酒交给老康："给你们添个菜。我十分钟就走，别管我，就当我是来参观白板的。"

他真的参观了白板。参观白板用了七分钟——白板上有攻坚组留下的半局五子棋、一道没解完的算法题、还有大刘写了一半的段子。第七分钟，他踱到友军那一桌，跟数据组的人聊了工具的体验，跟周昊聊了 TTL 收尾，最后在温遥面前停下来。

"温经理。"他说，"工具满意度调研得怎么样？"

"在调研。"温遥举了举手里的杯子，"样本量不足，正在扩样。"

"扩样需要多长时间？"

"看配合度。"温遥说，"有些样本比较难约。"

"那希望不难。"程亦朗说。他说这句话的时候，语速比跟数据组聊天时慢了一半，音量轻了三成。包间里闹哄哄的，这两句话被淹在骰子声和笑骂声里，只有坐在斜对面的沈见微听见了——她正在剥一只虾，剥到一半停了停。

程亦朗走的时候，温遥没有起身送。她低头喝了口"内存泄漏"，耳朵尖有点红。包间里没有任何人注意到这个细节，除了沈见微，和沙拉盘旁边的大刘——大刘什么都没说，只是把这个细节，连同包间的热闹，一起装进了眼睛里。

他今晚一直是这个状态：笑着，闹着，接梗接得比谁都勤，但每隔一会儿，眼神会飘一下——飘向手机，飘向门口，飘向"这些画面会不会变成下一次被问起的内容"。他知道自己在想什么。他也知道这个念头不该出现在团建现场。可它就是来了，像后台一个关不掉的进程，安安静静地跑着，把他眼前的热闊都隔了一层毛玻璃。

---

节目环节是九点开始的。

老康第一个上，唱了一首三十年前的老歌，跑调跑出了全新的艺术高度，收获了满堂的喝倒彩。降噪耳机高工被推上去，他的节目是"戴着降噪耳机盲打代码"——全场安静，他打了一分钟，投影出一段能运行的正则表达式，功能是把老康刚才那首歌的歌名转成 MD5。全场笑疯。

轮到江叙白的时候，是十点钟。

他是晚上八点半被老康"勒令到场"的——老康的原话是："十年了，团建你到场、买单、先走，三件事做得像任务编排。今年加一条：出节目。不出节目，明年预算我给你砍到只剩白板笔。"

于是十点钟，全场起哄的声浪里，江叙白站了起来。

他走到白板墙前，拿起一支笔。包间安静下来——所有人都好奇：这个人能出什么节目？唱歌是不可能唱歌的，这辈子都不可能。

他在白板上写代码。

写得很慢，很稳，一行接一行。写完，退后一步，说："好了。"

白板上是一小段 Python，一个叫 `qiu` 的空函数，函数体里没有代码，只有五行注释：

```
def qiu():
    # 一夜霜从江上来，
    # 叶落不知何处去，
    # 知交埋进土壤里，
    # 秋声收进抽屉深处，
    # 见微，而知著。
```

包间里静了两秒，然后炸了。

"卧槽，藏头诗！"周昊第一个喊出来，跳起来冲到白板前面，"一！叶！知！秋！——一叶知秋！江工你居然真的会写诗？！"

哄笑声掀翻屋顶。老康笑得直拍桌子："我服了，这节目过誉了但是它合理——藏头藏的是'一叶知秋'，符合他的性格：什么话都不直说，全藏在结构里！"

数据组的人凑上去研究代码，发现连函数名都有讲究：`qiu`，秋。有人掏出手机拍白板，闪光灯咔嚓咔嚓。老板闻声过来，看了两眼，说了句"这段可以留在墙上，免单一个果盘"。

混乱的高潮里，沈见微坐在自己的位置上，没有动。

她在看那五行注释。

不是看热闹的看。是她的看法——从第一行扫到最后一行，然后回到每一行的第一个字。周昊破译的是前四行的藏头：一、叶、知、秋。破译到这里，全场都以为谜底揭晓了，节目结束，哄笑散场。

但她看见了第五行。

第五行不在这首藏头诗的谜面里——四行藏头已经完整，第五行是多出来的。多的这一行不走藏头的逻辑，它直接把头露在外面，两个字的头：

**见微。**

见微，而知著。

前四行藏一个"秋"字，藏得规规矩矩，全场喝彩；第五行不藏了，把她名字里的两个字，明明白白放在句首——放在所有人都以为谜底已经揭晓、再没有人往下看的地方。

一叶知秋，见微知著。前半句是给全场的节目，后半句是给一个人的信。信封用哄笑做成，邮票用谜底做成，收件人地址写在一行没人再看的注释里。

她坐在喧闹的包间中央，脸上还挂着随大流的笑，耳朵却在一层一层地烧起来。烧到脸颊的时候，她下意识地端起杯子喝了一口——杯子是空的，她对着一只空杯子喝了一口。

放下杯子，她抬眼往白板的方向看。

江叙白已经回到座位上了，坐在长桌末端，正低头剥一只虾，剥得专注，仿佛白板上那五行注释是别人写的。他没有看她。一个眼神都没有。那份刻意的"没有"，和那行注释一样，藏得明明白白。

温遥的声音贴着她的耳朵飘过来，很轻，只有两个人听得见：

"脸红了。"

"喝多了。"沈见微说。

"哦。"温遥点点头，笑眯眯的，"'内存泄漏'确实后劲大。"

---

十一点，散场。

老康去结账，发现账单已经被买过了——江叙白走的时候顺路刷的，十年的惯例，全场无人意外，无人看见他什么时候刷的。大刘拍了很多照片，其中白板那段代码的照片，他拍得最清楚——拍完他盯着那张照片看了很久，手指在"发送"和"收藏"之间悬了几秒，最后按了收藏。

照片是林霜发出去的。她发了条朋友圈，九张图：白板代码、果盘、跑调的老康、以及她自己的自拍——自拍里她笑得很亮，配文是："年末的糖分补给。另：官宣一下，图中右手边的位置，以后有固定的人坐了。"

第九张图里，她右手边的空位上放着一杯饮料，饮料旁边立着一张工卡——数据组那个工程师的工卡。工卡主人本人没出镜，人在洗手间。但全评论区的八卦之魂已经点燃："霜姐？！！""谁？哪个？数据组？？"林霜在评论区只回了一个"沙拉配沙拉酱，绝配"的表情包。

没人看懂这个梗。只有坐在她旁边桌的沈见微看懂了——夏天的时候林霜说过她的择偶标准，原话是："我想要一个像沙拉一样的人，干净，简单，健康，没有心眼。"而数据组那位，全年中午都在吃沙拉，餐盒都自带。

温遥凑过来看朋友圈，看完凑到沈见微耳边："沙拉配上了沙拉酱。我们这一桌，今天成全了两对。"

"哪两对。"

"一对明恋，一对暗恋。"温遥说，"明恋的发了朋友圈。暗恋的写在白板上，全文免费公开，收件人独享。"

"温遥。"

"我在。"温遥笑得眉眼弯弯，"我就是感慨一下——你们攻坚组这面白板墙真是个好地方。老板说那段代码可以留在墙上。你想想，几年以后它还在那儿，一行一行的，前四行是一个成语，第五行是——"

"回家。"沈见微站起来拎包，"末班车要赶不上了。"

"好好好，回家。"温遥跟上去，走出去两步又回头，冲那面白板挥了挥手，像跟一个老朋友告别。

白板安静地立在包间墙上。五行注释在灯光下清清楚楚，一、叶、知、秋，见微。老板真的没擦它——后来那面墙上换过很多东西：下一场团建的涂鸦、某次头脑风暴的架构图、某个失恋工程师写的一整面歌单。唯独那五行注释一直留着，留了很久很久，久到后来的人都以为那是清吧自己的装饰。

它一直在墙上。

像一句写在公众场合的、只有一个人收得到的情话——最危险的藏身之处，从来不是暗处，是所有人以为谜底已经揭晓的地方。

那一夜之后，那张白板的照片在几个群里流传。传到第三个群的时候，配文变成了"江大神的隐藏技能：代码藏头诗"。传到第五个群的时候，有人开始逐字分析那四行注释的格律。

没有人分析第五行。

第五行平静地躺在所有的转发和点评里，像一枚沉在河底的戒指，河水从它上面流过去，一整个世界都视而不见——

除了那个把它戴在心里的人。

以及，后来，一个在深夜里逐帧放大照片的人。
