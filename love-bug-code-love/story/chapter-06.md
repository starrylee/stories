# 第六章 打杂的

转岗流程走得意外地顺。

周一早上，沈见微在内网系统里提交了调动申请，本以为要过乔曼那一关多少会磨几天——结果申请单在乔曼那里只停了十一分钟，签批意见干净利落："同意。年轻人多岗位锻炼，支持。"

后面还跟了一个笑脸。

周昊看截图的时候啧啧称奇："这么痛快？"

"痛快就省事。"沈见微收拾工位。她全部的家当装进一个双肩包：笔记本电脑、水杯、半盒没吃完的胃药、那个她记了两周的纸笔记本。最沉的是虚拟的——"工作留痕"文件夹，她拷进了新发的攻坚组账号里，加密，压缩，两道。

临走前她去了一趟斜对面的片区。温遥不在工位，屏幕上开着的原型图被锁定成一张屏保。她在温遥桌上放了杯杨枝甘露，压了张便利贴："冰的，快喝。"

没写名字。写了名字，那姑娘就要回请，客气来客气去，一杯奶茶能客出四轮。

---

攻坚组在四楼。

说是一个组，其实占了半层。电梯门打开的瞬间，沈见微的第一个感觉是安静——不是没人的安静，是图书馆那种所有人都在干正事的安静。开放区的白板一块挨着一块，写满了箭头和公式；人均两块大屏，大屏上滚动着她叫得出和叫不出名字的监控大盘；键盘声连成一片雨。

空气里有咖啡和外卖咖喱鸡的双重味道，说明这里的人吃饭不离工位。

"新来的？"前台旁边探出一个脑袋，圆寸头，络腮胡，工牌上写着"康明远"。他上下打量她，目光在她的工牌上停住，"沈见微？诶——"他忽然一拍大腿，"就你啊！上次把推送中心幂等那事儿翻出来的那个？"

消息传得比她想象中快。

"康明远，叫我老康。"他热络地领她往里走，一路小声科普，"组里规矩不多，就一条：江工说话你别往心里去。他昨天说我的压测报告'像散文'，我改了三稿。三稿！"

"他怎么说的？"

"第一稿，'像散文'。第二稿，'像散文，但装了数据'。第三稿——"老康痛苦地回忆，"过了。评语是'终于像人话'。"

沈见微："……"

工位在开放区中段，白板旁边。老康指着斜前方靠窗的一个独立位置——那个位置上堆着三摞技术书，一台没关的笔记本，屏幕黑着，人不在。

"江工的。他一般上午十点前来，晚上你下班了他还在。你运气好，他今天有评审，不在——"老康压低声音，"趁他不在，我先给你透个底：你那个'打杂的'，别当真，也别不当真。"

"什么意思？"

"上一任'打杂的'，"老康竖起一根手指，"在组里待了八个月，走的时候独立扛了两个核心模块。再上一任，现在在隔壁大厂当架构负责人。"他看着她，"这个组没有杂活。江工嘴里的'打杂'，意思是——从最硬的骨头开始啃。"

沈见微把双肩包放进抽屉："骨头呢？"

"急什么，"老康笑了，"他回来自然给你派。组里现成就有一根，全链路压测平台的流量染色——卡了俩月了，组里四个高工轮着啃，牙都崩了。"

---

下午四点，江叙白回来了。

他进门的时候没打招呼，径直走到自己工位，放下平板，站了几秒——然后转过身，隔着半个开放区看向沈见微的工位。

沈见微迎着那道视线走过去。

"报到了？"

"报到了。"

"环境搭好了？"

"搭好了。"

"wiki 看了？"

"看了。"

三个问题问完，他转身从自己桌上那三摞技术书里抽出一本，很旧，书脊都散了，翻开，夹着一张打印纸，递给她。

打印纸上是手绘的架构图，十几个服务节点，节点之间的连线上标着问号。

"全链路压测，压测流量要打标。"他说，"标记从入口进去，经过网关、服务、缓存、消息队列，要活着出来——中间任何一跳丢了标，真实流量和压测流量就会混在一起，混一起就是生产事故。现在的问题——"他指了指图上问号最密的那一段，"消息队列和异步线程这两段，标必丢。组里卡了两个月。"

沈见微盯着那张图："这是给我的？"

"攻坚组的活儿，攻坚组的人干。"他说，"你现在是攻坚组的人。"

"我是打杂的。"

"打杂的也是攻坚组的。"他把书塞给她，"两周。方案给我就行，不要求能跑——你现在是 T1，没人要求你两周解决 T6 的问题。"

最后一句话说得很平，平得像在陈述一个事实。说完他就转回自己的工位去了，留她拿着那本旧书站在原地。

沈见微回到座位，把那张架构图铺开在桌上，看了很久。

两周，不要求能跑，没人要求你两周解决 T6 的问题——话说得再客气，翻译过来还是那一句：这道题超了你五个职级，你做不出来是正常的。

做不出来是正常的。

她大学四年最恨的就是这五个字。绩点垫底的时候，辅导员说"每个人的花期不一样，你这样也正常"；秋招被刷的时候，室友安慰"今年行情差，大家都难"。每一句都是好人说的，每一句都往她背上垫一块砖，垫到她后来听见"正常"两个字就条件反射地挺直腰。

她打开那本旧书，第一页的扉页上有钢笔字，一行，笔锋很利：所有丢掉的标，都死在你不看的那一跳。

不知道是写给谁的。墨色已经旧了。

---

当晚，同期群里炸了。

起因是大刘。他不知从哪听说沈见微领了全链路压测的流量染色课题，在群里发了个目瞪口呆的表情：

"沈见微接了压测平台流量透传？？就那个卡了俩月的？？"

"哪个沈见微？"

"就破格那个啊！刚进攻坚组第一天！"

群里安静了几秒，然后消息一条接一条蹦出来。有惊讶的，有看热闹的，有发"新人持盾"梗图的。林霜发了一句："组里高工都啃不下来的，给新人？这是什么培养方式。"

大刘补刀："我赌五块钱，两周之后交一份文献综述。"

周昊私聊了她，就一句话："你真接了？那玩意儿我们组 T5 都不敢碰。"

沈见微正在读第三篇论文，回他："接了。"

"要不要紧啊，做不出来多难看——"

"做不出来是正常的。"她回完这句，把手机扣在桌上，继续看论文。

那条消息周昊看了半天，没看明白是倔还是豁达。

---

第一周，她什么都没干，就是看。

看组里前两任高工留下的四份方案，看 MQ 那一跳的上下游代码，看标记在异步线程池里蒸发的那三行日志。四份方案死法各不相同：有的想把标记塞进消息体，改协议，动静太大被否；有的想在消费端做二次校验，但校验源本身要跨网络，压测流量一大，校验链路先崩；有的想改造线程池做上下文包裹，改到一半发现适配的中间件版本号对不上，烂尾。

第五天晚上，她趴在桌上画那张架构图。图上的问号她已经能一个个讲出死因了，讲到消息队列那一跳，笔尖停住。

标丢在队列里，是因为入队和出队之间，隔着一次进程内的"失忆"。那么与其防止失忆——不如让标自己长记性。

她坐直了。

入队的时候，在消息的元数据里附一段指纹——不是标记本身，是标记的校验和，用消息体里天然稳定的字段算出来。出队的时候标丢了没关系，用同一组字段重算一遍指纹，对得上，补标；对不上，说明这条消息本来就不是压测流量，放行。不依赖上下文传递，不改造协议，不加跨网络校验——标记丢了以后，能凭消息自己"回忆"出自己是谁。

自愈。

她抓过草稿纸开始算指纹函数的选型。要用消息体里哪些天然字段，窗口期内的碰撞率多高，重算的开销对消费吞吐的挤压百分之几——算到第三张草稿纸的时候，她意识到一个问题，后背微微发麻：

这个思路的本质，是接受"丢失是常态"，把力气花在"找回"上。而组里前四份方案，全部在攻"永不丢失"。

方向是反的。

反的才有活路。她太熟悉这种感觉了——大学时她的调度框架之所以能用，就是因为所有人都在做"更聪明的调度"，她做了"更诚实的重试"。笨办法绕开聪明问题，是她的舒适区。

第二周，她开始写。方案文档十二页，代码一个演示原型，指纹算法三种候选的对比测试数据。写完那天是周三凌晨一点，她看了一遍，没发现什么问题，睡了。

第二天下午，江叙白在组里过方案。

他看她文档的速度很快，一目十行地翻，翻到第五页——自愈设计那一节——停住了。

停了很久。

久到老康都从自己工位探过头来看。江叙白的食指抵在屏幕上那一段，人陷在椅子里，钢笔在指间一动不动，眼睛盯着屏幕，像在跟某一行字对峙。

"这个指纹，"他终于开口，"为什么不用消息主键？"

"主键在分库分表之后不唯一，天然字段里只有订单时间戳加商户号的组合是全链路稳定的。"

"碰撞率。"

"十分钟窗口内百万分之四。"她说，"测试数据在附录二。"

"附录二我看了。"他说，"我说的是——你为什么敢算碰撞率。"

沈见微顿了一下。

"组里前几份方案，"江叙白说，"全都在论证'不丢'。丢一单，理论上就是生产流量被压测污染，所以没人敢往'丢了以后怎么办'想。你直接把'丢'当成了设计前提——"他转过头看她，"谁教你的？"

"没人教。"她说，"我以前写调度框架，所有人在做避免失败，我做的是失败之后的恢复。失败的代价如果能算清楚、能兜住，就不用怕它。"

开放区安静了几秒。老康和另外两个组员的对视，无声地完成了一次情报交换：这新人是真有东西。

江叙白没再说话，低头继续翻文档，翻完最后七页，合上。

"原型代码呢？"

她把工程链接发过去。他点开，从第一行开始看——看代码的时候他比看文档慢得多，一行一行的，像验钞。

看到指纹工具类那一屏，他的动作停了。

```java
public String resurrectTag(MessageMeta meta) {
    // 标丢了，自己爬起来
}
```

他盯着那个方法名看了两秒钟，然后开始打字。评审意见栏，一行注释，敲完提交：

【思路可以。命名不行。】

后面跟着一句："工程代码里不要出现 resurrect。它叫 rebuildTagFromFingerprint。明天改完，把方案评审约上日历——正式排期。"

正式排期。

老康后来告诉她这四个字的分量：攻坚组的课题，只有确认"能成"才配得上排期；之前那四份方案，连评审会的门都没进过。

沈见微看着评审意见栏里那行字，看了很久。

思路可以。命名不行。

这个人给批评给的像呼吸，给认可给的像拔牙——但牙拔出来了，就是真的拔出来了。她想起大学那四年，评奖委员会说"评委的考量不必解释"，辅导员说"你的综合表现我们了解的"——那些含混的、不给边界的评价，她从来不知道自己到底站在哪一格。

这个人不一样。思路是思路，命名是命名，可以是可以，不行是不行。刀切下去，切口是直的。

好。她把方法名改了，顺手把注释也改了：

// 标丢了，自己爬起来。——注释保留。注释不是给评审看的，是给三年后维护它的人看的。

提交。推送。

窗外张江的夜色又浓了一层。她收拾东西下楼的时候，路过江叙白的工位——人不在，屏幕锁着，那本旧书不知道什么时候回到了他桌上，摊开着，正翻在她看过的那一页。

扉页那行钢笔字在台灯底下泛着旧墨色：所有丢掉的标，都死在你不看的那一跳。

她想了想，从口袋里摸出笔，在自己笔记本的新一页上抄下了这句话。抄完，在下面又添了一行自己的：

那就让每一跳，都被看着。
