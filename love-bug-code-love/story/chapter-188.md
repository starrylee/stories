# 第一百八十八章 五分钟

周三，联席会开了一整天。

议程过到第七项的时候，已经下午四点了。会场是借的——出版社顶楼的多功能厅，来的人比预想多：五家主办方加上闻讯要来的，一共坐了六十几个。

第七项，"打断署名条款"的提案人出席。

青梧在台侧操作投屏。大屏亮起来，是视频窗口——铺子里那面软木板做背景，镜头前坐着池默。四十二岁，平头，围裙没解。

会场安静下来。六十几个人看着大屏上这个陌生人。

他面前摆着一张纸。稿子。

他念稿。

"各位。我叫池默，开修手机铺的。这条规矩是我提的，念一下来历。"

"十二年前我是个运维组长。我们那行那时候有个做法，生产变更用共用账号登录执行，出了变更，日志上是账号，不是人。有一年我背了一个锅，认定书上的依据就是那个账号。我在会上申辩了三次，被打断三次，第三次没讲完会就散了。我签了字，附卷了三份记录，然后换了城市。"

"十二年，我在铺子里修了几万台手机。每台写一张卡片，三段：诱因，过程，建议。后来我想明白了一件事——**打断我那三次的人，没有一个是坏蛋。**他们只是忙，只是觉得会开得太长了，只是觉得我讲的东西他们听不懂所以不重要。打断一个人，最常用的不是恶意，是省事。"

"所以这条规矩我提的不是惩罚。打断的人署名，记进纪要——不是让他丢脸。**是让'省事'这件事，留下一行成本。**一行就够了。人这个东西，成本到一行字的时候，就会开始算。"

"我讲完了。"

他真的念完了。两分四十秒，比承诺的五分钟短。念完之后他把稿子折起来，说了最后一句不在稿子上的话：

"这条规矩，是替十二年前那个没讲完的人提的。**也是替你们会上下一个没讲完的人提的。**"

然后视频窗口黑了。他自己断的线，一秒都没多留。

会场安静了几秒钟，然后有人开始鼓掌。掌声不长——这种场合的掌声都长不了，但它确实是自发的。

沈见微坐在台侧，没有鼓掌。她在笔记本上记时间：**两分四十秒**。然后在这行字底下写了一行小字：

"十二年前被摁住的话，今天两分四十秒讲完。**他练了十二年，练的不是稿子，是不怕。**"

第七项之后，议程本来该过第八项。青梧看了眼流程表，抬头问主持人温遥：

"第七项有十分钟讨论。要开吗？"

"开。"温遥说。

讨论开了。头两分钟是常规的——各主办方表态、执行细则、纪要模板。第三分钟，后排有个头发花白的人举了手。

温遥点名。那人站起来，先自报家门，声音不大：

"我叫周衡，退休三年了。原来是做银行信息科技风险管理的。"

沈见微的笔停了。周衡——她在这个名字上停了半秒。不是查到过的名字。是**查到过、但一直没对上人的**一个名字。她不动声色地在笔记本页边做了个记号。

"我说一个事。"周衡说，"打断署名这条，今天之前我不知道。我今天来，本来是替我们那个退休技术协会领资料的。听了这个，我想说——**这条规矩晚了二十年。**"

"二十年前我们行业开风险评估会，打断是常规动作。上级行打断乙方，老资格打断新面孔，懂业务的打断不懂业务的——大家都习惯了。习惯到什么程度？**被打断的人自己也习惯了。**我刚入行的时候被打断，心里不舒服，但没觉得有什么不对。后来我坐在桌子的另一头，我也打断别人。打断的时候心里想的是'这个年轻人讲太慢了'——**我成为当年打断我的人的时候，我一点感觉都没有。**"

他停了一下。

"三年前退休，闲下来，我才回想这些事。想起几个被我打断过的年轻人。有一个，会后被调去管机房值班表，一个很会做风险模型的人，管了六年值班表。**打断他的人是我。**他不知道，他以为是他自己讲得不好。"

"我不找他道歉了——道歉是给自己的交代，不是给他的。**他要的从来不是道歉，是当年那五分钟。**"

他指了指大屏——池默断线之后，屏幕停在软木板那格画面上。

"我要说的就这个。规矩里的'打断三次换主持人'，我投赞成。但我想加一句建议——**纪要里署名之外，把被打断的人当时讲到第几分钟，也记下来。**"

"为什么？"台下有人问。

"因为将来翻纪要的人，会想知道，"周衡说，"**那个被摁住的人，他的话讲到哪儿了。**差两分钟没讲完的话，和差十句话没讲完的话，分量不一样。十二年前那位讲到第几分钟，今天没人知道了。**这一行数字，是替未来留的。**"

他坐下了。

会场静了一会儿。温遥低头在流程表上写字，写完抬头，宣布：

"这条建议，作为联席会现场动议记录，随条款一起进修订程序。**动议人：周衡，退休三年，前银行信息科技风险管理。**"

她念"动议人"三个字的时候，周衡在后排明显愣了一下。大概他来的时候，没打算在任何一个纪要上留下自己的名字。

散会前最后一项，是新加的：自由陈述。

青梧报了一遍规则：不限题目，五分钟一人，报名自愿。她顿了顿，补了一句："**今年是第一次设这个环节。没有人报名，我们就准时散会——这也算这个环节的正常结局之一。**"

没有人举手。

十秒。二十秒。

温遥看了眼表，正要宣布散会——

后排，周衡又举了手。

"我报一个。"他说，站起来，往台上走。走到一半他忽然停下，回头问："**我讲的时候，会有人打断我吗？**"

全场笑了一下。他自己也笑了。

"按规矩，"温遥说，"**打断你的人，要署名。**"

"那我就放心讲了。"

他上台，不用话筒——厅不大，后排听得清。他站在台中央，没拿稿子。

"我讲三分钟。讲一个二十年前被我打断的年轻人。"

"他姓陈，比我小九岁，当时是乙方驻场的。做银行代收付系统对账模块的风险评估，他的方案我看过，做得细——细到什么程度，他连月末对账洪峰期间回单打印的延迟都算了进去。开会那天他讲到第七页，我看了眼表，会超时了，我打断他，说'结论先讲，过程书面补'。"

"他把第七页翻过去了。翻得很顺——**被打断的人翻页都很顺，这个动作他们练得多。**"

"四年后，那个模块出了问题，出在他第七页讲的东西上。事后复盘，他当年的分析全对。复盘会上有人问他：当年你为什么没坚持讲完。他说：**'会上给了书面补充的机会，我补了，没人看。'**"

"我看了。看了半页。"周衡的声音低下去，"看了半页，被一个电话叫走了。回来接着看第二份材料——**那天的第二份材料是什么，我现在死活想不起来了。被他半页分析挤掉的东西，我不记得了。**"

"我想了很多年，想明白一个道理：**打断的人丢掉的是几分钟，被打断的人丢掉的是全部。**因为在会议的语言里，'跳过'和'不重要'是同一个词。你跳过他的第七页，全屋人就都默认第七页不重要。**跳过即否定——这个翻译没有人做过，但它一直在自动运行。**"

"散会之前我说最后一句。"

他看着台下，看了好一会儿。

"这个环节叫自由陈述。我建议每一个坐进会议室的人记住一件事：**你跳过谁，谁就消失。**不是人消失——是**他的那一部分，永远不来了。**"

"我那个姓陈的年轻人，后来转行了。转去做企业培训，讲课去了。前几年我刷到过他一条朋友圈，讲怎么给学员控场。有一句话我截图存着——他说：**'我的课，从来不打断学员提问。他们问什么，我答什么，问到哪儿算哪儿。'**"

"他去了能讲完话的地方。"周衡说，"**我们这个行业没留住他。**"

他鞠了个躬，下台。没讲满五分钟——三分钟多一点。走到座位边上，他停了一下，回头看了一眼那面大屏。

软木板的画面还停在那儿。几十张卡片，一列一列。

"这位修手机的师傅，"他忽然对着屏幕说了一句，像跟人打招呼，"**回头帮我看看收音机。我家也有一台，喇叭不响三年了。**"

全场笑了。这次笑得很松。

散会。人往外走，走得不快——这种会散场都慢，大家心里揣着东西。

沈见微收拾东西的时候，青梧凑过来，压低声音："周衡这个名字——"

"我知道。"沈见微说，"**'门没锁'的号码，归属地登记是那家机构的简称。他自报的履历是银行信息科技风险管理——十二年前那场会，主持方是银行牵头的项目办公室。**"

"是他？"

"不知道。"她说，"**可能是，可能不是。可能是同一家机构里的另一个沉默者。**这件事我不查。"

"不查？"

"他说了'下次路过'。"沈见微把电脑装进包里，"**一个人如果想让别人知道自己是谁，他会自己说。他要是只想坐进去听一听，那他今天已经听完了一场'别人替他讲完'的会。**"

她拉上包的拉链，往门口走。走到门口，又回头看了一眼这个厅——椅子横七竖八，大屏还亮着，投影的光打在空了的台子上。

"青梧。"她说，"明年的议程，自由陈述环节保留。"

"没人报名也保留？"

"今年有人报了。"她说，"**明年会有人记得：去年那个环节，是有人讲完的。**"

出了门，走廊尽头的窗户开着，晚风进来。江叙白在楼下等她——他今天没列席，说到楼下等，然后在楼下的书店站了一下午。

她上了车。车开出去，她把今天的时间线在心里过了一遍：两分四十秒，三分钟，五分钟的环节，二十年前被打断的第七页。

"今天这个会，"江叙白问，"开得值吗？"

她想了想。

"一个修手机的，两分四十秒。"她说，"一个退休的，三分钟。**两个被打断过的人——一个替十二年前，一个替二十年前——今天都讲完了。**"

"值。"她说，"**这个行当往前挪的每一寸，都是这么几分钟几分钟挪的。**"

车过路口，红灯。等灯的时候，她的手机震了一下。

温遥发的，一张照片：会场纪要的截图，条款修订栏。周衡那条"记下讲到第几分钟"的建议，已经录入，动议人一栏写着全名。

照片下面温遥发了一行字：

"散会后他来找我，问纪要能不能给他一份。我说可以，留个邮箱。"

"他留的邮箱，"温遥说，"**前缀是 CH。**"
