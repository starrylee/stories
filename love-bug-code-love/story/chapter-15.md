# 第十五章 物理白板

根因分析会定在第二天上午十点，战情室。

参会的有十几个人：攻坚组、数据库组、平台条线的两位工程师，还有被 P0 机制拉进来的技术委员会观察员。江叙白主持。白板上昨晚的东西没擦——那根针、三个数、那句"集体阵亡"，原样留着。

乔曼也在。她今天到场是名正言顺的：平台条线负责人，事故的相关责任方。她坐在长条桌的斜对面，笔记本翻开，笔是普通的中性笔，记得很勤。

会议开始十分钟，就卡住了。

卡在归因上。

"我的看法没变。"平台组的资深工程师洪工说。他四十出头，在缓存和存储这条线上干了十五年，白头发比黑头发多，说话带着老工程师特有的笃定，"根因是预热脚本的批量写入。一次性灌几百万个 key 进缓存，这个写入模式本身就是错的——不管 TTL 有没有抖动，这么写都要出事。随机偏移那个东西，"他摆了下手，"是锦上添花的防御，不是必须项。我经手的缓存集群，一半以上不加抖动，也没见天天雪崩。"

他说完，有两个平台组的工程师点头。

"洪工的意思，"有人把话说得更直白，"是应用侧的锅，不是 SDK 的锅。"

这话有分量。因为"锅归谁"决定了三件事：复盘会上的责任归属、修复方案的主导权，以及——没人说出口，但人人都在算——这个 P0 算"业务设计缺陷"还是算"基础设施缺陷"。前者是商品团队的账，后者是平台条线的账。

"日常流量下，"洪工补充，"这套缓存跑了几年了。要按小姑娘的说法，'病'两周前就种下了，那这两周怎么一点事没有？没症状的病，你不能说它是病。"

这话说得不客气，但技术上并不外行。会议室里有短暂的沉默——这是一个难以反驳的实证：两周，零异常。

沈见微坐在长条桌末端。从昨晚到现在，她睡了不到五个小时，但此刻她是清醒的，清醒得能听见自己心跳。她举手的时候，还是老毛病，手心微微出汗。

"我请求用一下白板。"

江叙白把笔递过来。

她走到白板前，没有先说话，而是先做了一件事——把昨晚的推演整个擦掉，只留下最顶上的时间刻度。

"从零开始。"她说，"我们别从结论吵，我们从数据走。"

她在白板最左边写下第一个数：**两周前，T-336 小时。**

"两周前的周三，下午 15:40，缓存配置中心发生了一次变更。"她在数字下面画了一条短竖线，"变更之前，TTL 的实际分布长这样——"

她画了第一张图。横轴是时间，纵轴是 key 到期数量。她画的分布像一条毛毯：厚厚的、连续的、带着毛边，从左到右均匀铺开。

"四周前，档位统一化上线，三类 key 的 TTL 分别归到 600、1800、900 秒——但每一档带了正负百分之二十的随机偏移。所以档位是三档，到期时间是散的。"她在毛毯上标了三个薄薄的色带，"这是四周前到两周前的真实监控，我昨晚调的。毛毯一直在。四周，零异常。"

她在 T-336 那条竖线右边，画了第二张图。

同样的坐标系。这一次她画的分布像一把梳子：整整齐齐的齿，每一个齿都是一堵垂直的墙，墙与墙之间是空的。

"两周前的变更之后，随机偏移没有了。所有 600 秒档的 key，到期时间从'散布的一百二十秒'收缩成'同一个瞬间'。"

"这个变化当天就产生了后果。"她说，"洪工问，没症状的病怎么叫病——我昨晚也问了这个问题。然后我去找了症状。"

她调出监控历史，投在大屏上：一张日常时段的过期速率图，坐标轴被她故意放大了十倍。在放大的尺度下，日常的过期速率曲线上，能看见极小、极密、规律排布的凸起——像心电图上的小棘波。

"T-336 之后，日常流量下的过期速率，一直是这个形状。"她指着那些小棘波，"单秒过期的集中度，从随机分布变成周期性凸起，每天都在，每小时都在。它没有引发事故，只是因为日常回源量小，数据库扛得住——是血压高，但还没爆血管。"

她顿了一下，环视全场。

"所以洪工的两个论点，我用数据回答。第一，'预热脚本批量写入是根因'——不对。四周前那次变更之后，预热脚本同样在跑，批量写入同样存在，四周零事故。写入模式是常量，变量是 TTL。第二，'没症状的病不是病'——它有症状，只是症状小，小到监控的默认坐标轴上看不见。放大十倍，它一直在那里等一个大流量，把它放大成灾难。"

会议室里很安静。洪工盯着那张放大十倍的棘波图，看了很久，没说话。

"大促给了它十倍流量。"沈见微回到白板前，画下第三张图——把那把梳子的齿放大，每一根齿的顶端画上倒钩，"于是昨晚 20:06:31，血压高变成了脑溢血。"

她退后一步，把整面白板收进视野：毛毯、梳子、放大成灾的倒钩，从左到右，因果一条线。

"病是两周前种下的。"她说，"大促只是让它发病。"

---

又是那种安静。上一次这种安静出现在评优会，再上一次出现在第一晚的复盘会——她似乎总是用这种安静来给自己的人生盖章。

"梯度图有说服力。"技术委员会的观察员开口了，是个头发花白的女架构师，"但最后一环还缺着——两周前那次变更，具体是什么？谁提的？"

所有人的目光转向江叙白。他从昨晚起就是全套变更记录的封存人。

江叙白打开笔记本，把配置中心的变更详情投上大屏。

一行一行的信息刷出来：

**变更编号：CHG-20981**
**所属工单：OPT-4417「降本增效专项-缓存 SDK 计算开销优化」**
**变更内容：移除 TTL 随机偏移计算逻辑（rand 调用与偏移分支），预估 CPU 开销降低 1.8%**
**提交标题：perf: remove redundant ttl jitter calc**
**提交署名：周昊（平台研发组）**
**推送账号：platform-release（平台条线发布共用账号）**
**合入时间：两周前，周三，21:47**

会议室里响起一阵低低的骚动。

降本增效专项。这是全公司挂了半年的 KPI 项目，每个条线都背了指标。缓存 SDK 的 CPU 开销优化，是平台条线挂在专项下的十几个子项之一——提案、立项、评审、执行，一路的手续都齐全。

齐全，合规，且致命。

"perf，"洪工念着那个提交标题，眉头拧成一团，"移除'冗余的'随机偏移计算……"他猛地抬头看向沈见微，"你刚才说的那个偏移——在这个提交的作者眼里，是'冗余'的。"

"是。"沈见微说，"从纯 CPU 的账上看，随机数调用确实是开销。从缓存生存的账上看，它是保险丝。这笔优化省下了 1.8% 的 CPU，代价是昨晚六十九分钟的 P0。"

她顿了顿，把最后一句说完：

"省掉的不是计算。是冗余的运气。"

大屏上，那一行提交署名还亮着：**周昊（平台研发组）**。

会场的目光开始寻找这个名字的主人。周昊不在场——他此刻在楼下的工位上，对发生在三层尽头这间屋子里的每一分钟一无所知，还在给昨晚恢复了系统的缓存集群跑例行巡检，一边跑一边跟邻座炫耀"我们组的缓存扛住了十倍流量"。

老陈端着保温杯，慢慢说了一句："这孩子，怕是还不知道自己'写'了个啥。"

乔曼一直坐在斜对面，从头到尾记得很勤。此刻她合上笔记本，声音平稳地开了口：

"既然根因清楚了，我提两点。第一，这个提交是我们组周昊做的，平台条线不回避责任，该复盘复盘，该整改整改。第二——"她的语速慢了半拍，每个字都咬得很稳，"降本增效是公司专项，缓存开销优化立项的时候，方案评审、风险评估都是走完流程的。如果现在回头看当初的评审记录，我个人当时也是看过方案的。技术判断的失误，我们认；但立项合入的流程，是干净的。"

流程是干净的。

这句话像一块垫子，稳稳地垫在了平台条线和那口越来越大的锅之间。没有人能反驳——手续确实齐全，评审确实走过，签名确实存在。

会议在一种微妙的平静里散了。散会的时候，洪工走过白板，在那把梳子图前站了几秒钟，掏出手机拍了一张。

"发给我们组，"他对沈见微说，语气里已经没有昨晚的火气，只有老工程师认账时的干脆，"这种图，该印出来贴墙上。"

---

人走空之后，战情室只剩下沈见微和江叙白。

她在把白板上的字抄进自己的笔记本——从毛毯到梳子到倒钩，一格一格，抄得很细。抄到"CHG-20981"那一行的时候，她的笔停住了。

"江总。"

"嗯。"

"推送账号是 platform-release，共用账号。"她盯着笔记本，"署名是周昊。但是——"她翻到自己笔记本的前几页，那里记着聚餐那晚的事，"不对，记错地方了。"她又翻到另一页——大促保障值班表复印件，上面每个值班人的姓名、工号、岗位一列列排着。她的指尖落在其中一行上。

"周昊的年假。"她抬头，"大促前的两周，他休了一周年假。错峰游，他请的时候还跟我炫耀过机票价格。"

她把值班表推到江叙白面前，指着日期：

"合入时间是两周前的周三晚上九点四十七。那一天——周昊在三千公里外的海边。"

战情室安静下来。大屏已经熄了，只有头顶的灯和白板上那把梳子。

"共用账号，"江叙白看着那行提交记录，缓缓说，"在职权范围内，能登录它的人，不止一个。"

"而且，"沈见微的声音放轻了，不是怕，是那种接近真相时本能的放轻，"提交署名只是个字符串。Git 的 author 字段，写谁就是谁——推送的人，可以是任何人，写任何名字。"

她合上笔记本。

"周昊上礼拜跟我吹牛的时候，说的是'我给档位统一了'。他不知道两周前有人用他的名字，把他加的保险丝拆了。"

窗外，午后的阳光落在白板上，把那把梳子的影子拉得很长。

江叙白站起身，把封存硬盘从主机上取下来，装进防静电袋。

"明天复盘会之前，"他说，"把休假记录和推送日志的时间线做实。"

他走到门口，停了一下，回头看她。她坐在长条桌末端，笔记本摊开，正把"CHG-20981"和"platform-release"两个词并排抄在最新的一页上，笔迹很稳。

"沈见微。"

她抬头。

他看着她，说了今天对她的第一句完整评价，句子还是那么短，像评审意见：

"白板，以后都这么画。"

门在他身后合上。战情室里，那把梳子在白板上安静地立着——它此刻还不知道，自己只是一个开始。在它后面，还有一条长长的、布满同类齿痕的路，一直通向很多年后一个更大的雪崩之夜。

而路的入口处，此刻只站着一个人，马尾辫，工牌绳挂脖，正低着头，一笔一画地抄写一把梳子。

抄完，她在页脚画了一个问号。

这是她的习惯。每一个还没找到答案的事实旁边，一个问号。

这一页，她画了三个。
