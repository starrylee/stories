# 第十四章 战情室

灵犀的战情室在研发楼三层最深处，平时锁着，门禁权限只对 P0/P1 事故的战时状态开放。

沈见微是第一次进这扇门。跟在江叙白身后刷卡的瞬间，她有一秒钟的错觉——这不像一间办公室，像一间手术观摩室。

一整面墙的监控大屏，此刻全红。屏前一张能坐十二人的长条桌，桌上电源线像 Emergency 病房的地板一样横七竖八。右面墙是一块巨大的物理白板，几乎占了整面墙，白板下沿的凹槽里躺着二三十支各色白板笔，有几支的笔帽是瘪的——被牙齿咬的。门后的挂钩上挂着三件外套，分属三个不认识的人，挂着的样子像还留着体温。

白板正上方，贴着一张打印的 A4 纸，纸边发黄，不知贴了几年：

**先对时间线，再对责任。**

"说。"江叙白把白板笔扔给她。

她接笔的手几乎是本能的——三个月来她习惯了在工位小本子上画推理，但此刻面前是这间屋子里所有还清醒的头脑。她深吸一口气，在白板上写下了第一个数字：

**20:06:31**

"单秒过期量两百三十万。"她在数字后面画了一根针，"正常的 key 过期是下雨，这是钟摆。第一根针落下，命中率塌第一截；十六秒后第二根，十五秒后第三根——间隔稳定，是回建缓存的预热脚本在按固定节拍重新写入同样的 TTL。"

她在针的旁边写下三个数：600 / 1800 / 900。

"商品详情、库存、营销价，三类热点 key，TTL 各自统一成同一个值——没有任何随机偏移。大促预热脚本是批量写入的：写入时间相同、TTL 相同、到期时间就相同。几百万个 key，同一秒集体阵亡，全部回源数据库。不是缓存容量不够，是缓存在同一秒集体不存在了。"

她把最后一行字写完，退开半步。

战情室安静了大概五秒钟。这五秒里，十几双眼睛完成了同一个转变：从"看疯子"到"看答案"。

"证据？"说话的是数据库组的 DBA 老陈，五十岁上下，花白寸头，灵犀最老的一批员工。他问话的时候手里还攥着对讲机，数据库的生死此刻在他嗓子眼里。

"过期速率监控的针尖图，采样分析里抓的 TTL 值，还有——"她翻出手里的记录，"配置变更时间线。TTL 当前值是两周前一次变更之后生效的。变更详情我还没来得及拉，救火要紧。"

"够了。"江叙白说，"方案。"

"三步。第一步，立刻停预热脚本的批量写入，改成错峰分批，每一批之间加间隔，TTL 加随机偏移再写入——掐掉节拍器。第二步，存量 key 没法挨个改 TTL，用批量异步刷新给它们续命，把到期时间打散。第三步，"她顿了一下，看向老陈，"数据库侧再做一层保底限流：宁可商品详情慢三秒，不能让回源把交易链路一起拖死。"

老陈的对讲机已经举起来了："DBA 收到。限流值我按连接数的七成卡——保交易，商品页可以让它死。"

"商品页不能死！"长条桌另一头，商品业务方的电话会议里炸出一个声音，"开抢前十分钟商品页打不开，你们知道损失多少 GMV 吗？"

"死三秒和全死，选一个。"老陈头也不抬。

大屏上，业务方负责人的脸在视频框里涨红。最终是江叙白拍的板："按 DBA 方案。三秒降级换交易链路存活，这个账我来算。"

沈见微看着这个房间运转。指令像血一样从这张长桌泵向全公司的各个末梢，而每个末梢的反馈回流回来，又被消化成下一条指令。没有互相推搡，没有"这不是我的模块"——那些东西在大厅里存在，在 P1 的事故群里存在，但在这间屋子里不存在。

她后来明白为什么门后要挂那三件外套，为什么白板笔帽是咬瘪的。这间屋子只住两种情绪：紧张，和更紧张。

---

20:41，缓存命中率回升到 92%。

21:15，全链路恢复。P0 持续六十九分钟，交易链路熔断二十三分钟，大屏上的红一格一格熄灭，像退潮。

战情室里响起一阵压低的欢呼，有人瘫在椅子上，有人开始低声打电话报平安。行政推门进来派第二波红牛。

就是这个时候，乔曼到了。

她今晚并不在大促值班表上——她是被 P0 事故的升级机制叫回来的：缓存 SDK 归平台条线管，P0 定级之后，条线负责人必须到场。她进门的时候妆容还是完整的，只是呼吸比平时急，高跟鞋在战情室的地板上被地毯吞掉了声音。

"情况怎么样了？"她的声音进门的瞬间就把节奏接了过去，"我刚在大厅看了大盘，恢复曲线很漂亮。是谁定的应急方案？很果断。"

"平台条线的雪崩，"老陈意味深长地指了指白板，"归功于人家小姑娘掐着你的 TTL 节拍器。"

乔曼的目光顺着手指落在白板上——那根针，那三个数，那行"集体阵亡"。她的瞳孔缩了一下，快得像没发生过。

"统一 TTL……"她轻声念出白板上的数字，然后抬起头，脸上已经是全须全尾的专业："这个优化我记得，是缓存 SDK 的档位统一，我们组周昊做的。当时 review 的时候我还提醒过——"她停了半拍，改口，"提醒过要注意有效期管理。这样，现在业务恢复了，我建议今晚到此为止：所有变更操作冻结，配置快照我来安排平台组封存，明天复盘会上再做完整分析。今晚大家都很辛苦了。"

每句话都对。封存快照、冻结变更、明日复盘——教科书级的应急收尾。

"快照我来封。"江叙白说。

乔曼笑了一下："江总，平台条线的资产，按流程还是我们来——"

"证据链我来封。"江叙白重复了一遍，语速没变，"变更记录、配置历史、监控采样，全套。平台组今晚要做的事只有一件：把你们条线的值班交接好。"

战情室里的空气紧了一瞬。乔曼脸上的笑容维持着，眼睛里有什么东西快速地转了一圈——她环视这间屋子，像在重新评估每一个人的位置。她的目光扫过老陈，扫过江叙白，最后落在角落里那个抱着笔记本电脑的沈见微身上。

在那道目光里，沈见微清楚地看见了一样东西——不是感谢，不是欣赏，是一种被探照灯扫过的感觉。

"好。"乔曼最终说，笑容无懈可击，"那就辛苦江总了。另外——"她环顾了一圈，"攻坚组的支援同学，任务完成了也早点回去休息吧？大促还有两天，后面还用得着人。"

这话对着沈见微说，语气体贴得像递过来一件外套。

"她留下。"

江叙白的声音从大屏前过来，没有抬头，像在陈述一个不需要讨论的事实。

"雪崩的时间线，节拍器的证据链，接下来每一分钟的恢复过程——需要有人记录。"他终于转过头，看了一眼角落里的沈见微，又看向乔曼，"她记的东西，我在评优会上领教过，靠得住。"

"打杂也是缺人手的。"他补了最后一句，把视线转回大屏，"她留下打杂。"

乔曼脸上的笑容纹丝不动。

"当然。"她说，"听江总安排。"

她转身走出战情室的时候，步幅和来时一样，高跟鞋的节奏也一样——但沈见微注意到，她扶门框的那只手，指尖在门框上多停了半秒。

门合上了。

老陈凑过来，压着嗓子，用只有旁边两个人听得见的音量说："小姑娘，看见没？"他用下巴点了点门，"刚才那位进门到现在，一眼都没看过大屏上恢复的曲线。"

"负责人到了，不该先看曲线吗？"

"是啊。"老陈慢悠悠地拧开保温杯，"满屋子人都在看曲线，只有她在看人。"

---

那晚剩下的时间，沈见微坐在战情室的角落，干着江叙白口中的"打杂"——记录。

21:15 之后，她记：21:16 预热脚本错峰重写完成首轮回灌；21:22 存量 key 批量刷新打散第一批完成；21:30 命中率 92；22:04 命中率 97.4，逼近事故前基线。

她记的不止这些。

22:15，平台组值班交接，乔曼指定了封存配合人——她组里一个和周昊同工位的工程师。22:40，江叙白调走了配置中心两周前那次变更的完整记录，操作账号一栏，他盯着看了很久，什么也没说。23:05，大厅传来周昊的大嗓门，他在给恢复欢呼，喊"我们组的缓存稳住了"——隔着门，没人告诉他，他的名字此刻正贴在那块白板三米外的一份记录上。

这些她也记了。不知道会用到，不知道哪个字以后会站出来替她说话。

先存档，再判断。

凌晨一点，战情室散了。江叙白最后一个走，走到门口，回头看了眼白板——那根针、那三个数、那句"集体阵亡"还留在上面，没人擦。

"白板别擦。"他对值夜的行政说，"明天复盘会用。"

然后他看见了角落里还没走的沈见微。

两个人隔着空荡荡的战情室对了一秒视线。他没说话，只是抬手指了指她怀里的笔记本电脑——那个动作的意思是：**记完了就回去睡觉。**

她点点头。

他走了。门合上，大屏自动熄灭，战情室陷入黑暗，只剩白板上那些字，在黑暗里凭着记忆的余温存在着。

沈见微合上电脑往外走，路过白板的时候停了一下。

先对时间线，再对责任。

她想起这张 A4 纸在过去的六个小时里被兑现的样子。想起老陈那句"只有她在看人"。想起乔曼指尖多停的那半秒。

她拿出手机，在备忘录里敲了一行字，敲完锁屏，走进凌晨的电梯。

**乔今晚看曲线的时间：0 秒。看人的次数：4 次。**

存疑，先记着。

反正，这间屋子教她的第一课就是——先对时间线，再对责任。责任是结论，而结论，要用时间线里长出来。

电梯下行，一楼大堂空无一人。玻璃门外，大促的第二个白天即将开始，城市不知道昨夜有一场六十九分钟的战争，更不知道战争结束后，真正的战争才刚刚开始——

在配置记录里，在白板笔迹里，在一个个今晚在场的人的记忆里，安静地，开始。
