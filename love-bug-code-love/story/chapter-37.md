# 第三十七章 四小时

**01:47**

战情室的灯是老陈开的。

他到得最早，保温杯放在长桌的老位置上——去年雪崩那晚他就坐那儿，一年半了，位置没变过，杯子换了第三个。沈见微进门的时候，他抬头看了一眼墙上的钟。

"去年那仗，"他说，"是晚上八点开打的。你们年轻人现在流行凌晨两点了。"

"凌晨两点便宜。"老康跟在后面进来，怀里抱着一台笔记本和半袋没吃完的苏打饼干，"流量便宜，窗口便宜，出错也便宜——反正是维护期，天塌了也算天的问题。"

"天塌了也算天的问题"——老康的段子永远带着一种工程学的松弛。但今晚没人笑得彻底。长桌两侧坐定：数据组长带着两个工程师守修复引擎；老康和另一个攻坚组同事守缓存侧；阚工在线上，音频那头偶尔传来她敲键盘的声音；江叙白坐在长桌末端，面前只有一杯水和一支笔。

沈见微的位置在白板前——她的位置。九个月前她第一次进战情室，是站在这个房间的角落里"打杂"；今晚，白板上是她的时间轴，时间轴的左上角写着她的名字。

**02:00:00**

引擎启动。

主屏上的进度条开始走。二百万行修复队列，按优先级分批：客诉用户、活跃用户、长尾。每批一万行，写完一批，校验一批，队列计数减一。

最初的四十分钟是全世界最安静的时刻。没有人说话，只有进度条走动的沙沙声——其实进度条没有声音，那个沙沙声是三个人的椅子在同时微微晃动。老陈每十分钟看一眼缓存侧的大盘，看完报一个字："稳。"

**02:41**

"稳。"

**02:51**

"稳。"

**02:59**

首批二十万行完成，抽检全对。数据组长长出一口气，往椅背上靠了靠。进度走到百分之十，队列的配合比预想的好——按这个速率，四小时绰绰有余，甚至能提前。

沈见微没有松。她的目光不在进度条上，在另一块屏——缓存侧的大盘。她盯着一条曲线：**重建缓存的过期速率**。

修复引擎每重放一行数据，就会在缓存层重建对应的 key。这个动作她在方案评审时过过一遍，当时确认过"写入量在缓存承载范围内"。承载范围内是对的。但她盯着的那条曲线，从半小时前开始，一直在非常缓慢地、非常规整地往上爬。

爬得很有节奏。规整得让她眼熟。

**03:12**

"老康。"她说，"看大盘，右边第二行，过期速率。"

老康凑过去，看了三秒，苏打饼干停在嘴边。

"在爬。"

"不止在爬。"沈见微站起来，走到缓存大盘前面，指着那条曲线的形状，"你看它的形状——不是噪声，是斜率恒定的爬升。每分钟多出来一千二百个 key 的到期，误差不超过十个。"

"均匀到期……"老康的饼干彻底放下了，"均匀到期就是批量写入埋的雷。修复引擎重建 key 的时候，TTL 是——"

"统一的。"数据组长那边的工程师翻了配置，声音一下子紧了，"重放引擎的缓存写入模板里，TTL 写的是固定值，一千八百秒。批量重建，TTL 统一——"

他说到一半自己停住了。房间里安静了一秒，然后所有人都在同一瞬间想明白了。

**三十分钟前批量写入的 key，将在三十分钟后批量过期。**

现在是 03:12。引擎 02:00 启动。第一批 key 的 TTL 一千八百秒——三十分钟——02:00 写入的那批，02:30 过期，已经过去了；02:30 写入的那批，03:00 过期，正落在现在；而爬升的斜率意味着：写入的速率在增长，过期的速率就在增长——**再过五十分钟，第一批大规模集中过期会撞上队列进入活跃用户段之后的写入峰值。**

集中过期撞上集中写入，缓存命中率雪崩式下探，业务请求穿透到数据库——

去年十一月，那场六十九分钟的 P0，就是这个形状。

"这个病，"沈见微听见自己的声音在战情室里响起来，很平，"我治过一次。"

**03:15**

她已经在白板前了。

"看这条爬升曲线。"她一笔画出过期速率的延伸线，再画一条写入速率的曲线，两线在白板右侧交汇，"交点在四点钟附近——正好是队列跑到活跃用户段的时候。活跃用户段，单用户关联行数是长尾段的三倍，写入速率翻倍，过期速率同步翻倍——两倍的两倍，四倍尖峰。"

"缓存集群能扛四倍尖峰吗？"数据组长问。

"扛不住。"老康替缓存回答，脸沉下来了，"扛不住就穿透，穿透就打 DB，DB 一限流，业务就——"

"现在是维护窗口，业务量是平峰。"阚工的声音从音频里切进来，快而稳，"但窗口六点结束，如果雪崩链拖到六点以后，早高峰撞上来，去年十一月的事故复播。"

战情室里所有的目光都汇聚到一个问题上：怎么办。

数据组长的第一反应是常规操作："停引擎。TTL 模板改掉再跑。停下来重新配置，需要——"

"需要多久？"

"重启、加载、校验队列状态，至少二十分钟。"

二十分钟停机加重启，四小时的窗口就吃掉了整整一段，06:00 全量完成的承诺直接作废——而雪山银行的对接群明早八点要看结果。

"不用停。"沈见微说。

所有人都看她。

"两个动作，都不用停引擎。"她在白板上写下两行字，"第一，改 TTL 模板，加随机抖动——每一批新写入的 key，TTL 在基准值上浮动的正负百分之二十。这一条改的是增量，改完之后，后面的写入不会再生出集中过期。改配置是热生效的，引擎不用停。"

"第二，"她的笔移到第二条，"存量。过去七十二分钟已经写入的 key，抖动救不了它们——它们 TTL 是齐的，四点左右集中到期。对存量做异步续命：起一个旁路任务，把已写入的 key 的 TTL 逐个打散重设——不删数据，只改过期时间。续命任务的速率控制在每秒两千，不抢业务带宽。"

她把两条线的末端连到时间轴上："存量打散在四点前完成，四点钟的到期尖峰就摊平成缓坡。引擎全程不停，进度条继续走，窗口保住。"

白板上，一条原本陡峭如悬崖的过期曲线，被两笔改写成了平缓的斜线。

战情室安静了两秒。数据组长盯着白板，脸上的表情是那种"方案听懂了、但决定不敢自己做"的表情——这是他的引擎、他的配置、他的责任区间，改 TTL 是缓存侧的操作， Cache 不是他的辖区，他需要一个人点头。

他看向长桌末端。

江叙白从进来之后没说过一句话，此刻也没打算多说。他看了白板三秒钟——从曲线到两行字到时间轴——然后收回了目光，只说了四个字：

"她说了算。"

**03:21**

老康带人去改 TTL 模板。热生效，三十秒后，新写入的 key 开始带上随机抖动——大盘上，爬升曲线的斜率肉眼可见地钝了下去。

沈见微自己写存量续命脚本。旁路任务，每秒两千个 key 的 TTL 重设，打散窗口九十秒——她在写第三行的时候听见自己的心跳，很稳。这套动作她熟得不像话：TTL 打散、异步续命、速率控制——去年十一月的雪崩之夜，这三板斧是她在战情室里被逼出来的应急三步；后来写进了 TTL 治理的整改方案，成了全公司的标准动作。

标准动作。可是数据组的重放引擎里没有它——不是谁失职，是制度还没长到那儿：整改方案落地在缓存条线的系统里，不覆盖数据条线新建的工具。

她在心里给笔记本预定了一行字：**好方案会繁殖，但繁殖得比系统慢。**

**03:44**

续命任务跑完存量前段。大盘上，四点钟的到期预测尖峰，从一座山，摊成了一道坡。

"预测过期峰值下修百分之七十一。"老康盯着屏幕念出数字，然后忍不住加了一句他自己的注解，"去年这玩意儿塌的时候，我们用了三个小时。今年从发现到摊平，三十二分钟。"

"不是我们快了。"老陈在长桌那头拧开保温杯，慢悠悠地说，"是这丫头认得它了。病还是那个病，大夫出过一次诊。"

**04:00**

中点校验。一百万行完成，抽检三轮，全对。

四点整——三十分钟前白板上预言的"尖峰时刻"——平稳度过。过期曲线趴在基线附近，像一头被驯服的兽。没有人欢呼，但战情室里的空气松了一格，有人起身去接水，老康的苏打饼干袋重新响了。

沈见微坐回自己的位置，盯着进度条。百分之五十，五十一，五十二。

她忽然发现自己在等一件事：等一个人说点什么。长桌末端那个人，从"她说了算"之后就再没出声，此刻正低头看他自己带进来的一沓材料——一份和今晚无关的架构文档，看得投入，好像这间战情室里正在进行的一切与他无关，好像三十分钟前那四个字不是他说的。

好像"她说了算"这种话，说出口之后就不需要盯着兑现。

**05:47**

进度条走完了最后一格。

二百万行，全量重放完成。比承诺的 06:00 提前十三分钟。

终校验开始。数据组的三轮校验，从 05:47 跑到 06:05——晚五分钟，全对：客诉用户数据回正，关联表交叉一致，错行计数归零。

06:05，数据组长在灰度事故的对接群里，敲下了那句话：

"双写回滚全量完成。二百万行修复，三轮校验通过，错行清零。详细报告上午补发。"

群里安静了几十秒。然后，雪山银行那边的对接人——一个从头到尾潜水的技术总监——冒出来了，只发了一句话：

"收到。这个修复方案的工程严谨性，我们认可。"

又过了十几秒，第二条：

"想请教一下——报告里提到的染色轨迹分析和续命方案，署名的'沈工'，是哪位？我们行的技术团队想认识一下。"

**06:06**

战情室里，老陈把这条消息念了出来。

念完，房间里安静了一下，然后哄的一声笑了——不是大笑，是那种熬了一整夜之后，所有紧绷的东西一起松掉的声音。老康笑得最响，边笑边拿饼干袋拍桌子："'哪位'！老陈你听听，人家问'哪位'！"

"人家客户问的是哪位，"老陈慢悠悠地拧上保温杯，"问得对。去年这个时候，'沈工'这两个字，全公司知道的人一只手数得过来。今年人家银行的技术总监专门问——"

他没说完，摆了摆手，好像"说完"这个动作都嫌费劲。

沈见微站在白板旁边，脸有点热。她低头去看自己的时间轴——四个节点全部完成，最末一行"06:00 全量完成+终校验"旁边，被谁用红笔打了一个勾。勾打得很大，一笔下来，带着整夜的疲惫和痛快。

然后她看见了白板左上角自己昨晚写的那三个字。

**担保：沈见微。**

三个字下面，多了一行新的，不是她的笔迹——是老康那种龙飞凤舞的字，什么时候写上去的，她没看见：

**见证：攻坚组全体。另附：缓存侧官兵若干，DBA 一名，晨光万丈。**

她盯着那行字看了很久，喉咙有点堵。九个月前她站在这间战情室的角落里，是个连白板笔都轮不到用的打杂的；今早她写在白板角落的军令状，被人添了一整行的见证。

窗外，天已经亮透了。五月的晨光从战情室的窗户平射进来，照亮了长桌上散乱的空咖啡杯、打印稿、老康的饼干袋，和一块写满了曲线与时间轴的白板。晨光爬上白板，把那些字迹一一照亮：两行方案，一条被驯服的曲线，四个打勾的节点，三字担保，一行见证。

江叙白是最先走的。他收拾东西的动作很轻，走到门口的时候，晨光正落在他的侧脸上。他停了半秒，回头看了一眼——不是看她，是看整间屋子，看这片狼藉，看这块白板。

然后他对着屋子里所有还瘫在椅子上的人，说了一句他今晨的第二个整句：

"都回去睡觉。报告下午再写。"

门关上了。

---

沈见微是最后走的。

她把白板擦干净——从曲线擦到时间轴，从担保擦到见证。板擦划过"沈见微"三个字的时候，她停了半秒。

擦掉之前，她拿出手机，把整块白板拍了一张照片。

照片存进相册，她想了想，又把它存进了一个地方——网盘，monthly-archive-01，那个加密文件夹里。文件夹里躺着的都是问号和证据，这张是第一张例外：

**不是问号，是句号。**

军令状兑现了。四小时，二百万行，一场差点复播的雪崩被摁死在白板上。她的名字第一次出现在一份被客户方认可的报告里，第一次被一个陌生的技术总监郑重其事地问起——"是哪位"。

是哪位。

她关灯，走出战情室。走廊尽头的窗户全部亮着晨光，电梯下行的时候，镜面里那张熬了一夜的脸，眼睛却是亮的。

这个问题——"这位沈工是谁"——今晚只是一个客户对接群里的礼貌性提问。

但她有一种预感。这个问题的答案，会有一天不止是"攻坚组的沈工"。它会长，长成行业内一个不需要解释的名号，长成一份份复盘文档角落的署名，长成很多年后某个年轻人念出来时会挺直腰背的三个字。

从今晚这四小时开始，钟已经上弦了。

走出大楼的时候，早班的班车刚好进站。五月的早晨，风里全是新叶的味道。她掏出手机看了一眼——对接群里，雪山银行那位技术总监又发了一条，是补发的：

"修复报告出来后，请抄送我一份。署名页——保留全部人的名字。"

她看着"保留全部人的名字"七个字，站在晨光里，笑了一下。

然后收起手机，走向班车。

睡了这一觉，还有很多仗要打。
