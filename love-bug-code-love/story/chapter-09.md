# 第九章 第一次救火

故障是从周二开始出现的，很轻，轻得没人拿它当回事。

推送中心，批量推送任务偶发超时。一天三到五次，每次只挂一两个任务，五秒后自动重试，重试全部成功。P3 级别，连告警群都只是懒洋洋地弹一条黄色消息：**推送任务 21874 执行超时，已自动重试成功。**

真正让人不舒服的是第五天。

到周五中午，超时累计四十一次，仍然全部重试成功，仍然无规律——早上九点有，下午三点有，凌晨两点也有；大任务超，小任务也超；同一个通道昨天超今天就不超。值班工程师张伟盯着告警曲线看了一下午，最后在值班群里留下一句话：

"这玩意儿要么自己好，要么等它变大。现在的信息量，够不着。"

没人反对。这就是偶发故障的宿命：数据不够，规律不显，监控全绿，日志干净。应用没有重启过，依赖服务没有抖动过，数据库慢查询为零，网络重传为零。一个健康的系统，在随机时刻随机地超时——像一个人体检全正常，但每天随机心悸两次。

下午两点，因为推送中心在平台条线、而攻坚组的灰度放量课题恰好要复用推送通道的影子流量，老康被拉去支援排查，顺手把沈见微也带上了："多双眼睛。你就当打杂，端茶倒水递日志。"

战时还没到开战情室的程度，就是研发区拉了个临时排查群，十几个人，两块屏幕，一白板写满了划掉的假设。

"连接池？"有人问。

"看了，池子水位常年百分之三十，峰值都没满过。"

"线程池？"

"队列深度为零。"

"下游限流？"

"下游说他们什么都没干。"

白板上的假设一条一条增加，又被一条一条划掉。到下午四点，划掉的红线比假设本身还多。

沈见微坐在最角落，干着她被拉来干的活：递日志。有人要看哪个时间段的应用日志，她就按时间戳切出来发过去。三个小时，她切了四十多份日志。

递日志这个活儿有个别人不太在意的好处：每一份日志都是同一个系统在同一批超时事件周围的切片，切多了，切片之间会互相说话。

到下午五点四十分，她发现了一件很小的事。

她把它写在了自己的草稿纸上，没敢直接说——一件这么小的事，在一个十几个人排查了三个半小时的群里，说出来是需要点脸皮的。她先自己验了一遍：四十一次超时，她把每一次的时间戳单独摘出来，贴到流量监控的曲线上。

四十一个点，全部落在曲线的谷底。

不是随机。超时从不发生在高峰，全部发生在低峰——任务队列越闲的时刻，越超。

她盯着这四十一个点看了两分钟，忽然意识到自己可能碰到了那个"够不着"的信息量。忙的时候不超、闲的时候超，这个规律反直觉到没有一条已有假设能解释它——所以大家找规律的时候，都本能地在"忙"里找。

她举手的时候手心有点出汗。

"我说个现象。"她说，"四十一次超时，全部发生在流量低谷。"

群里安静了一秒。有人立刻把她的点贴上大屏。

四十个红点撒在流量曲线上，像一串脚印，全部踩在谷底，一个山头都没翻过。

"……为什么闲的时候超？"张伟喃喃。

"因为闲，"沈见微已经在翻她那沓日志切片了，"所以池子里的连接一直没被用。"

这句话说完，排查方向在三十秒内完成了集体转向：连接在空闲状态下发生了什么。

空闲连接、超时、任务来了却拿不到可用连接——三个词拼在一起指向一个所有人第一轮就查过、因而第二轮不太好意思再查的地方：连接池的配置。当时查的是池子水位和最大连接数，都对。现在要查的是另一组参数：空闲回收时间、保活间隔、最小存活。

"推送中心的连接池配置，最近有人动过吗？"

没人动过。配置平台的变更记录干干净净——上一个变更在三个月前。

配置没变。那什么变了？

"配置没变的话，"沈见微慢慢地说，"让配置生效的东西，变了。"

代码。

---

六点二十，她坐在自己的工位上，面前摊着推送通道服务最近一个月的合入记录。三十七个提交。

老康端着泡面凑过来："你怎么看这个？三十多个 diff，一个一个看要看到明天。"

"不用全看。"她滚动着列表，"看发布日期。故障第一次出现是周二。上一次发布是上周三。中间隔了六天——如果超时是这次发布带进来的，前六天是它攒概率的时间。"

她把上周三那次发布包含的提交单独滤出来：五个。

第一个，业务需求，改动在订单文案组装模块，无关。第二个，依赖升级，锁文件三百多行，无关。第三个，第四个，都是小改动。

第五个，提交说明写着：**"调整连接池空闲回收策略"**。

她点开 diff。改动很小，两行：

```
- idleTimeout: 600000
+ idleTimeout: 30000
```

注释，一行小字，趴在两行改动的下面：

```
// 临时：测试环境连接数不够，把空闲回收调小先顶着，上线后改回
```

上线后改回。

她翻这个提交之后的所有记录。没有"改回"。六天了，"临时"两个字还活着，活在生产的每一个连接池里。

"十分钟回收变成三十秒回收，"她跟张伟说，"低峰期任务间隔经常超过三十秒——池子里的连接一闲下来就被回收。下一批任务到的时候，池子在建新连接，建连接要握手、要鉴权，冷启动一两秒，超过五秒的任务等待阈值就是超时。高峰期任务一个接一个，连接永远'不闲'，永远不会被回收——所以忙的时候从来不超。"

她在白板上画了条时间线：任务与任务之间那道超过三十秒的空隙，像退潮后的滩涂——连接是搁浅的鱼，三十秒内没有被下一个浪头救走的，就被回收了。

"重试为什么都成功？"

"因为重试的时候，池子已经把新连接建好了。"她说，"所以这个故障永远'自愈'，也永远不改。它只有在你闲的时候咬你一口，忙起来它就装死。"

白板前安静了几秒。张伟一拍脑门："我说呢！我盯着告警想找规律，全盯着高峰那几个毛刺看——"

"高峰的毛刺是正常的毛刺，"沈见微说，"这种故障的脾气是反的。它不咬忙人，专咬闲人。"

有人已经开始在群里发结论，发修复方案：idleTimeout 改回十分钟，当晚发布窗口就走紧急通道。

按理说，到这就结束了。定位、修复、验证、复盘，一条流水线。

但沈见微多做了一件事。

她盯着那条注释，"临时：测试环境连接数不够"，多看了一会儿。测试环境的问题，改在生产代码里，用一行注释标记"上线后改回"——这个做法本身，就是事故。于是她顺手点开了这个提交的评审记录，想看看 review 的人当时说了什么。

评审记录只有一行：

**批准合入：QM-qiaoman（上周三 21:47）**

提交时间：上周三 21:45 48 秒。

提交到批准，间隔九十秒。

一个改动连接池核心参数的提交，两行代码加一行"上线后改回"的注释，在九十秒内走完了 review。她想起自己那个改了个函数命名的提交，江叙白看了一整晚——当然，那个评审记录里也有一行字，"思路可以。命名不行。"

她没多想，把评审记录的截图存进了"工作留痕"。职业习惯，先存档，不判断。

---

当晚十点，修复上线。此后四十八小时，超时为零。

复盘会定在下周一，临时排查群解散前，张伟在群里发了长长一段感谢，最后@她："沈工那个'低谷聚类'的分析思路，能不能整理成文档？我想放进推送中心的故障手册。这毛病我们组两年里出过三次类似的，每次都是不了了之。"

她回了个"好"。

十一点，她整理完文档初稿，检查最后一遍的时候，发现群里有条新消息。是江叙白——他从头到尾没在排查群里说过话，此刻也只发了一行：

**"低谷聚类。这个词可以。"**

没有夸人。夸的是词。

沈见微看着那五个字，莫名其妙地笑了一下，又赶紧收住。她回了个"收到"，关掉电脑。

走出研发楼的时候她想，这篇文档的标题就叫《低峰期偶发超时的空闲连接回收竞态分析》好了——太长，缩一下：**《闲出来的超时》**。

嗯，还是正经点。毕竟是故障手册。

---

同一个晚上，十一点半，乔曼还没走。

她坐在自己的办公室里，面前的屏幕上是那条复盘消息——故障定位结论的全文，她看了三遍。

空闲回收、低谷聚类、临时注释、九十秒。

她点开那个提交的评审记录，看着自己的账号名和那个时间戳：21:45:48 提交，21:47:11 批准。她记得那天晚上自己在干什么——在赶季度汇报的 PPT，同时挂着五个待办，组里的小蒋在群里@她："乔组长，这个 MR 今天必须走，测试环境还等着合入重建呢，您过一下？"

她点进去，扫了一眼——两行配置，一个"临时"注释，改动方向是"调小"，不会引发容量问题。测试环境等着。发布窗口在九点五十。她点了批准。

九十秒。她连那行注释的后半句都没读完。

现在，这九十秒躺在评审记录里，被贴在了十几个人看过的定位结论旁边，被写进了一篇要进故障手册的文档——文档的作者署名，沈见微。

乔曼靠在椅背上，办公室的灯只开了她头顶一盏，光圈之外的黑暗把她整个裹住。

她不怕这个。真的，她告诉自己，这算什么？一个 P3，一个非蓄意的临时改动，一个她正常履职的 review 批准。复盘会上她只需要说一句"流程上确实疏忽了，以后测试环境的调整走配置不走代码"——体面，无懈可击。这种事在哪家公司一周不出三回？

可让她后背发凉的不是这个。

是那个女孩看东西的方式。

四十一次超时，所有人在日志里、监控里、依赖关系里翻了一下午，她递了三个小时日志，然后把四十一个点撒在流量曲线上——全在谷底。然后是发布日期，然后是五个提交，然后是两行代码下面的一行小字。每一步都不惊人，连起来就是一条直线，直直地通到她的批准记录上。

不是怀疑。乔曼很清楚那不是怀疑——沈见微甚至没有在群里提"谁批准的"这四个字，她只是在做她那种把一切推到底的归因，像一台不知疲倦的机器。

这就是可怕的地方。她不是冲着谁来的，但她路过的地方，所有习惯性潦草的痕迹都会被照亮。

乔曼在黑暗里坐了很久，然后打开抽屉，拿出自己的记录笔，在笔记本上写了一行字。写完看了看，又慢慢划掉了。

划掉的那行字是：以后合入前，看清楚注释的每一句。

她重新写了一行：

**别再让任何东西，经我的手留下时间。**

窗外张江的夜空是暗红色的。她关掉最后一盏灯，高跟鞋的声音在空无一人的走廊里响得很清，一声，一声，直到电梯门把她吞进去。
