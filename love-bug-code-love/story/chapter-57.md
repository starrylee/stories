# 第五十七章 学历

周六早上九点差五分，温遥的电话先到了。

"你先别打开圈内。"电话那头的声音很稳，稳得刻意，"听我说完，你再自己决定看不看。"

沈见微一边把水烧上，一边听。温遥用三句话讲完了：圈内昨晚出了个热帖，关于她的学历，现在热榜第三，评论两万多条。

"我知道了。"她说，"我现在就看。"

"微微——"

"温遥，"她打断她，语气很平，"看和不看，它都在那儿。"

她挂了电话，坐到窗边的桌子前，打开了那个 app。

《大厂新贵女工程师的学历罗生门》。

她从头到尾读了两遍。第一遍用眼睛，第二遍用笔记本。

帖子的主体是三段。绩点二点三，专业排名后百分之八；三年六次约谈，奖学金四年零记录；破格录取，流程特殊。

她在笔记本上把三段抄下来，然后在每一段后面画了一个勾。

真的。真的。也是真的。

这就是它毒的地方。她盯着那三个勾，心里安静得近乎冷酷——谎话是可以拆穿的，一个伪造的仓库她能在四个小时内验尸出三刀；可真话的排列没法拆穿。真话的排列，只能认领。

她在页脚写：

**每一颗子弹都是真的。枪法是假的。**

评论她已经不用逐条看了。翻到热评第一，那句话挂在那里，两百多赞，还在涨：

"好学校里的差学生，也配代表大厂技术？"

她的目光在这行字上停了几秒。四年前，在另一间机房，有人当着半个实验室的人说过一句几乎一样的话。那时候她没有回答，只是低着头，把手里的第七版代码改完了。

这一次她也没有回答。她做的是另一件事：把热评、楼层结构、发帖时间，一页一页截图存档。

---

中午之前，她把整个帖子解剖完了。

笔记本上多了三行结论。

第一行，手法。这个帖子和十一月那个只活了一百四十分钟的论坛帖，是同一双手——真话排列，收割现成的疑问。区别只在载体：论坛有管理员，匿名社区没有。她当时的预判一条条应验：会写这种东西的手不会只写一次，下一次载体就不是论坛了。

现在是下一次了。

第二行，水军。前四十条评论，十一分钟铺满，间隔均匀。她借了一个爬虫脚本，把账号注册时间拉了出来：八成七的账号，注册于最近三十天。评论长度整齐地落在十五到二十五个字之间——真人的抱怨是长短不齐的，只有任务才这么整齐。

第三行，是她写到一半停了很久的一行：

**对方不在系统里了。在人群里。**

系统的仗她打了两年，输赢都有章法。人群这一仗，没有白板可画。

下午三点，手机震了一下。江叙白发来一张图，没有说明文字。

是一张直方图。横轴：账号注册时间。纵轴：数量。最近三十天的柱子高得像一面墙。是他自己爬的数据——她的爬虫下午一点才跑完，他的图比她的结论早到了两个小时。

图下面跟着一行字：

"水军。帖子的半衰期三天，你的 commit 半衰期是永远。别回。"

她回："知道了。"

想了想，又补了两个字："谢谢。"

对面没有再回。她知道他不需要这个谢，就像他知道她不需要那句"别回"之外的任何安慰。一张图和一句判断，一个替她省了两个小时，一个替她省了三天——三天，正好是热帖的半衰期。

傍晚温遥又打来一个电话，问要不要公司出面。

"公司出面，就变成公司的事了。"她说，"这是冲我来的。我自己接。"

"怎么接？"

"还没想好。"她看着笔记本上那三行字，"但我知道第一步是错的——发帖对骂。人群不听道理，人群只听故事。他们有故事，'差学生的罗生门'。我没有故事，我只有……"

她停了一下，翻到笔记本的某一页。那一页抄着四年前的一份 commit 记录。

"我只有时间戳。"

---

周一，公司里的空气换了一种成分。

走廊里的目光变得复杂：三分好奇，三分探究，还有四分是刻意的躲闪。茶水间的谈话在她进门时低下去半拍，又若无其事地续上。有人在电梯里对她格外客气——那种客气她认识，是人们对待"出事的人"的客气。

上午十点，HR 总监约她谈话。办公室的门关着，对方的态度诚恳得近乎小心："公司方面的态度是明确的，提名不撤，鉴定照走。只是当前这个舆情环境，我们建议你——降低一点曝光。下个月的沙龙邀约，是不是先缓一缓？等风头过去。"

"风头是他们的产品。"她说，"我停一次，他们就知道这个产品有效。下一次，剂量会加倍。"

HR 总监沉默了几秒："这个说法……有道理。但你一个人扛舆论，压力会很大。"

谈话结束的时候，程亦朗在走廊上等她。休闲西装，没打领带，手里拿着一杯咖啡，像只是路过——他等她的姿态，永远做得像只是路过。

"帖子我看了。"他说。停了一下，把下一句说得很慢，"这次，我真的删不掉。"

她也停了一下。两个人都记得十一月那次，一百四十分钟。

"但我能做的我都做了。"他说，"提名不撤，鉴定照走，法务在评估匿名社区的追责路径——虽然我个人不乐观。剩下的事——"他看着她，那双总是笑着的眼睛难得没有笑，"你自己决定要不要接，怎么接。公司不替你做这个决定。这是我能给你的位置。"

"我接。"她说。

程亦朗点点头，转身走了两步，又回头补了一句："沙龙的事，不用缓。你要是想上台，舞台是你的。"

中午，圈内出现了全站少见的实名长评——《我，周昊，被她救过清白的人》。三百字，火力十足，句句都是雪崩案的第一人称视角。评论区质疑他"收了钱的吧"，气得他中午多吃了两碗饭，下午在工位上气鼓鼓地又编辑了一版，加了一句："我实名，工牌号 u182556，欢迎来查。"

---

真正的转折，不在公司里。

周一深夜，她开源仓库的 issue 列表里，多了一个新的 issue。发起人是一个 2019 年的老用户，标题起得很朴素：

《关于"学历"——我这个 2019 年的 star 有话说》

正文不长。贴了一张截图：2019 年 3 月到 6 月，她的仓库 commit 时间分布。两百一十四个提交，落在凌晨一点到五点之间。

"她绩点多少，我不知道，也不关心。"那位老用户写道，"我只知道 2019 年的那个春天，我在凌晨两点提过一个 issue，十一点钟收到了回复——我当时就好奇，什么样的人这个点还醒着。后来我数了数：三个月，两百多个 commit 落在这个区间。学校在量她什么，是学校的事。git 在量她什么，是白纸黑字。"

这个 issue 发出来两个小时，底下跟出了一条长长的尾巴。

一个早期贡献者认领了自己 2020 年提的第一个 PR——"she reviewed it at 1:47 a.m.，留了七条意见，第五条我记到今天。"另一个用户贴出她凌晨修 bug 的恢复记录。有人翻出 star 曲线，和她的学期时间轴并排放在一起："每个期末，曲线就掉一次——她在考试。每个假期，曲线就涨一波——她也在干活。四年看下来，三千一百四十七个 commit。"

跟帖的最后，有人把这句话顶了上去：

**学校量不出的东西，git 都记着账。**

周二早上，这条尾巴被搬运进了圈内，搬进了微博，搬进了几个技术社区。舆论的水位开始往回漫——不是反转，是稀释。嘲讽还在，但"两万条"变成"两万条对一万条"，然后是"对三万条"。

周二晚上，沈见微坐在出租屋的桌前，把作证长帖从头到尾读了一遍。

读到第三遍的时候，她做了一件这一年很少做的事：把每一条作证，一条一条地点了感谢。不是策略，不是存档习惯——就是想点。凌晨一点四十七分那条回复的作者，她多看了很久。四年前那个凌晨她自己都不记得了，但有人替她记得。

然后，她翻到了那条回复。

在长帖的中段，一个 ID 很老的账号，留言只有四行：

"2018 年 11 月，这个仓库第 47 个 star 是我点的。那年冬天，我陪她在机房 debug 到凌晨四点。她的绩点我不记得了——我只记得那晚整个机房只剩一盏灯，灯下那个人，在改第 13 版。"

她的手指停在了屏幕上。

shiguang。

注册时间：2018 年 11 月。六年没换过头像，一只像素风的小台灯。

机房的灯。第 13 版。第 47 个 star。这三个数字像三把钥匙，同时捅进了同一把锁——锁后面是 2018 年的那个冬天：暖气坏掉的机房，凌晨四点，一件盖在椅背上的外套。

她盯着那个像素小台灯看了很久，然后点开了私信输入框。

光标闪着。她打了一行字，删了；又打了一行，又删了。第三遍，她留下了七个字：

"shiguang。好久不见。"
