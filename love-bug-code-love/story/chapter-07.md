# 第七章 深夜便利店

瑶光风险期最紧的那一个月里，有一件小事，沈见微记了很久。

事情的起因是值班。瑶光进入联调冲刺之后，门户组认领了联调期的发布值班——值班表排得公公正正，每个模块负责人轮流上岗，负责发布窗口的值守、监控盯盘和第一响应。

轮到沈见微的那一周，是整个排期里最不巧的一周：周三晚上有一个客户侧的紧急变更窗口，周四晚上是例行的灰度发布，两个窗口背靠背，中间只隔一个白天。值班表排出来的时候，这一周被标成了"重活周"，白纸黑字，谁都看得见。

没人给她穿小鞋——这是排期和风险期的发布密度决定的，谁来轮到这一周，都是这一周。老宋在排值班表的时候甚至说了："这周要不行我替你值一天。"

她没让替。"没事儿，我的链路，我的值班。"她说，"替了，出事的时候你接不住。"

于是周三晚上十点，发布窗口开启，她一个人守在工位上。

那天晚上的变更本身不复杂，但验证很熬人——变更之后要盯四十分钟的核心指标，每小时一轮巡检，任何抖动都要当场判断"是变更引入还是环境噪声"。四十分钟过完，第一轮巡检过完，时间已经过了十二点。她揉着眼睛看了眼监控，全绿，去茶水间泡了杯咖啡。

泡完咖啡回来的路上，她路过白板区，忽然发现白板上多了一行字。

那行字是用白板笔新写的，字迹清瘦有力，写在她课题排期图的旁边：

**"灰度放量观察项：增加长尾场景采样。深夜流量形态与白天不同，别用白天结论推夜间行为。——江"**

时间戳显示是四十五分钟前。

她愣住了。四十五分钟前，是变更窗口刚开启、她埋头盯第一轮验证的时候——那个人在。他在她盯盘的同一时刻，路过（或者专程走过）她的白板，把她课题里一个她自己都没意识到的高度，补了一笔，然后没打招呼，走了。

她盯着那行字看了一会儿，掏出手机拍了张照。

拍完，她忽然注意到另一件事——那行字旁边，白板笔的笔帽没有扣回去，而是搁在了笔槽的最边上。这个细节很轻，轻到像什么都不是。但她见过这个人评审系统里的批注风格：所有评论落款只有一个"江"字，从不写称呼，从不写"辛苦"，从不写任何情绪。

连补一行白板，都是她的课题长在了他的巡场清单里的样子。她不知道他今晚为什么还在公司——他的行程里没有值班，没有变更，没有她能想到的任何理由。

---

周四晚上的灰度发布，轮到她值第二个班。

这个晚上更熬。发布本身出了个小插曲——一个下游服务的配置在灰度环境里串了版本，导致她的影子验证链路在灰度第一轮出现了报警。报警是误报，但要证明它是误报，就得把链路的每一段日志拉下来，逐段比对。她从十点弄到凌晨一点半。

一点四十，她收拾东西下楼，在楼下便利店又撞见了江叙白。

这是第二次。这一次两个人都懒得假装惊讶了。他站在关东煮的柜台前，手里端着纸碗，看见她进来，抬了抬下巴，算是打过招呼。

她拿了咖啡，犹豫了一下，走过去在他斜对面坐下。便利店的窗玻璃上映着两个人的影子，张江的灯火在玻璃外面铺开。

"误报？"他先开口。他居然知道。

"串版本。下游的锅，明天让他们改。"她说，"你怎么知道我在……"

"评审系统里有你的灰度发布单。"他说，"单子挂了三个小时没闭环。"

"……你半夜看发布单？"

"瑶光期间，所有涉及发布的评审，我过。"他重复了一遍自己到任第一天说过的话，然后把最后一口关东煮吃完，"我说过的。"

她看着他起身去结账。收银台的小票打出来，他撕下来捏在手里，走的时候只说了一句：

"下次误报，先看时间戳。串版本的报警，时间特征是齐步走——一整批同时红。真故障的报警是散的。"

门上的风铃响了一下，人走进夜色里去了。

沈见微坐在原地，望着他渐渐消失的背影，久久没有收回视线。她低头翻开随身的笔记本，把这行话记了下来。记完她看了一眼手机——凌晨一点五十七分。

第二天是周五。她照常上班，中午的时候，老宋拿着新的值班表走过来，脸上带着点古怪的表情：

"晚上那份灰度值班的排班，调了。"

"调了？"

"你下周二那个值班窗口，挪给老张了。"老宋挠着头，"说是架构评审需要——江总点名要老张下周二参与一个架构评审的旁听，时间正好冲突，值班就得换人。换完之后，你的重活周就……轻了。下半周两个窗口，一个都不用你值了。"

"谁批准的调换？"

"江总签的字。"老宋把值班表拍在她桌上，"流程走得干干净净——旁听是真实的，评审是真实的，调换理由充分，谁也挑不出毛病。就是，"他压低声音，"我就是纳闷，老张上周刚旁听过一场架构评审，怎么这周又要旁听。旁听这种事，一个月一次是学习，一周两次是……"

他没说完。但沈见微听懂了。

她低头看着那张新的值班表。白纸黑字，流程干净，理由充分——和上周那块白板上的字一样，和深夜便利店那句"先看时间戳"一样。所有的事情都藏在"顺理成章"里，没有一件事可以被指认成"照顾"。

她忽然想起入职第一天听来的那个段子——"这段代码谁写的，站出来"。此刻她意识到，这个人的语言系统里大概永远没有"我来帮你"这四个字。他的照顾，全部长成"流程"的形状。

中午在食堂，温遥凑过来，压低声音："哎，跟你说个事。昨晚我加班到两点，走的时候看见你们瑶光那层的灯——就江总那间办公室的灯，亮到两点。"

"他昨晚在。"沈见微说，"便利店碰到了。"

"又碰到？"温遥的眼睛亮了，随即又收住，用很公事公办的语气说，"哦，那可能就是巧。"

沈见微扒着饭，没接话。但她心里把这件事翻了个面：上周白板上的字，昨晚便利店的"顺路"，今天那张重活周消失的值班表——三件事，没有一件可以被单独指认。连在一起看，是一个人在她完全看不见的地方，把她的"重活周"悄悄搬空了，然后一次面都没露。

她不知道自己该用什么情绪接住这件事。

感激？他做的事配不上这个词的重量——那更像一种工程行为：识别出一个即将过载的节点，在她自己还没意识到的时候，先把负载卸掉。

不平？更谈不上。流程干净得像教科书。

她最终选了第三种反应：打开"工作留痕"，新建文档，把三件事的时间戳并排列了一遍——白板批注的时间、便利店的时间、值班表调换的签字时间。

列完，她在文档末尾敲了一行备注，敲完想了想，又没有删：

**这三件事互相独立，来源不明。但它们有一个共同点：发生的时间，全部在我看不见的深夜。**

**存档，不判断。**

她不知道的是，这些深夜的"独立事件"，在未来的很多年里，会被她自己一条一条重新翻出来——在战情室的白板上，在五年后的书桌前，在一张叫 hername.v1 的文件夹里。

守护的痕迹链，此刻只是开了个头。头开得无声无息，像所有深夜的灯光一样，只对看得见它的人生效。
