# 第一百一十二章 全站打不开

战情室的灯，是从下午两点开始亮的。

后来复盘的时候，那一天被拆成了分钟。但当时站在里面的人，对时间的感受只有一种：**塌方的速度。**

上午九点十分，客服系统收到第一批用户反馈："官网打不开。"九个字，被客服按惯例归类为"个案网络问题"。

九点四十分，反馈量突破三百。数据分析部的值班同事拉了一下地域分布——华东、华南、华北，都有。**不聚堆。**散点状的故障，像雨点落在一张白纸上，看不出形状，但纸正在变湿。

十点半，运维群炸了。第一批全面排查开始。

排查的顺序是标准的教科书顺序——因为教科书就是这么写的：**从应用层开始。**

十点半到十一点，应用层自查：服务进程全在，端口全监听，应用日志无异常。健康检查——**全部通过**。这是这一天最诡异的画面：所有的服务都在说"我很健康"，所有的监控都在画绿色的线，而用户在电话里、在微博上、在合作伙伴的群里，一遍一遍地问：你们是不是倒闭了。

十一点，排查转向网络层。"网络波动"四个字开始在公司里流传。运维开始查交换机、查防火墙、查出口带宽——一切正常。带宽曲线平稳得像什么都没发生。**因为确实什么都没发生在带宽上。**

十一点四十，有人提出了第一个接近真相的猜想——一个实习生，在群里弱弱地问了一句："要不要查一下 DNS？"然后自己补了一句"应该不至于，DNS 好多年没出过事了"。

这句话沉下去了。**没有人接。**不是忽略——是那天上午所有的人都在扑火，火在哪里看得见（应用重启了三遍、网络设备查了两遍），而 DNS 这种东西，是空气：正常的时候没人想它，异常的时候——异常的时候大家会想起它，但上午十一点，递归缓存还没过期到那个程度，**大多数内部测试还在通过**——因为公司自己的测试客户端，缓存还没到期。

**他们在自己的缓存里测试一个已经断了的权威源。**

这就难怪查不出：拿昨天送来的报纸，验证今天的邮局还开着门。

十二点，午休没有休。十二点四十，程亦朗从董事会现场出来看了半小时手机——董事会被迫中断，他冲进战情室的时候，领带是歪的，这是老员工第一次见他领带歪。

下午一点，战情室正式成立。

---

沈见微是在下午六点四十分进来的。

温遥在门口等她，两个交接的动作快得像演练过：一件外套（"战情室冷"）、一杯热水、一句话——"**到现在，方向还没找到。应用和网络各查了三遍，全绿。现在在查第三方 CDN 服务商。**"

"CDN？"

"嗯，CDN 那边的工单回复了，说他们的节点一切正常，问题在回源。"温遥压低声音，语速快得像发报，"回源——源是什么，你知道的。**现在屋里还有人主张继续给 CDN 施压，让他们查节点。**"

沈见微把外套搭在手臂上，站在战情室门口，往里看了三秒钟。

三秒钟里她看见的东西，比过去六个小时里面所有人看见的加起来还多——因为她不是从下午两点开始看的，**她是从四年前开始看的**。

她看见战情室的正墙上挂着三层监控大屏，全绿。她看见应用组的人围着一张桌子重启第四遍服务。她看见网络组的人在配线架前面打着手电。她看见 CD N 的工单被打印出来传阅，传阅到一半被捏出了褶。她看见乔曼。

乔曼站在主桌的侧面，正在说话。

"——CDN 的回复我认为不能采信，"她的声音是这一天战情室里最稳的声音，冷静，专业，条理分明，"但也不能排除。**我建议双线并行：一边让 CDN 出具节点级证明，一边我们自查出口策略——尤其是上周刚上线的防火墙规则灰度。**"

有人立刻去执行了。她的建议永远是可以执行的、流程完美的、听起来极有道理的——**防火墙规则上周确实灰度过，这是一个真实存在过的、现成的嫌疑对象。**

沈见微看着她。

隔着半个战情室，她看着这个下午两点半就到了战情室、指挥排查四个小时、滴水不漏的女人。四年前她看不懂这个人；两年前她看懂了手法；此刻，她看懂了全部——

**乔曼不是在误导排查。她是在"组织"排查。**组织一个永远差半步的排查：查 CDN，查防火墙，查运营商——每一条线都是真的，每一条线都值得查，每一条线都恰好不指向配置中心。她甚至不需要撒谎，只需要**排序**：把所有正确的方向排在错误的方向后面，然后用"严谨"把排序固定住。

四年前雪崩案的那一晚，她也是这样"冷静专业"的。

历史不是在重演。历史是同一个人，用同一双手，在更大的舞台上，做同一个动作。

"她四个小时做了什么？"沈见微低声问温遥。

"协调了 CDN 工单、组织了防火墙自查、拉了运营商的链路报告……"温遥数着，忽然停住，她反应过来了自己数出来的东西是什么，"**每一样都对。每一样都……绕着走。**"

"嗯。"

"你怎么……"

"我不是猜的。"沈见微说，"我手里有东西。周日晚上的变更确认单——配置治理二期的批次，第二十七行，同步了二十三个参数段。里面有 dns-authoritative-resolver。"

温遥的呼吸停了半拍："**dns……权威解析？**"

"权威解析。"沈见微说，"现在所有服务的'全绿'，都是缓存在撑。缓存三十二小时，从昨晚十一点起算——**骨牌从今天上午九点开始翻，现在翻到第几张了，没人知道。但源头我知道。**"

她说完，不再等温遥的反应，径直往主桌走。

战情室很吵。她穿过人群的方式是一种她独有的东西——不快，但没有人挡得住。四年了，这间公司的人对她的背影有一种条件反射：那个背影出现的时候，说明排查要换方向了。

她走到主桌侧面，乔曼的旁边。所有该看的她都看了，所有该核的她路上都核了——W-041 的确认单、二十七个段的名字、TTL 的时长、异常开始的时间。链条不需要再验证了。她只需要做一件事：

**让一屋子查了七个小时的人，停下所有错误的方向。**

她开口了。声音不大，但战情室的嘈杂有一种奇怪的脾气——她的声音一出来，人群会自动降两个调，因为她开口从来不说废话。

"查变更。"

半屋子人回过头。

"查配置治理的变更。"她说，"周日晚上的，W-041。第二十七行，共享域参数段同步——同步范围里包括权威 DNS 解析参数段。**服务全绿是因为缓存还没过期——你们在拿昨天的报纸，验证今天的邮局。**"

战情室安静了一秒。

那一秒里，她听见很多人的呼吸变了——那是"所有碎片突然咬合"的声音。应用组的人想起来了：服务确实全绿。网络组的人想起来了：带宽确实正常。查 CDN 的人想起来了：回源失败，**源**是什么来着？

然后，整个战情室像一台巨大的机器换了挡，轰的一声，所有人的方向调转过来——应用组的组长抓起内线电话喊"查配置中心的状态快照"；网络组的人从配线架后面钻出来直奔工位；连打印机都开始吐 W-041 的批次材料。

混乱。但是对的混乱。

在这一切的中央，乔曼站在原地，没有动。

她看着沈见微。沈见微也看着她。两个人的目光在战情室的人声鼎沸里交汇，隔着一张摆满咖啡杯的主桌——一个刚刚交出了答案，一个站在答案的源头。

乔曼先开的口。她的声音还是稳的，稳得挑不出任何毛病，甚至带着恰到好处的如释重负：

"见微回来得好。"她说，"**我四个小时前就调过 W-041 的材料了**——一直排在待核清单里。你来得正好，第二十七行是你名下的变更，**你来说明一下执行情况，比谁都权威。**"

战情室的人声，在这一句话上，降了半度。

有几个人回头看了沈见微一眼——那一眼里的东西很复杂，是刚刚的敬佩，掺进了一点新的、说不清的什么。

沈见微站在原地，看着乔曼。

她听懂了。这句话是刀。刀藏在"比谁都权威"五个字里——在座的每一个人都刚刚听见"第二十七行是你名下的变更"这九个字。**答案和罪名，在同一句话里交付了。**

四年前，她大概会当场炸——当场质问，当场失态，当场掉进圈套。

两年前，她会忍——把火咽下去，先做事，把委屈留到复盘。

此刻，她做了一件介于两者之间、但两样都不是的事：

她点了点头。

"好。"她说，声音平静得像在评审会上答一个问题，"我来说明。**先恢复，后说明**——恢复需要十五分钟：把二十三个段从基线快照里回滚，回滚完成，缓存刷新，服务恢复。说明放在恢复之后——因为说明不止我一个人的事。"

她顿了顿，看着乔曼，一字一字：

"**第二十七行，从评审评论到边界修改到执行挂载，每一个环节的经手人，恢复之后，我们一起对时间线。**"

乔曼的脸上的表情，没有任何变化。

**完美**的表情管理。但站在她侧后方的温遥看见了一个细节——乔曼搭在桌沿的那只手，指尖极轻地、几乎看不见地，蜷了一下。

像一根绷了四年的弦，第一次，被指甲碰出了声。
