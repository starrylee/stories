# 第一百八十七章 时区

周二，相框寄到了。

顺丰，寄件人栏写的是铺子全名，包裹里除了相框，还有一张便签——池默的字，还是那样，收笔偏紧，但每笔都落到了底：

"原件入墙。复印件我挂铺子里了，价目表旁边。**来修手机的人抬头能看见。**今天有个取件的大姐问这是什么，我说是一个规矩。她说什么规矩。我说——**讲完的规矩。**她说挺好，她家那口子也讲不完话。

零日之约的会，我不去。**人多的会我不讲东西。**凳子给你们留着，哪天路过，坐着修手机。"

温遥把相框挂上了提案墙。挂的位置她挑了很久——最后挂在提案墙最左端，"提案墙"三个字的名牌底下，第一件。

"为什么是第一件？"青梧问。

"时间戳最早。"温遥说，"这条规矩的原稿，落款在十二年前。**我们墙上其他展品都比它年轻。**"

沈见微站在那面墙前面看了一会儿。玻璃后面那张软纸，两行字。正文一行，落款一个名字。

正文的字是池默的，紧而稳。落款的字是老严的，老了，但收笔很轻，像怕压着正文。

"给下一个开口的人。"她低声念了一遍，走开了。

公约第七次修订版，周五定稿。六条意见采纳四条，驳两条。驳回的两条写进了修订说明，理由各一段——夜枭坚持："**被驳回的意见也要留在纸上。规矩的成长史，比规矩本身值钱。**"

修订版发布那天，两点半社群里转发了一遍。转发语是青梧写的，只有一句：

"新规矩：**打断别人陈述的人，要署名了。**"

当天晚上，社群里一个平时从不发言的 ID 发了第一句话。是个运维组长，凌晨两点十七分发的：

"想问一下。要是打断的人是领导，署名这条，**真的敢用吗？**"

这条消息底下，三分钟内盖了一百多条楼。有人答敢，有人答不敢，有人讲了自己会上被打断的经历。凌晨两点半的社群，跟它的名字一样热闹。

沈见微没有回帖。她把那条消息截了图，存进一个新建的文件夹。

文件夹名她想了半分钟，最后叫：**"不敢用"**。

问题清单。公约管纸面上的权利，**不管纸面外的胆量**。权利写进去是一回事，用出来是另一回事——十二年前池默有附卷权，他也附了卷；有申辩权，他也申辩了。权利都在。**人被摁住了。**

摁住人的东西不在公约里。在会议室的座位表里，在年终评级的权重里，在"这个人不好合作"的私下印象里。

她盯着文件夹名看了一会儿，然后在旁边记了一行：

"**下一步不在条款层。在椅子层——让敢用的人，坐到不用看人脸色的椅子上。**"

周六，回沪第九天。

江叙白在书房改《制度补丁》的再版稿。她端了两杯茶进去，一杯放他手边，一杯放自己那边。

"零日之约的议程。"她说，"二届的。主办方联席会下周三，你列席吗？"

"我列席什么。"江叙白说，"我列席，别人就要听我发言。**我去了，议程就矮半头。**你们开。"

"那议程里有一项，需要你点头。"她把平板推过去。议程第七项：**"打断署名条款"的提案人出席确认**。

提案人栏，写着"修机·复数据（池默，视频接入五分钟）"。

他看完，点头："五分钟够吗？"

"他自己要的。"她说，"他说的原话：'**我在人多的会上讲不了东西。五分钟，我念稿。念完就断线。**'"

"念稿。"江叙白说，"十二年前他被摁住的那句话，今天要用念稿的方式说出来——"

他停住了。想了一下，改口："**念稿好。**念稿的人不怕打断。**稿子在那儿，打断一次，接着念。**"

她说："我就是这么答他的。"

两个人各自端起茶。书房窗外，下午的光斜进来，照在两摞清样上。一摞是他的，一摞是她的。两摞的高度差不多——这半年来，他们的案头一直保持着这个对称。

"还有一件事。"她说。

他从清样上抬起眼。

"那个号码，"她说，"今天回复了。"

江叙白放下笔。

"四个字。"她把手机递过去。

屏幕上，那条消息是下午三点零六分发来的。回复时间是傍晚六点五十一分——间隔三个小时四十五分钟。

四个字：**"下次路过。"**

没有称呼，没有落款，没有一个多余的字。

江叙白把手机还给她。两个人对着这四个字，安静了几秒钟。

"三个小时四十五分钟。"他说，"他看到消息，到发出回复，中间隔了将近四个小时。"

"你也注意到了。"

"**这四个字他写了将近四个小时。**"江叙白说，"一个能接触原始纪要的人，不说别的，至少当年的级别不低。这样一个人，回一条四个字的消息，写了近四个小时——**每删掉的一稿都比留下的长。**"

沈见微把手机扣在桌上。她想起老严在车站说的话——沉默者开口，有他们自己的时区。

"下次路过。"她重复了一遍，"'路过'，说明他知道那间铺子在哪儿。'下次'，说明他给自己留了不承诺期限的余地。**四个字，一个地址感，一个时间弹性。**"

"还有一个信息。"江叙白说，"他没问'是谁把号码给你的'。**默认他知道你们查到了他。**不惊，不避，不解释。"

"这种人，"沈见微说，"当年在会议室里，大概也是这样——**什么都看见了，什么都不说，谁也不知道他看见了。**"

她说完，忽然笑了一下。

"笑什么？"

"我想起来，"她说，"我们这一路办过的案子，最难办的从来不是撒谎的人，也不是构陷的人。**是看见了、记住了、然后不说的人。**证据在他们的记忆里存着，比硬盘里存得还稳——但取不出来。"

"现在有一个开始往外取了。"江叙白说，"虽然一次只有四个字。"

"一次四个字。"她说，"十二年的沉默，按这个进度，说完全部要——"她心算了半秒，"算不出来。**但没关系。我们等得起，他也开口得起。两头都不催。**"

窗外，天色慢慢往晚了走。晚饭的时间快到了。她收拾平板站起来，走到门口，又停住。

"下周三联席会，"她说，"还有一项我想加。"

"说。"

"议程末尾，加一个'自由陈述'环节。不限题目，不限内容，五分钟一个人，**报名自愿。**"她说，"第一年没人报也没关系——**把环节放在那儿。**像留白墙第一行，像铺子门口那张凳子。"

"放的目的是什么？"

"让每一个来参会的人都知道，"她说，"这间会议室里，**有一个属于'讲完'的位置，从今天起，一直在。**"

江叙白看了她几秒钟。然后他从清样堆里翻出自己那份议程草稿，拿笔在末尾划了一道，写了一行字。

写完推过来。她看见那行字是一个问题：

**"陈述从何时开始计时？"**

她愣了一下，随即明白过来——计时从开口那一刻起，还是从打断之后重新讲起那一刻起。这是个条款漏洞，也是个哲学问题。

她拿过笔，在问题底下写答案。写得很慢，一字一句：

**"从第一次开口那一刻起。中间被打断的每一秒，都算陈述人的时间。"**

写完，两个人看着这行字，谁也没再改。

晚饭下楼吃的。楼下那家面馆，老位置。两碗面，一荤一素，交换着吃一半——这是他们的老规矩，从五年前那间车库开始的老规矩。

面端上来之前，她的手机又震了一下。两点半社群，"不敢用"文件夹相关——青梧转来的：那个凌晨发问的运维组长，今晚发了第二条。

第二条比第一条长：

"补一下。今天下午我们开周会，我试了新条款。领导打断我的时候，我把纪要推过去，说——**麻烦署个名。**他看了我十秒钟，签了。签完说：'行，你接着讲。'"

"我讲完了。入职六年，第一次在周会上把一个方案的来龙去脉讲完。讲完之后会议室安静了几秒钟，我领导说：'早这么讲，三个月前就不用返工了。'"

消息末尾，他补了一句：

"**原来打断是可以被署名摁住的。原来我讲完的时候，是有用的。**"

沈见微看完，把手机屏幕朝下放在桌上。面来了。她拿起筷子，先吃了一口，慢慢咽下去。

然后她说："这条，截图存档。**不进'不敢用'文件夹了。**"

"进哪儿？"江叙白问。

她想了想。

"新建一个。"她说，"文件夹名，我想好了——**'敢用了'。**"
